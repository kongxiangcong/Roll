# Roll 能力补齐与开源组件增量接入

**Status:** ready-for-agent
**Completion:** pending
**Execution:** IN_PROGRESS — 2026-10-15 用户显式启动；2026-10-14“仅发布”的文字为发布时历史边界。
**Created:** 2026-10-14（Asia/Shanghai）

## Problem Statement

Roll已具备账户镜像、证据归档、量价模型、历史模拟、连续影子、自动验证框架和日常界面，但部分真实数据与政策闭环尚未完成，财报和新闻情绪能力不足。用户希望通过成熟开源组件补齐能力，减少重复开发，保留当前架构、已完成验收及运行资料。另一会话仍在实施，因此当前只能发布独立计划，不能用本次审计快照覆盖它的最新成果。

## Solution

按现有闭环收尾、财报观察、新闻情绪观察、绩效报告与统计核验、新特征研究的优先顺序，形成可逐票实施的增量交付。先验收另一会话的交接；已经实现并通过验收的范围引用证据继承，只开发真实剩余差量。新观察功能先提供有出处的事实与分析，不直接改变已冻结量价模型或正式资格。

首期沿用既有受支持证券；真实采集试点以交接时已授权的600362范围为基线，工程允许已登记的证券身份，其他证券通过明确范围验收后开放。财报首期支持一般非金融企业，银行、保险、券商等特殊行业明确不支持专用比率，不伪称全行业分析。

## Implementation Decisions

### ID-01 交接、所有权与实施启动

当前只发布计划，所有票pending。用户以后显式启动后才执行01；01必须核对最新集成提交、未提交修改、验收材料、冻结工件与运行状态。不能假设另一会话成功，也不能重做它已验收的切片。记录每项旧责任为已继承、待补差量、外部阻塞或范围变化；没有证据不得继承。旧P0仍是其原范围的验收权威，新票只描述补充切片，不靠关闭新票自动关闭原票。

### ID-02 架构与最小复用

保留Python/FastAPI模块化单体、React、SQLite正式状态、Parquet与内容寻址原件。复用已有源配置/退避、worker租约、归档、研究注册、影子、通知和报告边界；不建立第二套账本、数据湖、调度、策略DSL或权限平台。无需独立前置重构票：必要小重构与首个可展示切片一起交付。若实现证明必须改公共模型，采用兼容扩展、消费者迁移、最终收敛，另记实际影响，不借本计划重写核心。

### ID-03 组件选择与版本

默认：既有CNEquity/BaoStock；AKShare财务/新闻取数；Docling表格/OCR；Trafilatura正文；QuantStats报告；scikit-learn评分；arch区块统计；中文FinBERT2为需验证权重的分类候选。datasketch仅在近重复规模/样本表明需要时采用，精确hash先行。
Tushare为具备用户配置服务权限时的替代来源，不因默认源失败擅自申请账号/购买；RSSHub、MinerU是证据支持时的替代，不是必装依赖。Qlib、Alphalens、skfolio、GS Quant、FinRL、FinGPT不在本次必交范围；未来需要多证券因子/组合研究时另立规格。
每个组件随首个业务切片完成版本/许可/必要依赖/Windows兼容核对；重依赖使用现有子进程模式隔离，不把大量模型包塞入业务环境。锁定代码及权重摘要，不自动升级。无可用许可/权重时保留真实阻塞，不强行使用不明下载包或替用户接受服务条款。

### ID-04 原件、来源与采集用途

真实响应先存再解析；若库只返回DataFrame，使用其受支持传输扩展或限定源适配保存原响应，不能把重新序列化的DataFrame称为上游原件。若无法可靠捕获，候选只作诊断，不进入要求原件的正式用途。记录证券、上游、请求范围、返回分页、单位、披露/首次接收/可消费时间、修订和用途。相同上游不算独立来源；未查到不等于不存在。新增版本不能重解释旧保存包。
来源接入前沿用已有调用预算；无既定预算的新公开源默认单证券、单次用户请求最多8次HTTP、总18秒/8MiB，零隐式重试。解析下载若需不同资源上限须先在该票记录固定计划，不循环试源。不得突破已CLOSED的历史来源尝试预算。

### ID-05 旧闭环补齐与期限

日线、状态、行动三个切片分别消费真实来源证明，不能承诺开源库解决所有历史缺口。后继政策延续已登记经济目标与规则，只补完整协议、验证器和消费者；没有既定参数时先冻结明确的后继设计再接触确认性结果，不从有利结果反选阈值。当前动作有效期与LOSS恢复规则沿用旧P0要求；未授权不得代填真实资金。
首条真实前向只依赖数据、完整冻结与确认性准入、备份等原起点条件；正式动作、LOSS恢复、财报与新闻不是额外启动前提。首次归档起最长三自然月，缺席和换库不重置期限。运行外部条件不成立时记录具体阻塞，继续独立可实施票。

### ID-06 财务事实模型

用新增不可变财务版本保存证券、行业、报告期、披露/接收时点、报表类型、币种、原始单位、原始字段、规范字段、修订关系与原件引用。资产负债表为时点数，利润/现金流区分累计与单季；不混合合并/母公司，不将供应商最新重述值倒填成历史可得。更新同一期形成新版本，原有观察重放仍指向旧版本。

### ID-07 财务指标与分析

单季流量：同口径Q1原值，Q2/Q3/Q4累计减上一季累计；缺前期或版本不可比则未知。TTM由四个连续可比单季求和。同比仅在基期为正且口径可比时给百分比，基期为零/负给绝对变动与原因；不以绝对值分母制造增长率。
初始指标为营收/归母净利、毛利率（适用时营业收入减营业成本再除营业收入）、经营现金净额、净利率、经营现金/净利润（正净利）、负债/资产（正资产）；分子分母主体需一致，归母净利不得与集团现金流混作同主体比率。没有同主体利润就拒绝该比率。零/负/缺失及现金流健康解释分开。暂不作不明口径自由现金流、估值目标价、行业排名或统一买卖评分。
提供指标、跨期趋势、可追溯说明和局限；文字分析只引用已验证事实，不能用LLM补数字。金融企业专用指标留明确不适用。

### ID-08 文档解析

Docling消费已保存PDF，输出派生表格/文本及页码、边界、解析器/模型指纹。结构化源与PDF冲突并列，不静默替换。检查跨页表头、负号、括号、千位与万元、合并列、脚注；低置信/不可识别保持待核。模型首次下载、运行资源与兼容在该票单独验收；解析失败不影响原pypdf查看。

### ID-09 新闻事实与去重

AKShare指定证券近期新闻作为首个来源，保留近期条数限制与查询词，查无结果不证明无新闻。正文由已归档HTML离线抽取；原标题、链接、媒体、发布时间和首次接收分别保存，发布时间未知不猜。
先按规范URL与正文hash精确归并；近似重复仅产生候选组，不删除原件。数字/日期/否定/更正变化保留独立版本；转载组多个媒体不累计为多个独立事件。证券关联分明确公司、行业背景、不相关/不确定，多对象事件保存对象级含义，不由标题关键词自动给交易动作。

### ID-10 情绪模型与序列

先核对FinBERT2具体checkpoint、语种、标签和许可，复用推理而非默认自训。二分类权重不凭空生成中性概率；由相关性/不确定拒判层处理，UI注明真实标签集；若任务必须中性而模型无法支持，候选不通过并记录最小替代评估。
离线评估集至少120条，来自合法归档中文材料，覆盖正/负/中性/不相关、否定、修订、多公司和转载；按事件组及时间切分，保留人工标签或明确“非独立人工标注”。查看结果前冻结标签映射、各类支持、macro-F1、每类召回/混淆、拒判覆盖与速度门槛；没有独立标签的评测不得宣称真实分类有效性。工程夹具不替代业务评估；不要求用户为本票承担技术标注职责，证据不足可保持研究试用。
序列默认展示正/负/中性/拒判计数、唯一事件数、来源覆盖、模型版本、截至时点；仅支持的类别进入汇总，不发布伪精确综合情绪指数。分类置信度名称始终为文本情绪，不能称收益/买入/卖出概率。

### ID-11 日常观察与UI

沿用“今天、持仓与关注、同步账户、历史记录、设置”五入口，在单股与复盘页增加可折叠财报/新闻区，不新增大型诊断首页。后台仅在线时按已登记盘后检查点采集，手动按需复用缓存与真实新鲜度；离线留缺口，不创建新的桌面自动化。暂停/退避局部化，重复结果不重复通知。外发仍等待用户既有渠道配置与授权。

### ID-12 报告与统计参照

QuantStats只读接收Roll已有净值/收益与基准，禁止隐式下载；外部转入不算收益；账户/历史/影子/条件诊断分开。固定窗口、年化/无风险利率、费用与缺失口径，阻止默认dropna/首个非零截断篡改可见覆盖；不足区段不出完整期指标。
scikit-learn核对Brier、log-loss、可靠性曲线；arch核对成对区块区间。明确标签成熟、去重、日历聚合、区块、重采样、随机与区间定义。先作为诊断参照，不替换冻结代码；独立数值一致不等于独立统计有效性。发现差异区分口径与实现缺陷，原失败保留。

### ID-13 新特征研究与真实执行门槛

新增财务/情绪特征仅以实际可得版本形成快照，保留所有缺失和拒判；旧量价模型指纹与结果不改。研究方案在查看确认性结果前冻结，继承家族关联、全部失败及共享预算。最多登记量价基线、加财务、加情绪、二者组合四种消融配置，但实际拟合数量受现有剩余预算约束；不足则减少预登记范围或保持阻塞，不能自动重置预算。
保持已批准预测事件/期限及执行假设，比较同一支持窗口、净费用收益及概率可靠性；必要的时间隔离/模型训练语料截止不明列为风险，不声称严格历史未知。训练、完整冻结、真实前向、终点交付分票。工程模拟可先完成，真实训练、SEALED访问、模型技术审阅和资金启用沿用现有授权边界；本计划不授权新的外部材料发送或自动交易。

### ID-14 增量迁移与失败隔离

新增事实/派生表/索引采用兼容迁移，旧读者和原工件可重放；禁用组件不删原件、不清空状态，不借降级恢复失效资格。迁移与恢复在隔离副本验证，真实库操作服从启动时保护要求。新库错误不得阻断原账户同步、既有来源与复盘；资源上限、取消、重启、失败回执沿用原运行时。

## Testing Decisions

- 主边界沿用已确认的公开FastAPI命令/查询，真实隔离SQLite与临时原件目录。测试请求→持久化→查询→重启/重放的外部行为，不锁定内部函数调用次数或数据结构实现。
- 先例为现有市场证据、来源解析、模型/连续影子、统计方法、报告、运行角色和迁移恢复应用测试；延续原测试框架与隔离方法。
- 浏览器只验用户关键链：单股财报溯源、新闻去重/情绪说明、报告导出、设置暂停和手机宽度；API通过不代替浏览器通过。
- 真实来源/模型工件兼容验收与固定响应测试分别记录；403/限流/截断/网页变化是可报告结果，不写成成功。模型分类样本评估与METHOD测试分开。
- 主动覆盖重试幂等、部分写入、取消/崩溃、原件损坏、来源同源、单位/时点冲突、未来数据拒绝、缺失不补零、账户与旧冻结不变。
- 数值参照使用相同输入和明确容差；精确货币仍用原Decimal链，不用浮点报告反写账本。
- 每票附固定版本、命令、结果、失败、截图/回执、剩余项；按pending/partial/complete记录。只在所有必需验收成立时complete，不以实现完成冒充真实资格。
- 26完成本次工程集成；08、23—25的真实时间/权限待满足项单列，不伪造结束，也不阻塞独立观察模块开发。

## Out of Scope

整仓迁移第三方平台；券商自动下单；全市场无限新闻流；盘中持续覆盖承诺；默认付费服务/账号申请；大模型自训练和多角色裁决；无登记批量策略搜索；全行业财报分析/估值推荐；替换旧模型或删除旧实验；强迫等待数月的代理会话；新增桌面定时任务；未经配置实际外发。
Qlib/Alphalens/skfolio等未来方向不列为本轮必装；开源库不替代真实PIT、独立验证或正式资格。

## Acceptance criteria

- [x] 基于15唯一事件与16实际支持标签生成计数/比例，分母和拒判数可见；不以转载数加权制造热度。
- [x] 事件首次可消费时点按Asia/Shanghai映射已登记观察检查点，盘后/休市内容不倒入之前交易日。
- [x] 页面显示源覆盖、数据截至、模型版本、缺失和不支持类别，不默认输出伪精确综合指数。
- [x] 模型/去重策略变化生成后继序列，历史观察可重放，不混合不同标签语义或检查点。
- [x] 通过公开查询与浏览器验重复、漏日、非交易日、多对象方向、版本更换；无数据不是中性。
- [x] 附本票适用的代码/依赖版本、公开行为验收、真实与METHOD边界、原失败及剩余条件；若继承另一会话成果，引用精确验收并核对当前版本。不得以仅写计划或仅实现拒绝路径替代所要求的正向能力。

## Implementation boundary

优先复用原服务和指定成熟组件；新增表、接口、页面与测试围绕本票用户路径增量实现，不横向重写整个模块。01交接票只做交接核对；08及23—25是真实运行操作。其他票的API/持久化/界面与测试应作为同一可演示切片交付。新组件不可写真实账本或自签资格；没有必要不新增测试入口或插件框架。

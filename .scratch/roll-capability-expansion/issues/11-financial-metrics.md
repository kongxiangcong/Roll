## Acceptance criteria

- [x] 实现规格ID-07的单季差分、TTM和同比规则，输入期间/主体/币种/单位必须可比；前期缺失即未知。
- [x] 实现营收/归母净利趋势、适用毛利率、净利率、经营现金、同主体现金利润比和负债率；每个值提供公式口径与源版本。
- [x] 负/零基期的同比显示绝对变化和原因；零/负分母、金融行业不适用和字段冲突不硬算。
- [x] 同一期更正追加版本；当时观察与当前修订视图分别查询，不使用后来重述改写历史知识截止。
- [x] 公开API验证跨季度/年度、累计/单季、合并/母公司、万元/元、重述、缺失，页面可展开口径与出处。
- [x] 附本票适用的代码/依赖版本、公开行为验收、真实与METHOD边界、原失败及剩余条件；若继承另一会话成果，引用精确验收并核对当前版本。不得以仅写计划或仅实现拒绝路径替代所要求的正向能力。

## Implementation boundary

优先复用原服务和指定成熟组件；新增表、接口、页面与测试围绕本票用户路径增量实现，不横向重写整个模块。01交接票只做交接核对；08及23—25是真实运行操作。其他票的API/持久化/界面与测试应作为同一可演示切片交付。新组件不可写真实账本或自签资格；没有必要不新增测试入口或插件框架。

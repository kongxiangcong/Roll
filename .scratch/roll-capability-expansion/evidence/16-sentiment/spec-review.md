# 16 规格审查

| 验收条件 | 结论 | 说明 |
| --- | --- | --- |
| checkpoint/中文任务/标签/许可/来源/资源 | 部分 | FinBERT2 无可推理情绪权重；替代模型 apache-2.0、权重 SHA、CPU 资源已记录 |
| ≥120条计划、标签来源、事件/时间隔离、结果前冻结门槛 | 通过 | 150唯一事件、120+30标签、门槛先冻结 |
| 二分类不伪造中性；不相关/模糊/低支持拒判；记录标签集 | 通过 | 拒判层 v1；二分类仅 Negative/Positive |
| 保存分类/对象/模型与输入版本/置信度；公开查询与研究页面 | 通过 | API/持久化/页面/真实运行 |
| 真实每类支持、macro-F1/召回/混淆/拒判/延迟；非独立标签不宣称独立有效；未过门槛研究受限 | 通过 | eval 结果与页面限制 |
| 许可/模型缺失则该能力partial并给资源条件 | 通过（保持partial） | FinBERT2 权重缺失，未购买/未自训 |
| 版本、边界、原失败与剩余条件 | 通过 | acceptance、reference、两次评估保留 |

结论：工程与替代评估完整；FinBERT2 资源条件未满足，保持 partial，不宣称情绪能力通过。

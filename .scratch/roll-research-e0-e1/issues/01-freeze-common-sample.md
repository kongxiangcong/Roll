# 01 · 冻结预设与共同样本

Status: ready-for-agent

Blocked by: 无，可直接开始

## What to build

研究者从正式 Roll CLI 为江西铜业建立开发实验任务，显式选定有版本的 E0/E1 预设。按任务 ID 可重读冻结的预设、数据快照和共同入场机会集，即使两组特征从未同时就绪，也能查到阻塞日期和原因。

## Acceptance criteria

- [ ] 建任务时能核对 E0 的权益调整总回报指数 20/60 日均线规则、E1 的沪深 300 收盘价严格高于含当日在内的连续 20 日收盘均值条件、15:05 信号时点和次日开盘执行时点。另起 CLI 可重读所选版本及绑定的快照。
- [ ] 开发清单仅使用本地冻结数据快照。回执记录来源版本、快照用途（重建研究或严格历史时点用途）、实际取得时间、逐日可得性假设及单源与修订风险。用晚于开发期取得的合法重建行情断网验收，确认外部数据请求和付费数据开销均为零。
- [ ] 仅在 2020-01-02 至 2023-12-29 内逐日选取当时可用的量价和权益观测，再生成特征和统计。以带独有标记的 2026 年公告、复盘备注、留出期行情和跨窗摘要核对开发清单。改变窗外数据，比较两次公开材料的内容；改变开发期较晚观测，核对此前的信号。
- [ ] 用指数较晚完成预热、期间有缺失、不可用或未解决冲突的行情手算共同起点。相应特征的连续预热在中断后重计；回执标明名义和有效区间、候选日分母、共同可评价日、损失日及所有原因，同日损失只计一次。
- [ ] 以无共同可评价日的快照发起任务，重开 CLI 仍能按任务与尝试查到预设、输入引用及覆盖缺口。对比操作前后的正式样本揭示记录。

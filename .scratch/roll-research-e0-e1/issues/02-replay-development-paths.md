# 02 · 运行四条路径并离线复算

Status: ready-for-agent

Resolution: completed

Closed: 2026-11-27

Blocked by: 01

## What to build

研究者用冻结任务运行 E0、E1、买入持有和不主动交易，按任务取得不可变的开发回执，并能从原输入离线复算。开发入口复用既有模拟撮合、成本与权益规则，独立于会登记样本揭示的正式实验运行和回放。

## Acceptance criteria

- [x] 四条路径以首个共同信号日盘后为计量起点，均从 10 万元模拟现金、零持仓和同一模拟预算出发。E0、E1 与买入持有从该盘后产生首批决策，再从下一开盘起撮合。仅使用预设模拟账户；在验收副本替换真实持仓、成交或风险预算后结果相同。
- [x] E0 沿用冻结趋势策略。用指数高于、等于和低于均线的样例验证 E1 只过滤买入及加仓，为已有持仓保留原退出规则。任一必要特征缺失、不可用或冲突时，两条路径均暂停新增买入；既有可判定退出、在途权益和估值连续处理。
- [x] 使用可手算的次日成交、未成交和公司行动案例核对四条路径。回执列出净收益、相对双基准收益、最大回撤、成交笔数、费用和滑点，沿用协议的最低佣金、历史费率和股息红利税前口径。末日待执行信号标为超窗；修改留出期行情不改变开发指标，修改窗内较晚观测不改变此前成交。
- [x] 从回执可核对共同样本、覆盖损失和实际过滤数及其分母；直接过滤与持仓路径分化产生的后续差异分别计量。估值或执行依据不足时标出受影响的日期、路径和指标。
- [x] 保持同一输入、共同起点和缺数处理，仅在自检中令 E1 条件恒真。核对两组逐笔成交、费用、权益及逐日净值完全相等。另起离线进程复算正常预设，核对共同样本、过滤数、双基准和全部指标。
- [x] 成功回执绑定到任务并可在进程退出后重读。制造计算失败时可查到预设、输入引用、失败环节和原因。核对成功、失败及复算前后的正式验收和样本揭示记录一致。

## Comments

分别从 10 万元和零持仓起算四条模拟路径。实际回执 E0 净收益 23.08913%，最大回撤 43.61340%，20 笔成交，费用 1,426.87 元。E1 净收益 25.67537%，最大回撤 41.47287%，19 笔成交，费用 1,444.63 元。买入持有净收益 49.42026%，不主动交易净收益 0%。E1 在自身 34 次共同可评价的买入候选中直接拦截 17 次。恒真自检以及另起 CLI 对输入、逐日轨迹、归因和回执 ID 的复算均通过。

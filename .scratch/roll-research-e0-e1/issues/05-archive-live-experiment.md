# 05 · 审阅归档并完成真实助手联验

Status: ready-for-agent

Blocked by: 03, 04

## What to build

研究者从正式 CLI 完成一次江西铜业真实助手解读，核对回执中的交易和区段，按指定尝试和报告版本在任务内归档。工作台后续可通过同一任务读取完整证据；本票在 CLI 验收。

## Acceptance criteria

- [ ] 在验收库副本上通过阶段 02 的真实受限助手执行一次开发解读。从报告中的收益、成本、成交日期和持仓区段定位到冻结回执，核查回撤期间持仓、差异集中情况及证据限制。保存可重放的命令和产物引用。
- [ ] 归档指定尝试和报告版本。另起 CLI 按任务读回冻结预设、输入、回执、解读，以及目标尝试、报告版本、结论类别、审阅人、停止或继续的理由和归档时间。开发报告不能作为个股研究档案发布。
- [ ] 核对四类结论及理由。动作一致、差异仅由缺数或费用解释、改善集中于单段时停止扩展，证据不足时保留缺口。仅在多个不重叠段仍有待解释差异时，记录下一项仓位对照的预定规则与计量口径，交由后续研究。分组日均收益仅支持提出假设，全窗平均持仓匹配仅用于事后归因，评估推广性需要新的独立数据。
- [ ] 发起实验前保存固定当前盘后输入的 `roll plan --preview` 档案引用及正式验收、样本揭示和生产准入记录。归档后以相同输入核对仍引用原个股档案，各项记录逐项一致；`roll experiment verify m0a-jxcc-default` 仍能离线核验原报告。

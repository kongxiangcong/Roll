# 03 · 把差异追到交易和持仓段

## What to build

研究者通过正式 CLI 从开发回执的两条收益路径下钻，定位到哪天产生了不同的动作、哪笔实际模拟成交改变了仓位，以及各自最大回撤发生在哪个持仓段。同一份新生成的冻结回执携带解读所需的指标、交易和区段引用。

## Acceptance criteria

- [x] 按信号日重读个股入场依据、沪深 300 状态、两组动作、过滤或缺数原因，并追到次日成交日期、数量、价格和费用，或未成交原因。能辨认一次直接过滤以及由先前过滤引起的一次后续仓位差异。
- [x] 按两条路径各自从建仓至清仓的连续持仓段展示日期、仓位、费用和净值变化，标明期末未平仓段。以日期部分重叠的案例核对两条路径的持仓区间并集，每个对照行情段只归因一次。
- [x] 用已知峰谷的路径分别核对 E0、E1 最大回撤的峰日、谷日和期间实际持仓。不同路径的峰谷可落在不同日期。
- [x] 在同一回执按互不重叠的行情段列出差异及集中情况。用动作相同、仅缺数或费用有差异、改善集中于单段及多个区段有差异的样例，逐项从明细复核判断；交易过少或路径不完整时能定位证据缺口。

## Comments

实际回执中，`signal:2021-08-02` 链接到 `trade:e0:2021-08-03`。E0 成交 5,000 股，价格 25.76 元，费用 41.22 元，E1 无委托。两个账本的最大回撤峰日均为 2021-02-23，峰日均持有 6,800 股。谷日均为 2022-11-22，分别持有 6,900 股和 7,200 股。七个互不重叠的对照段中，四个区段的净值差依次为 +4,860.99、−277.65、+318.17、−2,315.27 元，合计 +2,586.24 元，段外残差为零。CLI 回归覆盖仅成本差异、动作一致、单段和多段差异、未平仓及无成交或估值缺口。

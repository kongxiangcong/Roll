# 04 · 按冻结回执解读一次并支持重试

Status: ready-for-agent

Blocked by: 02

## What to build

研究者从同一 CLI 任务取得一份有版本的实验解读。Roll 在回执落库后沿用阶段 02 的受限执行边界，向助手交付本次公开材料和冻结回执。此票用已有指标引用即可验收；逐笔与区段引用在真实助手联验时核查。

## Acceptance criteria

- [ ] 用可控离线执行桩捕获实际输入，确认首次调用时另一 CLI 已可按任务重读同一回执。每次有可解读结果的尝试只调用一次；没有结果的计算失败保留缺口或失败原因。
- [ ] 检查实际交付的公开包和回执引用，确认只含开发窗获准材料与模拟路径结果。用可识别的后期材料及私有账户标记核对，助手无法取得真实持仓、成交、风险预算或本地数据库路径。
- [ ] 按任务与尝试 ID 重读报告版本，沿引用找到原回执中的具体指标，核对解读的数值、差异、不确定性与证据缺口。只有能追到冻结回执的实验结论才可交付审阅。助手提出的新条件可留作后续线索。
- [ ] 分别制造助手失败、超时和取消，按尝试重读对应原因及原冻结回执。人工同输入重试产生独立尝试并复用同一回执，原尝试、回执引用及已有报告版本仍可查询。

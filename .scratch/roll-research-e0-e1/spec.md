# 03 · 江西铜业 E0/E1 开发实验

Status: ready-for-agent

## Problem Statement

研究者想知道，在同一组交易机会中，给江西铜业的日频趋势策略增加一个沪深 300 入场条件，究竟改变了哪几笔交易、多少费用和哪一段回撤。现有开发分析能按大盘状态分组统计日均收益，却无法说明过滤入场后，现金、持仓和后续交易会怎样演化。现有正式实验入口及其回放模式都会登记样本揭示，无法用于这项纯开发期研究。

## Solution

研究者在正式 Roll CLI 建立研究任务，选定一组有版本的 E0/E1 预设。Roll 先在冻结的开发窗口内演算两条策略和两个基准，保存开发回执，再把获准的公开输入与回执交给助手解读一次。研究者按任务 ID 查看结果，从收益差异追到信号日、次日成交和连续持仓段，核对证据后把报告归档到这次研究尝试。报告可以得出“动作一致”“差异集中于一段行情”或“证据不足”。

## User Stories

1. 作为研究者，我希望在建任务时看到并选定完整预设，以便在看到收益前就确定这次检验的问题。
2. 作为研究者，我希望 E0 沿用江西铜业冻结趋势规则，以便与已有单股研究使用相同的信号语义。
3. 作为研究者，我希望 E1 只增加一个定义清楚的沪深 300 入场条件，以便把直接被过滤的信号与后续持仓差异联系起来。
4. 作为研究者，我希望看到每个交易日能使用的材料、快照来源及实际取得时间，以便判断历史重建的依据和限制。
5. 作为审阅者，我希望两条策略从同一个可评价日、同一现金和持仓出发，以便排除提前建仓带来的差异。
6. 作为审阅者，我希望看到候选交易日、共同可评价日和损失原因，以便分清预热、缺数与市场条件过滤各占多少。
7. 作为研究者，我希望逐日查看两条路径的入场机会、动作和次日成交结果，以便知道哪些信号真正改变了持仓。
8. 作为研究者，我希望按相同成本与权益口径比较净收益、最大回撤和双基准，以便理解减少交易对账户的实际影响。
9. 作为审阅者，我希望看到两条路径各自最大回撤的峰日、谷日及期间持仓，以便核查它们是否经历了同一段下跌。
10. 作为研究者，我希望按连续持仓段核对收益差异和费用，以便判断改善是否集中在一次行情。
11. 作为审阅者，我希望从冻结输入离线复算，并能在相同机会集上核对恒真条件，以便验证对照只改变了指定条件。
12. 作为研究者，我希望缺少共同样本、成交资料或估值依据时仍有可读回执，以便知道哪些问题尚无数据回答。
13. 作为研究者，我希望助手逐项引用已冻结的回执，以便核对解读中的数字、判断和证据缺口。
14. 作为研究者，我希望助手失败后仍可重读已算出的回执，以便用同一材料人工重试并保留原尝试。
15. 作为审阅者，我希望按明确的尝试和报告版本记录停止或继续的理由，以便后续研究者了解哪部分观察值得另立问题。
16. 作为盘后操作者，我希望能核对实验归档前后的生效个股档案、样本揭示与策略准入记录，以便继续使用既有计划依据。
17. 作为工作台使用者，我希望后续能按同一个任务 ID 找到预设、逐笔明细、开发回执及已审解读，以便在工作台复核命令行产生的研究。

## Implementation Decisions

- **预设与时点。** 本轮提供一组供研究者在建任务时显式选定的固定预设。E0 沿用江西铜业（600362.SH）冻结协议，以截至信号日已生效的权益构造总回报指数，连续预热后，20 日均线严格高于 60 日均线时目标为模拟风险预算允许的最大配置，否则目标为零。每个交易日按上海时间 15:05 判定，下一交易日按原始开盘价及届时可见的条件撮合。
- **E1 的唯一变化。** 沿用已有开发分析对沪深 300（000300.SH）的状态定义。信号日收盘价严格高于含当日在内的最近 20 个连续交易日收盘均值，才允许个股规则产生的买入，包括加仓。等于或低于均值时拦截该笔买入，已有持仓继续按 E0 的退出及共同风险规则处理。数据中断后重新预热。计数时区分因该条件直接拦截的买入和因先前拦截、后来现金或持仓不同而产生的动作差异。
- **数据快照。** 开发窗口固定为 2020-01-02 至 2023-12-29，研究材料的历史截止为末日盘后。开发实验仅读取本地冻结 `DataSnapshot`，零网络请求、零付费数据预算。先按窗口与各模拟时点选取观测，再构造特征、统计和助手公开包。计算信号只用截至当日已可用的内容，撮合只用下一开盘可得字段。重建研究按 `trade_date <= 2023-12-29` 与逐日可得性假设截断量价及权益观测，保留晚于开发期的实际取得时间供审计而不误判为未来泄漏，并保存快照来源版本、用途模式（`RECONSTRUCTED_RESEARCH` 或 `STRICT_HISTORICAL_AS_OF`）、逐日可得性假设及单源/修订风险。缺失、不可用（`unusable`）或未解决冲突（`conflict`）的观测均不进入信号特征，中断连续预热并计入覆盖缺口。2026 年公告、复盘备注、留出期行情以及包含留出期的全窗摘要一律排除。
- **共同样本与账本。** 窗内预热只积累特征。两组必要特征均就绪的首个信号日盘后为共同期初计量点，E0、E1、买入持有与不主动交易均从 10 万元模拟现金、零持仓、相同模拟预算和期初净值出发，计量至开发窗末；E0、E1 与买入持有均从该共同起点盘后产生首批决策，并于其后的首个可执行开盘起撮合。起算后若任一必要特征缺失、不可用或存在冲突，该日退出共同入场机会集，E0 与 E1 当日均不产生新增买入（含加仓）；既有持仓、可判定的退出、在途权益和估值仍连续处理。末日信号若需窗外开盘才能执行，标为超出窗口。
- **确定性计算。** 研究任务调用独立的开发实验入口，复用现有模拟账本、日频撮合、成本、权益结算与双基准。采用冻结协议的佣金与最低费用、历史费率、滑点及股息红利税前口径。开发计算直接绑定快照与协议版本，绕开有样本揭示副作用的正式运行和回放入口。开发实验仅使用预设模拟资金与风险预算，不读取也不向助手暴露真实账户持仓、成交、风险预算或数据库路径。计算失败也按任务保存预设、输入引用、失败环节和原因。
- **回执与归因。** 回执列出预设、来源与快照用途模式（`RECONSTRUCTED_RESEARCH` / `STRICT_HISTORICAL_AS_OF`）、名义窗口与有效区间、共同期初状态、各路径净收益与相对双基准的收益、最大回撤、成交笔数、费用和滑点。列明机会数及其分母，分别统计预热、缺数/不可用/冲突和市场条件实际拦截数。同日多项缺口保留各自原因，计算损失天数时按日期去重。估值或执行依据不足时标出受影响的日期、路径和指标。
- **逐笔与逐段复核。** 按信号日列出 E0/E1 入场依据、市场状态、过滤或缺数原因、两组动作，并关联次日模拟成交的日期、数量、价格、费用，或未成交原因。按从建仓至清仓的连续持仓段展示区间、仓位和净值变化，注明期末未平仓段。按两条路径持仓区间的重叠并集划分互不重叠的对照行情段，同一段行情只归因一次。分别标记各自净值最大回撤的峰日、谷日及期间持仓变化。在同一回执列出分段差异及集中情况，供审阅者判断。
- **单次解读与归档。** Roll 先持久化不可变的开发回执并绑定到任务，再沿用阶段 02 的隔离执行边界，通过现有研究尝试把限定于开发期的公开材料和回执引用交给离线执行桩或真实助手。每次有可解读回执的尝试只调用一次。助手引用可定位的指标和交易或区段，说明差异、不确定性与证据缺口。无法形成实验结果时保存失败或缺口；助手失败、超时或取消时仍保留既有冻结回执，同输入人工重试形成新尝试并复用同一冻结回执。研究者按指定尝试和报告版本在任务内审阅归档，归档记录至少保存目标尝试、报告版本、结论类别（动作一致 / 差异集中于单段 / 证据不足 / 多段保留待解释差异）、审阅人、停止或继续的理由及归档时间，任务记录可追到冻结输入、回执、解读和审阅理由。开发报告不具备个股研究档案的发布资格。
- **停止或继续。** 两组动作一致、差异只能由缺数或费用解释、或改善集中于单一行情段时，归档描述性结论并停止扩展。只有多个互不重叠的持仓段均留下待解释差异时，研究者才为下一项仓位对照预先固定仓位规则和计量口径，另行研究。按市场状态分组的日均收益只用于提出假设，用全开发窗事后匹配平均持仓只用于归因；推广性须由新的独立数据评估。

## Testing Decisions

主验收边界为正式 `roll` CLI。通过研究任务发起、重读和归档来检验外部行为，观察冻结公开包、开发回执、报告引用和登记状态。沿用现有研究任务测试对公开输入和失败回执的检查、开发鲁棒性测试对留出期的隔离、冻结实验测试的离线复算与缺失开盘场景，以及计划预览对生效档案版本的核对。

1. **时间截断与只读口径。** 在验收库副本中使用实际取得时间晚于开发期的重建快照，并放入可辨认的后期公告、复盘备注和留出期行情。核对实验过程零外部数据请求、回执保留快照用途模式与实际取得时间而不误拒重建行情，并核对开发清单、逐日信号和实际交给助手的文本不含后期材料。改变留出期的哨兵值后，开发指标和公开材料内容应相同。修改开发期较晚的观测，核查此前信号和成交仍可逐日复现。
2. **共同起点、缺数冲突与恒真自检。** 构造指数比个股更晚完成预热、途中又出现缺日线或冲突观测的行情，手算首个共同信号日及可评价天数。核对期初现金、持仓、净值、末日、四条账本在共同起点盘后的决策与次日开盘撮合时点，以及指数缺数/冲突日 E0 与 E1 均不产生新增买入且既有退出与权益连续处理。保持输入、共同样本及缺数处理相同，仅令 E1 在可评价信号上的市场条件恒真，逐笔成交、费用、权益和逐日净值应与 E0 完全相等。
3. **逐笔核算与离线复算。** 覆盖指数高于、等于、低于均线和数据未知，包含一次被拦截的买入、已有持仓的退出、一次次日未成交及一次权益结算。用可手算的成交、成本和净值核对汇总与明细，检验末日未读取窗外开盘。另起离线进程用冻结输入复算，核对共同样本、覆盖损失、实滤信号数、双基准及全部报告指标。
4. **持仓段与回撤。** 用峰谷已知的净值路径逐条核对 E0/E1 的回撤区间和当时所持股数，以及重叠持仓段按并集对齐的对照归因。分别核查动作一致、只剩缺数或费用差异、改善集中于单段，以及多个不重叠段仍有差异时的归档理由。审阅者应能从同一回执重建分段判断，交易过少或路径不完整时可归档证据不足。
5. **结果交付、失败重试与隔离。** 经同一 CLI 用可控离线助手捕获公开输入，核对首次调用已含可重读的冻结回执、不含私人账户信息且全程只调用一次。分别制造计算失败以及助手失败、超时或取消，按任务与尝试 ID 重读原因及已生成的冻结回执，并核对同输入重试复用同一冻结回执。具备结果时在阶段 02 的真实助手上完成一次江西铜业开发解读，核查报告中的指标、交易日期与区段引用，记录可复验的命令和产物引用。
6. **归档与生产隔离。** 在上述副本记录当前固定盘后输入的 `roll plan --preview` 档案引用，以及正式验收、样本揭示和策略注册表准入记录。审阅归档指定实验报告后另起 CLI 按任务重读回执、解读及归档元数据（尝试、报告版本、结论类别、审阅人、理由与时间），重复相同预览，比对上述记录与实验前逐项一致。运行 `roll experiment verify m0a-jxcc-default` 应仍能离线核验原 M0a 报告。

## Out of Scope

本阶段只交付一组预先选定的 E0/E1 开发对照。参数网格、自动追加实验、下一项仓位对照的实际运行、E2 行业、E3 ETF 资金与 E4 基本面、独立验收、样本揭示、生产准入及 M0b 前向签收各循后续或既有流程。工作台操作由阶段 04 接入。

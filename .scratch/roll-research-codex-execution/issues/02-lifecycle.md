# 02 · 取消、中断恢复与同输入重试

Status: ready-for-agent

Blocked by: 无，可直接开始

## What to build

从正式任务入口控制单次执行的生命周期，查询中途状态，在停止或失去执行者后安全重试。

## Acceptance criteria

- [ ] 研究等待期间可从另一 CLI 进程重读任务、完成独立同库写入，同任务同时只有一个执行者。
- [ ] 在目标平台区分主动取消、超时、执行者异常退出；观察含后代的执行进程树全退出和锁释放，随后同输入立即重试。
- [ ] 取消和最终交付竞争时只保留一个终态；查询不会导致活跃任务中断。重试保留旧日志、产物与清单，补证沿用关联任务。

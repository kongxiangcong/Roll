# 01 · 受限 Codex 研究尝试

Status: ready-for-agent

Blocked by: 无，可直接开始

## What to build

在现有研究任务 CLI 显式选用 Codex，以冻结公开文本取得单次结构化响应，通过任务、尝试和版本重读。

## Acceptance criteria

- [ ] 原离线入口及历史回执兼容；真实尝试记录实际平台、CLI 版本、权限摘要、退出诊断及按尝试隔离的日志。
- [ ] 目标机用公开输入、假私有文件及回环服务核验生效权限；配置不足时拒绝执行，记录配置错误。
- [ ] 通过正式 CLI 区分阻塞缺口、合规草稿、配置错误、非零退出与不合约回包；检查证据来自本清单，草稿只随成功回执提交。

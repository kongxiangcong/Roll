## Acceptance criteria

- [ ] 正式 CLI 调用一次真实 Codex 得到江西铜业待审草稿，重读清单指纹、退出回执及日志。
- [ ] 对照原文抽查事实引用、推断及未知字段。用同一发布入口验证仅签名被拒、事实依据、具名理由和生效计划的字段、确认人及有效期。
- [ ] 记录可重跑的命令、公开输入和实际平台观测，复核文件、回环服务、进程树和同库写入，并完成后端回归。

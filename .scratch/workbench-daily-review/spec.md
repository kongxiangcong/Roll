# 工作台消费已保存的日常报告

在工作台用已有每日合并报告完成持仓复查。保留「研究」和「历史表现」作为独立研究与回测入口。

用户在「日常复查」选择报告版本。复查以指定的 report_id、输入指纹、known_by 和报告保存的上一份报告为准。显示上一份报告的日期、版本与截止时点，区分同日更新和跨日比较。初报没有基准时，明确标明无法比较。打开和切换报告只读取冻结事实，不拉取新行情、不重跑回测、不调用模型服务。各来源继续展示实际时点与范围。

1. **发生了什么变化**。逐持仓比较两份报告中的持仓、已完成日线、财务事实和新闻公告。列出新增或修订证据及其引用，区分已核对无变化、缺失、与没有比较基准。
2. **变化是否影响原持仓理由**。显示冻结的原判断、推翻条件与评估依据。可计算的价格阈值或复查日期给出实际结果。财务或新闻变化与自由文本条件的因果关联交给用户确认，明确显示待判断。
3. **哪些持仓需要复查**。分为需要复查、证据不足、暂无新增复查事项。阈值或日期已触发以及相关事实出现变化时提示复查。缺少原判断、缺少可比的必要来源或有未核对的自由文本条件时保留待确认。仅当明确的检查范围有足够证据且无触发时才允许显示暂无新增事项，并列出依据。此状态属于客观观察。用户的未行动原因使用既有 NO_ACTION 记录。
4. **何时重新判断**。展示价格阈值、复查日期和人工判断条件。在打开或切换到含触发证据的新报告时显示复查提示。条件不明时引导补记。首版提醒在工作台呈现。

记录人可以显式将某条判断的自动检查范围限定为收盘价和可选复查日期。只有报告基准可比、当日完整收盘价可用、所选条件均未触发、且已保存证据未提示其他复查事项时，才在这个限定范围内显示暂无新增复查事项。财务和新闻的覆盖缺口仍单独呈现。已有自由文本判断默认需要人工核对。

从报告冻结的账户及估值在本地计算现金占比、持仓权重和集中度。仅在有适用且同一时点保存的资金授权与风险事实时报告约束结果，缺失或陈旧显示未知。复查读接口返回必要摘要及证据引用，模型无需接触账本。

复用每日报告判断记录的写入口。新判断、复查结论、未行动原因和实际成交关联绑定所选 report_id，复查可关联原 note_id。保存后明确显示成功，历史报告保持原版，后续报告冻结新记录。

验收以报告复查 API 和工作台为边界。覆盖完整复查、未知、触发、版本重放、保存记录后在新报告可读，以及独立回测入口。用隔离测试账户和可控证据，不依赖外部行情或模型。

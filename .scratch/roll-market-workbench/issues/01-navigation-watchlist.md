# 01: 四栏导航与观察池迁移

Status: ready-for-agent

**What to build:** 用户通过「概览、市场、交易与复盘、研究」进入 Roll 投研台。把原首页自选表和联动详情迁入「市场 → 观察池」，以真实观察池作为三个市场主题共用布局的第一个可用实例。

**Blocked by:** None (can start immediately)

- [ ] 从包含自选和持仓的旧库启动，名称、排序、持仓标记和去重结果保留；增删、重排后重新打开，结果一致。
- [ ] 概览可查看正确账本和待办，常规界面不摆单只 ETF 或完整自选表。同步状态和账户切换可用；市场内能切换三个主题，尚无输入时呈现对应空状态。
- [ ] 通过原有概览、个股决策及研究书签可到达相应对象；从观察池行打开详情、交易或研究并返回时保留选中对象。切换主题保持观察交易日，各主题记住各自筛选；观察池从该日行情读取，名单与账户信息注明所属时点。
- [ ] 从浏览器验证桌面和窄屏下的主导航、主题、数字表和详情；原有研究发布、账本隔离与盘后登记可通过原入口使用。

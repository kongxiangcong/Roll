# 03: 宽基 ETF 日报

Status: resolved

**What to build:** 用户从「市场 → 宽基 ETF」同步和浏览指定交易日的本地报表，从篮子合计展开到跟踪指数和单只基金，能够核对每一笔贡献。

**Blocked by:** 01 四栏导航与观察池迁移、02 单只 ETF 实数入库与复算

- [x] 逐只映射版本化对照篮子、有效区间及正式跟踪指数。35 只对照篮子单独命名，159949 在创业板50（399673）组；另一份 123 只清单不可混算。
- [x] 在 11 月 26 日固定真实样本上，35/35 合计 +112.0964733 亿元，展示 +112.10。先按十进制原精度逐只与逐组求和，两个路径在展示舍入前相等。注入已核实主源的次源差异，保留差异记录及原主源合计。详情给出两日份额、当日净值与贡献额。
- [x] 部分数据到齐时明确列有效／应有只数、已知部分合计及缺项原因。全部缺失、有效零值、部分和恰好为零三者可辨。数据日与查看日期分别显示。
- [x] 后台同步逐项更新状态，部分失败后仍能查看最近完整报表及所属日；打开详情和切日期从本地读取。同步不触发研究助手、发布或交易计划。

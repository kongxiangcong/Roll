# 02: 单只 ETF 实数入库与复算

Status: ready-for-agent

**What to build:** 通过正式 CLI 在独立 SQLite 数据目录同步一只 ETF 的相邻两日总份额和单位净值，冻结数据快照后离线读出单日估算净申赎。相同路径以沪深各一只真实基金验收。

**Blocked by:** None (can start immediately)

- [ ] 用交易所日终总份额和扶摇单位净值核对 2026-11-26：510300 增加 1.782 亿份 × 3.9741 元／份 = 7.0818462 亿元；159915 增加 21.01 亿份 × 2.2048 元／份 = 46.322848 亿元。记录样本的真实取得时间。
- [ ] 逐条保留原始值、单位、所属日、来源定位、披露依据和取得时刻。重复同步相同输入及重启离线重放给出同一读数；修改后的输入可另行冻结。
- [ ] 按交易日历取前一交易日。折算时将前日份额转换为当日单位：演示 100 万份经 1 拆 2 后为 200 万份，当日实有 205 万份、净值 1.2 元，估算额为 +6 万元。以十进制复算；必要输入或折算依据缺失时标缺。已确认无变化与无法计算能被 CLI 区分。
- [ ] 取数失败可重试，成功部分可复用，默认付费预算生效。在既有 159915 日期错位样本上追加次源记录，已核实的交易所份额继续入算，次源保留原日期与差异。主源缺失时只选已核实的补源；同级冲突无法裁决时给出缺项。

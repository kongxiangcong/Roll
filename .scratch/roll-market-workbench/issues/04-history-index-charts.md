# 04: 历史报表与指数联动

Status: resolved

**What to build:** 在同一宽基 ETF 报表中查看历史净申赎、资产规模和指数走势，在所选对照版本下按固定名单回看整体、指数和单只基金，标出版本和当时是否已上市。逐日披露规则池由 07 接入。

**Blocked by:** 03 宽基 ETF 日报

- [x] 展示当日、5、21、120、242 个交易日及年初以来的金额与实际起止日、有效／应有基金日。以两只已上市基金、五日应有 10 个基金日为例，仅缺一只基金某日净值时须标 9/10 的部分累计；验证节假日、数据开头不足、成员未上市、缺日和部分覆盖。
- [x] 逐日金额柱与规模曲线可独立核对。用一个份额不变、净值变化的样本证明规模可变而单日净申赎为零。仅缺前日份额时规模仍可算；缺当日成员净值时完整规模曲线断开，部分规模另标覆盖。
- [x] 从整体切换跟踪指数后，K 线和下方申赎图按相同交易日联动；点击一日能看到对应组、基金与当天读数。缺少指数行情或净值时显示缺口。
- [x] 在断网、刷新和窄屏场景下可读已存数据，逐日明细支持横向或等价浏览；进入单基金详情并返回时维持范围与选择。

# 09: 在工作台和日报看到同一份晴雨表

Status: ready-for-agent

**What to build:** 工作台展示当日四维得分、覆盖率、唯一档位及上限，日报冻结同一计算结果。

**Blocked by:** 03, 07, 08

- [ ] 整维计权。验证 0%、35% 不可用，恰好 65% 可归一化；资金缺两融时其余完整得 70%，全齐得 100%。
- [ ] 四档起点 0、25、50、75 分对应上限 15%、35%、60%、80%。全市场广度只取五日上涨家数占比均值；相同市场输入下改变个人跟踪池，市场总分和档位一致。
- [ ] 70% 时冻结，同日补齐数据后工作台为 100%，重开及再次生成均返回原报告和截止时间。

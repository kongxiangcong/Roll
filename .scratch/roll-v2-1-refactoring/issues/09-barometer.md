# 09: 在工作台和日报看到同一份晴雨表

Status: resolved

**What to build:** 工作台展示当日四维得分、覆盖率、唯一档位及上限，日报冻结同一计算结果。

**Blocked by:** 03, 07, 08

- [x] 整维计权。验证 0%、35% 不可用，恰好 65% 可归一化；资金缺两融时其余完整得 70%，全齐得 100%。
- [x] 四档起点 0、25、50、75 分对应上限 15%、35%、60%、80%。全市场广度只取五日上涨家数占比均值；相同市场输入下改变个人跟踪池，市场总分和档位一致。
- [x] 70% 时冻结，同日补齐数据后工作台为 100%，重开及再次生成均返回原报告和截止时间。

## Comments

`roll barometer YYYY-MM-DD` 读取最新工作台；`barometer_history(data_dir, start, end)` 单次 SQLite 读取及整段滚动计算供回测与校准使用。冻结时直接在日报事务内读取同一组市场观察。百分位使用并列中秩，价格读沪深 300 原始收盘，缺交易日对齐为空。四只宽基 ETF 始终使用固定代码及逐日份额变化与同日净值。

`test_v2_barometer.py` 复算票 07 的五组冻结特征及 0/25/50/75/100 分档边界。另建 1260 个连续交易日的确定性序列：缺末日两融时仅趋势 50、广度 75、估值 50 有效，覆盖 70%；显式冻结后补齐末日两融，工作台覆盖 100%、总分 55、均衡上限 60%。变更跟踪池与批量回放均得到同一市场结果，重开及再冻结仍是原 70% 和原截止时刻。在两融窗口中间删除一个交易日也使整维缺失。晴雨表、历史输入及日报相关的 11 个测试通过。测试序列用于核对规则；实际数据覆盖见票 08。

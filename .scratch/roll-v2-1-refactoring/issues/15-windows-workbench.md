## Comments

Windows 无参数启动 `scripts/start.ps1` 会从当前源码构建静态前端，再启动单个 `roll serve` 进程提供三个 React 页面和 FastAPI 接口。已从系统临时目录用脚本绝对路径启动，在默认回环端口实际读取交易日和 v2 页面并停止测试服务。页面构建、浏览器模板检查均通过；1365×900 与 390×844 视口检查通过。市场首页可读取晴雨表且未访问账户接口，空库检查未建立账户事件表。

一份 Playwright 配置运行 Chrome、真实 HTTP 服务、CLI 与隔离 SQLite。联网一轮使用正常扶摇来源，同步 2025-07-28 至 08-01 三只股票及沪深 300，各五行。浏览器建立零元基线、转入 5,000 元、买入江西铜业 100 股（20 元、费用 5 元），确认回执与冻结余额均为 2,995 元。随后下载 JSON、重新载入并重读报告、运行双组合回测及历史和前向校准。此 UI 测试中的 ETF 价格为确定性验收数据。另一次无扶摇凭证的同配置运行验证来源失败时仍可完成本地工作流。

`sync --daily-only` 从 CLI 重新取得相同四标的行情；`report read` 的原截止时间仍为 2026-11-25T01:20:17.837580+08:00。`backtest --start 2025-07-30 --end 2025-08-01` 覆盖三个交易日。并发测试从另一 CLI 进程和 Web 对同一交易日首次冻结，逐字段比较原结果与 JSON，及 Markdown 的冻结截止。完整后端套件 36 项通过，测试客户端上游有一条弃用提示。

另将这份独立账本导出的 Markdown 交给本机 WorkBuddy 已安装的 Markdown guest，在阻断外网的无头浏览器中通过其宿主协议接收 `contentLoaded`，实际渲染正文 1768 字符并核对同一截止时间。这项验证覆盖 WorkBuddy 阅读组件，本次没有发起 AI 对话。

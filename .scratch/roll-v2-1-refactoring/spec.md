# Roll v2.1 · 个人盘后工作台重构

Status: resolved

## Problem Statement

我需要在 Windows 本机收盘后更新行情、核对真实账户镜像，并看清哪些风险值得自己处理。v0 的资格审批、研究后继链和常驻进程介入了这些日常操作。数据缺一项时，我仍需要能读的日报。过几天打开它，我需要看到当时掌握的事实，也要能单独判断晴雨表控仓在历史上是否有效。

## Solution

用单进程、离线优先的工作台串起记账、按需同步、晴雨表、风控和回测。先用独立 v2 入口跑通空账本、两项真实行情和冻结日报，随即切换并清理 v0。随后加入四维晴雨表、单 ETF 控仓回测和三个页面。用户通过同一套业务规则获得网页结果及供 WorkBuddy 读取的 JSON 或 Markdown 报告。

## User Stories

1. 作为账户使用者，我希望从空账本录入资金和实际成交，以便重启后核对现金和逐证券持仓。
2. 作为账户使用者，我希望导入成交 CSV 并核对结果，以便批量记账。
3. 作为盘后使用者，我希望一键同步股票、指数和 ETF，以便查看各自最近的有效交易日。
4. 作为盘后使用者，我希望同步失败时仍能读取已有历史，并看见缺项和最后成功日期，以便判断今天能用哪些数据。
5. 作为复盘者，我希望分别查看原始成交价和口径一致的复权指标，以便解释除权前后的价格变化。
6. 作为复盘者，我希望按当时已披露的财报版本重放风险灯，以便还原更正公告前的判断。
7. 作为盘后使用者，我希望看到市场总分、四维得分、覆盖率和唯一仓位上限，以便理解当天的档位。
8. 作为盘后使用者，我希望缺数时看到具体缺项，以便识别无法判断的交易日。
9. 作为跟踪池维护者，我希望一次编辑 YAML 即可在下次同步应用股票和风控参数，以便维护自己的观察范围。
10. 作为账户使用者，我希望个股卡显示行业强弱、止损提醒和财报灯，以便逐股核对风险。
11. 作为账户使用者，我希望总仓位超限时看见金额和百分点，以便自己决定处理哪些持仓。
12. 作为账户使用者，我希望单票超限时看到受可卖数量约束的参考股数，以便在券商端自行处理。
13. 作为日报读者，我希望显式生成当天唯一的冻结报告，以便断网、重启或后续补数后复查原貌。
14. 作为回测读者，我希望用同一只 ETF 对比晴雨表控仓和买入持有，以便看清扣费后的净值、回撤和换手。
15. 作为回测读者，我希望缺信号日的持仓继续计价，以便回撤覆盖整个持有期。
16. 作为校准结果读者，我希望看到同档历史上涨频率、成熟样本数和 Brier 分母，以便理解估计依据。
17. 作为前向统计读者，我希望只评价当时实际冻结过的预测，以便区分真实记录与历史回放。
18. 作为本机使用者，我希望按需启动网页或命令行并导出日报，以便关机期间也无需维持后台任务。

## Implementation Decisions

目录布局、模块职责、SQLite 数据归属及分周装配顺序按已确认的 [Roll v2.1 代码组织方案](../../docs/design/architecture/roll_v2_1_code_organization.md)执行。

### 交付与切换

- Windows 单进程、单 SQLite 库，命令行与 Web 共用核心库。保留十进制账本、成交与现金账户事件、成交 CSV 导入和对账，以及可复用的交易日历、整手、T+1、费用和统计计算。命令行提供同步、报告、回测、启动服务四项操作。网页收敛为今日晴雨表、持仓与跟踪池、回测与校准三页。
- 首周走独立入口和新建空账本。首周三项验收全部通过后，在同一阶段归档 v0、切换默认入口、按清理矩阵删除旧入口及依赖。清理后继研究、资格审批、模型审阅、废弃行情采集与静态原件、常驻 worker、旧页面和验收脚本，收敛依赖锁及浏览器测试配置。切换说明在 README 明示 v2 废止 ADR 0003 的 G1–G7、资格审批和资金授权门禁。保留模块化单体、按需分析及历史重建的时点边界。

### 行情、财报与配置

- 首版使用盘后日线。同步按类型直接调用固定来源。扶摇提供股票及指数日线和复权因子，AKShare 提供 ETF 行情、份额、净值及所需两融、广度、估值和财报数据。成功项增量更新，失败项显示最后成功日期并保留历史。跟踪池与个股风控参数由 YAML 单入口编辑，下一次同步生效，网页只读。
- 股票存原始 OHLC 和因子，按同一因子序列及各自锚点动态计算前后复权价，MA 与 ATR 使用一致锚点。成交回测读原始开盘价。普通补数可回看五天。指数取原始点位。ETF 份额变化换算净申赎额前核实单位净值、单位及日期。
- 财报按报告期、版本及该版本自身披露日追加保存，更正前的回放读取当时已披露的最新版本。保留营收同比、扣非净利同比、单季经营现金流和资产负债率。累计现金流按财年换算单季，一季度从本年起算。营收同比低于 −10% 且扣非净利同比低于 −20%，或连续两个相邻单季经营现金流为负且最新季资产负债率高于 75%，触发红灯。

### 晴雨表和风控

- 趋势与波动占 35%，资金占 30%，全市场广度占 20%，估值占 15%。广度取最近五个交易日每日上涨家数除以上涨与下跌家数之和的均值。行业 ETF 相对强弱只进个股卡。市场总分、仓位档和校准归档独立于个人跟踪池。
- 第二周实现晴雨表前，用一张表冻结必需输入、单位、窗口、预热长度、分段线性评分节点、端点、插值、超界处理及组合公式。估值分位 70%–85% 的映射须连续。参数选择限于 2020–2023 定权期资料。2024–2026 至实际可得最后一个完整交易日仅作样本外检验，接受无单调关系的结果。
- 各维完整且预热充分时计入全权重。覆盖率达到 65% 后，以有效维度加权分之和除以覆盖率。低于门槛时列缺项、覆盖率和“今日晴雨表不可用”，总分和总仓位上限留空。单票配置上限仍独立适用。
- 分数自 0、25、50、75 起依次进入防守、谨慎、均衡、进攻档，100 属进攻档。唯一总仓位上限依次为 15%、35%、60%、80%。真实账户高于上限才提示超限金额和百分点，标的由用户选择。单票超限才按计价价格、整手规则和账本确认的 T+1 可卖数量折算参考股数。缺少所需输入时指出原因。卡片显示收盘价交易日、账户确认时点、行情截止时间和过期状态，支持个股 ATR、近 20 日低点及财报风险提醒。实际委托、成交和记账由用户处理。

### 冻结日报、回测与校准

- 同一交易日首次显式生成日报时冻结结果及截止时间。重复生成返回原报告。工作台可继续同步，补数、改配置和追加成熟结果均保留原日报。首周日报即可显示覆盖不足。
- 回测固定为现金加 510300.SH，对照为买入持有 510300.SH，共用行情与费用口径，报告历史缺口。收盘首次得到有效档位或相对上次有效档位换档时，于次日原始开盘价按档调仓。同档允许漂移，缺信号期间持有原份额并逐日计价，恢复后和上次有效档比较。报告扣费净值、年化收益、最大回撤、卡玛比率和换手。
- 预测事件为沪深 300 自 t 日收盘至第 20 个后续交易日收盘收益大于零。沿用四个仓位档，冻结预测日、档位、同档已成熟样本数和当时上涨比例 p。空档概率留空。有档无概率的历史样本成熟后进入同档频率，其自身排除在 Brier 分母外。Brier 为已成熟且有预测样本的 (p−y)² 均值。
- 前向预测仅在交易日当天显式冻结有档位和概率的该日日报时登记一次。结果成熟后追加标签，统计期并列交易日数、实际登记预测数和已成熟预测数。仅同步、重开日报和历史回放均不增加前向样本。

## Testing Decisions

以已确认的用户操作作为主验收入口。通过 v2 正常入口操作独立本地账本、同步并读取报告，用公开可见的价格、余额、档位及截止时间断言行为。参考现有账本与 CSV 导入应用测试、日报冻结与重启测试、部分数据源仍可出报告测试，以及 20 个交易日成熟标签测试。确定性输入用于边界和回放，数据源验收使用真实响应。浏览器通过一份端到端配置检查正常工作流。

| 场景 | 操作与可观察结果 |
|---|---|
| 首周切换门槛 | 三项同时通过。① 新账本录一笔资金和一笔成交，重启后现金及逐证券数量相符。② 真实同步江西铜业 600362.SH、沪深 300 000300.SH，记录实际日期范围，股票分别核对原始和前复权，指数请求省略复权参数。③ 显式生成带截止时间的日报，列出账本现金持仓、两标的最近收盘价格或点位及各自交易日、取得和缺失的数据。仅给能验证完整且预热充分的维度计权，断网后重读内容一致。 |
| 来源验收 | 用真实除权事件比较跨除权增量同步与空库全量重建，在同截止日及锚点逐日核对复权 OHLC、MA、ATR，并独立核对原始开盘价。510300.SH 行情、份额、单位和覆盖按 ETF 单独验收。 |
| 财报时点 | 同季首发前不可见、首发后见初版、更正后见新版。回放两次披露之间的日期恢复当日财报灯。缺季不能满足连续两季条件。 |
| 覆盖率与配置 | 固定整组输入及唯一输出，覆盖 100%、恰好 65%、仅趋势 35%、全缺 0%。资金缺两融而其余完整得 70%，总分按 0.70 归一化。换跟踪池应改变个股卡，市场总分、档位及归档一致。 |
| 仓位提示 | 均衡档实际仓位 55% 和 60% 均无提示，65% 显示超限 5 个百分点及金额。单票参考股数受可卖量约束。 |
| 同日补数 | 70% 覆盖时冻结，补数后工作台为 100%。重开和重复生成均返回 70% 及原截止时间。 |
| 回测执行 | 依次输入均衡、均衡、不可用、均衡、谨慎，仅首次均衡和最后谨慎触发次日调仓。持仓漂移到 59.6% 时同档不交易。缺数日的盈亏进入净值和回撤。 |
| 校准冷启动 | 首次防守无同档成熟样本，p 为空。该标签若为上涨，第二次预测时仅此样本成熟，则样本数为 1、p 为 100%、历史 Brier 分母为 0。第二次成熟后分母为 1。 |
| 前向与回放 | 对仅同步、当日有预测的冻结、重复生成及事后回放分别核对前向计数，只有当日首次有效冻结增加一条。第 20 个后续交易日收盘取得结果后才计入成熟分母。 |

## Out of Scope

旧账户迁移及迁移样例、长期双轨、盘中报价、前复权缓存、可插拔行情基类、备用源切换、ETF 份额 CSV 补录、网页编辑跟踪池、同日日报多版本、自动登记前向快照、账户级卖出分配和券商下单均不属于首版。回测排除跟踪池组合、ATR 止损策略、MA20 择时、恒定 50% 对照和第二套概率分箱。首周验收排除 ETF、完整晴雨表和四标的六年历史限时拉通。

## 实施与验收记录

2026-11-25，15 张实施票均已解决，默认入口切换到 v2。集成分支为 `codex/roll-v2-1-refactoring`，v0 保存在 `archive/v0-legacy`（`eefe2c57`）。工程与规格审查的修复位于 `6402f6ae`，两组复审均已通过。最终集成分支在 Windows 宿主通过全部 42 项后端测试和 2 项浏览器端到端测试。以下验收产物保存在本机工作区。

- Windows 原生 Chrome 通过同一份 Playwright 配置跑通同步、记账、回测、冻结、导出和重读。真实扶摇行情单独核对。覆盖率 70% 冻结、补数到 100%、重读仍为 70% 的页面用例使用确定性输入。
- 首周离线冻结见 [JSON](../v21-acceptance/week1/frozen.json)。最终联网浏览器流程的[冻结日报](../v21-acceptance/browser/final-report.md)由本机 WorkBuddy Markdown 阅读组件在禁用外网的环境中渲染，并核对冻结截止时间。
- 独立真实行情库覆盖 2020-01-02 至 2026-11-24，510300.SH 原始日线共 1,670 个交易日。沪深 300 实得 1,211 行，四只宽基 ETF 的单位净值各补取 330 日。ETF 份额存在请求超时，历史广度与日频估值也有缺口。2020–2023 的 970 日及 2024 起的 700 日均未达到 65% 的整维覆盖率。控仓组全程持有现金，历史 Brier 分母为零，当前数据无法评价控仓效果。[回测明细](../v21-acceptance/history-confirmation/backtest.json) · [历史校准](../v21-acceptance/history-confirmation/calibration.json)

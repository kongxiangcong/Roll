# Ticket 19：Choice 对旧 PIT 档案的补充价值

核查日期：2026-10-10（Asia/Shanghai）。本轮最终范围遵从用户纠正：“考虑寻找补充旧 PIT 档案，而不是现在向前积累”。仓库当天此前的前向路线仅用于理解现状；不把它当作禁止本轮调研的约束，也不修改既有采集任务、数据库或 ticket 状态。

## 结论

**Choice 有充分的历史字段覆盖，值得作为历史状态、权益及旧披露材料的补充渠道；公开证据尚不能确认普通金融终端／EmQuantAPI 可以提供 ticket 19 所需的旧量价 PIT 档案。**

重点未决项是：历史某个知识截止时点，曾经发布／可得的 RAW 日线具体值，以及更正前后版本和实际发布时间。今天查询到旧交易日的数据，即使不复权、带公告日或可选择历史状态，也不能自动证明这些值就是当时提供的版本。未知不能写成供应商绝对不支持。

若目的是解决旧 PIT，下一步应先核实 **Choice 数据库／定制数据交付** 能否提供历史原始版本或发布档案；不要仅凭终端含“历史行情”或“回测”就认定门槛已满足。官方确认有独立数据库及定制服务，但没有公开承诺这些服务提供所需 PIT。[Choice 数据服务](https://choice.eastmoney.com/product/datacenter)

## 能补什么，不能据此证明什么

| 材料 | 官方字典证据 | 对旧 PIT 的判定 |
| --- | --- | --- |
| 历史 RAW 日线 | `csd` 行情字典有 OPEN/HIGH/LOW/CLOSE/VOLUME/AMOUNT；Python 手册支持日序列、不复权查询 | 能补日期和值的覆盖与交叉核对；未证实旧发布版本、修订链或知识截止查询 |
| 历史停复牌和 ST | `TRADESTATUS`、`ISSTSTOCK`、`ISXSTSTOCK`；状态说明列出正常／复牌／连续停牌／当日与盘中停牌等 | 比仅当前状态线索更完整；仍需核验江西铜业实际窗口、枚举和历史发布依据 |
| 涨跌停 | `LIMITUPPRICE`／`LIMITDOWNPRICE` 是价格；`HIGHLIMIT`／`LOWLIMIT` 是是否触及限制的指标 | 可补执行依据，不能混用价格与布尔／分类指标，也不能反推当时可得性 |
| 分红送转、配股 | 实施公告／登记／除权／派息／红股上市日期；配股价格、比例、公告与上市日期 | 可找旧事件及对应原公告；事后整理的完整事件表不能提前成为旧预测输入 |
| 部分旧财报版本 | A 股财报字典 `Type=5/6` 分别对应合并／母公司“更正前”，另有实际披露日期及披露安排变更字段 | 有限的旧版本线索，不能笼统说 Choice 毫无旧版能力；不等于每次修订全链，也不能外推到本票量价数据 |
| 历史公告／资讯 | 官方有资讯查询，公告字段时间存在展示日期口径 | 原文及原披露记录可成为逐项旧证据候选；展示日期不能直接当精确发布时间，亦未证明完整保留撤回和替换版本 |
| 数据库／定制交付 | 官方独立数据服务支持多种数据库及定制交付 | 最值得核实旧行情档案的渠道；公开页不提供 PIT 保证或具体历史版本 schema |

## 旧 PIT 的具体未决项

1. **旧量价版本**：公开 `csd` 日期范围选择的是行情日期；没有确认能选择“截至过去某时刻当时发布的版本”。RAW 只是不复权，不保证未修订。
2. **历史发布与可得时点**：交易日、财报报告期、登记日、除权日和公告展示日期具有不同含义；需要档案／上游记录证明当时已可得。现在下载原件的取得时间须另存，不能倒填。
3. **修订链完整性**：需要能识别首次版、修订版、生效／发布时刻和对应原件；仅有当前值或“更正前／调整后”两个类别未证明完整链。若供应商保证某类 RAW 行情从首次发布后从未修订，应给出可审计的范围、规则及依据，不能由我们假定。
4. **实际交付**：尚未用已授权账号验证江西铜业样本、历史覆盖、缺失和停牌行语义；普通终端使用权不自动等于 API／数据库档案权限。[官方 API 权限说明](https://quantapi.eastmoney.com/AIGuide/PromotionPage?from=web)
5. **研究实现和统计支持**：供应商给到合格档案后，仍由 Roll 接通真实来源准入、合法 DEV/CAL、成熟标签、训练校准及冻结；资料补齐不自动完成 ticket 19 或取得正式资格。

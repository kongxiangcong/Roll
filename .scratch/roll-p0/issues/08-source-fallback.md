# 08: 换源、局部降级与证据修订

**What to build:** 主源不足时用户能看到其他可比来源取得的同一事实、仍可用的部分与受限原因，并可追踪后续证据修订及离线重放原运行。

**Blocked by:** [07 · 单源日线与报价证据闭环](07-market-evidence.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-31、AT-42、AT-78、AT-81。

**References:** [规格](../spec.md) ID-06—08、ID-17—20、Testing Decisions 1、4、6—7 与后端/外部组件、运维容量组合；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 至少两条实际取得事实的路径通过统一契约使用；指定工具不可用时下游保持相同事实格式并记录实际来源。切换逐项核对对象、日期、单位、复权和字段定义，转换有依据，不可比就明确阻断而非静默拼接。
- [ ] 缓存暴露真实采集/可得时点，包装或重试时间不能刷新数据年龄；用途相关新鲜度与缺口明确，不能给全部材料套同一任意分钟门槛。
- [ ] HEALTHY、DEGRADED、BLOCKED_NEW_RISK、MONITORING_UNAVAILABLE 表达受影响用途；可选材料缺失时已知部分继续，必需输入缺失时暂停对应能力，不删除特征后冒用原模型资格。
- [ ] 联网补查异步并有停止条件；失败返回证据与缺口，不补值、不吞异常为成功。与 02 联验补查阻塞/超时期间实际账户确认仍可完成，记录相同环境下确认 P95 ≤ 2 秒和外部耗时。
- [ ] 后续事实、补录与修订生成新依据和依赖失效记录；旧结论、原运行输入与原始材料保持可查询，后取证据不伪装成当时已知，未解决依赖不继续被引用为有效依据。
- [ ] ReplayRun 使用原运行归档和版本重现结构化事实/状态，不重新联网覆盖输入；更新、重新取数或再次生成均是新的关联运行，原运行审计可解释前后差异。
- [ ] 从 FastAPI、真实 SQLite/归档与页面验证转换、降级、修订和重放；分别保存真实换源运行、固定错误响应及确认并发证据。只参考 LangAlpha 的证据依赖方法，不迁入技能或 approved 资格语义；实际模型依赖在后续调用票联验。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

# 30: 盘后唯一前向归档与研究终点

**What to build:** 程序运行且冻结实验可运行时，在预登记盘后检查点归档一次预测或明确缺失，记录实际前向起点、最迟终点与成熟结果，让用户看到真实研究进度。

**Blocked by:** [15 · 按需与盘后观察、覆盖时间线](15-on-demand-review.md)；[20 · 冻结研究政策与连续影子](20-policy-continuous-shadow.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-58、AT-88。

**References:** [规格](../spec.md) ID-09、ID-14、ID-15、ID-16、ID-18；Testing Decisions 的主要边界 1、2、5、6 及“时点与有限研究”；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 程序运行、检查点合法且冻结实验具备所需完整输入时，由一个后台进程结合 SQLite 持久化任务调用共同应用用例，保存预测、动作或拒绝原因及实际依据，不引入 DAG 或分布式队列；不要求交易时段常开，条件不满足保留具体缺口，不自动改成合格样本。
- [ ] 确认性样本身份按实验及预登记检查点/交易日固定，独立于任务键、账户版本和数据快照；重复触发、重试、新快照或手动点击可有关联记录，但不能增加确认性样本或 PASS 判定点。
- [ ] 首次成功持久化冻结模型的实际前向预测才登记 forward_started_at 和 forward_deadline；创建实验、部署、导入历史或测试 fixture 均不能启动真实计时。失败或崩溃不能留下无实际归档的伪起点。
- [ ] 按冻结时区、自然月加法/月末及截止边界计算不晚于起点加三自然月的终点，不能用 90 天替代；缺席、重试、换取证后端和不利结果不延期，预登记较早停止条件保留可追溯依据。
- [ ] 停机缺日不补预测；后来行情仅能补事实或按政策结算既有预测，恢复不重置影子。拒绝机会也在结果发生前记录，成熟后反事实诊断不混入连续策略收益。
- [ ] 终点到达时按协议关闭本轮采样/判定边界，已成熟与未成熟项分列；不足形成 INCONCLUSIVE 及实际审阅状态，未完成验证/审阅仍标明缺口，不提前判未成熟结果输赢或为其自动续期。
- [ ] 经 FastAPI、真实 SQLite/文件和必要真实进程故障验证唯一归档、提交边界与恢复；用可控时钟覆盖月份、月末、截止及标签成熟边界。工程模拟时间只证明算法，实际首次归档及真实终点分别由 32、33 执行留证。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

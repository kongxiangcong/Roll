## Acceptance criteria

- [x] 建立并实际使用 DataRequest 和 RetrievalRun：对象、日期/截止、用途、字段与技术限制随请求保存，运行记录实际来源/工具、状态、证据和缺口；为 11/12 提供相同事实与运行契约，不要求生成式后端先完成。
- [x] 至少一个真实来源贯通请求、原始响应先可靠归档、内容指纹、规范化事实、SQLite 快照引用及可归档 Parquet；页面可查看原始依据和转换，正式事务不引用尚未可靠保存的必需附件。
- [x] 按 PRD 6.1 登记并逐组验收 P0 数据：当前名单与基准的原始 OHLC/成交量额及调整事件、实际可得报价、预先固定宽基及少量相关行业指数、当前停牌/风险警示/价格限制/除权事项，以及名单公司的公告、业绩和重大事项。指数只作背景/基准，相关性与选取范围可查；缺失逐组、逐用途显示，不以日线/报价连通代替其余数据组通过。每组保留实际来源样例与归档回放；当前异常识别可用固定样本，不要求采齐全市场历史状态。
- [x] 名单事件通过实际取证 → 原始依据 → 规范化事实 → 确定性结构化检查 → Observation/RiskAlert 查询和页面的完整路径，保存对象、事件类别、时点与精度、来源/依赖、严重程度、未知项和待处理事项；事实与推断区分，未确认到账仅生成待核事项，不能产生未经授权的交易判断。普通记录单源通过基本检查即可，限于名单和必要市场背景，不扩展全市场新闻流或 P1 的扩展公告抽取；不以 11/12 后端接入为本票前置。
- [x] 登记实际来源权限、对象范围、粒度、历史深度/截断、单位/复权、时间戳/延迟与失败语义；小样例可达只证明该范围，不标为长期稳定或所有市场覆盖。
- [x] 原始可交易价与调整价分开，转换股/手、元/万元有来源依据；空值、真实零量、占位、停牌、休市及获取失败明确区分。公司行为导致原价跳变不误作普通暴跌，账户权益仍待用户确认。
- [x] 外部事实分别保存事件/交易日、获取及实际可得时间和时间精度；日期粒度公告不补零点，报告期不当披露时间，批次时间不证明每只证券新鲜，未来公告不得进入过去输入。
- [x] 日线保存 completion_state，未完成输入不进入完整日线模型；普通盘前/盘后记录有一个可追溯合格来源即可使用，完成基本口径检查后不强制第二来源或多个 Agent。
- [x] 若摘取 DSA 请求映射，登记具体组件、固定版本 ce364e457aab288863a5707e7b3df79786ad07f2、MIT 许可/版权、实际必要依赖和语义改造；不继承补 OHLC/零量额、默认全市场报价和无复权标记切换。按规格资产表逐项适配，未采用也记录结论。
- [x] 经 FastAPI、真实 SQLite/归档与页面验证上述路径；保存各数据组实际外部取数证据及固定响应的单位、日期精度、缺失、截断、未完成和历史时点测试。事件样例覆盖实际已知时点、仅日期的公告、来源缺失与后续修订，旧证据/观察保留版本关联而非覆盖；08 联验修订后的依赖失效，14 联验关键复盘冲突，15 联验按需/盘后客观风险展示，均由责任票接入实际下游后完成。重放只读原归档，记录环境/版本和实际覆盖，后续模型票复验必需输入边界。

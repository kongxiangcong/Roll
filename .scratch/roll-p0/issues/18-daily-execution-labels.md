# 18: 日线执行模拟与成熟标签

**What to build:** 对协议规定的交易事件与执行方案生成可重放的日线模拟结果，在研究页面分别查看成熟、未成熟和不可判断的标签及执行依据。

**Blocked by:** [17 · 研究设计登记与全部尝试留痕](17-research-protocol.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-35、AT-36、AT-37。

**References:** [规格](../spec.md) ID-06、ID-10、ID-14、ID-15；Testing Decisions 的主要边界 1、5、6 及“时点与有限研究”；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 从研究入口指定已登记协议和归档日线后，保存事件定义、执行价/允许范围、退出规则、成本、输入版本、结果和成熟依据；查询可回到所用原始证据，重放不重新联网替换输入。
- [ ] 同日涉及多个条件而没有盘中顺序时，按冻结的保守或区间口径处理或标记不可判断；不择有利路径，不把触价等同成交，不要求补造分钟历史。
- [ ] 模拟包含未执行、错过、部分执行、可卖日期、费用和无法成交；至少验证下一交易日开盘/收盘、再延迟一日、超出价格范围不成交的预登记压力方向。只有真实归档报价支持时才另测下一可观察价格。
- [ ] 每个预测保存 label_matures_at 或预登记提前结算规则；二十日预测第二天上涨仍未成熟，未成熟结果不评分、不训练，也不被排成独立成功样本。
- [ ] 历史规则或执行状态不足按预登记缺失政策处理并标明局限，不按输赢删除样本；模拟对用户真实照做分布未知的限制随结果可见。
- [ ] 通过 FastAPI 应用入口、真实 SQLite 和隔离归档验证成熟边界、价窗/延迟/费用、同日路径歧义及同输入结构化重放；只为难以定位的日历或计算边界补少量纯计算测试。
- [ ] 页面与证据明确这些协议样例和回放是工程验证，不能作为真实 G7；结果保留 HISTORICAL 或研究用途，不写真实账户、正式动作或正式收益。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

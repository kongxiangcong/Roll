# 22: 独立风险回退政策

**What to build:** 为一个确定性降风险政策单独登记依据并验证，在研究/测试视图展示触发条件、可行数量与限制；没有合格政策时保持风险事实与待处理状态。

**Blocked by:** [10 · 资金授权与默认关闭的正式能力](10-funding-boundaries.md)；[17 · 研究设计登记与全部尝试留痕](17-research-protocol.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-70。

**References:** [规格](../spec.md) ID-10、ID-11、ID-12、ID-14、ID-16；Testing Decisions 的主要边界 1、5、7；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 使用 17 的协议与证据记录，单独冻结政策依据、适用范围、触发规则、数量算法、资金边界与恢复条件；资金边界来自用户已有授权，不替用户猜测金额。
- [ ] 政策的验证证据覆盖实际数据口径、规则/数量计算、授权边界、跳空/延迟/不可成交等压力执行和在线一致性；记录明确通过、失败或不足依据，不以保守措辞代替验证。
- [ ] 本政策不要求收益候选已产生正面结果，也不依赖其预测优势；同时不得作为收益模型免除 G3、G4 或 G7 的通道。两类政策的协议、结论、范围与资格依据可区分。
- [ ] 研究/测试入口可查询触发、允许数量、未知可卖量或规则不足等受限原因，结果持久化并可重放；收益模型停用且没有合格风险回退政策时只展示事实/待处理状态，不默认 HOLD、判断型 WAIT 或一律卖出。收益模型单独停用不使独立合格回退失效；正式调用的正向路径在 25 按政策自身资格验收。
- [ ] 本票不签发正式能力；后续仅由 24 的受控服务按这份独立政策的证据和当前条件检查资格，由 25 在动作链中使用。研究结果不能直接写真实账户或产生执行意向。
- [ ] 经 FastAPI 应用入口、真实 SQLite 和研究页面验证已知/未知规则、授权缩小、数量不可计算与压力结果；保留 AT-70 的服务端拒绝与可见状态证据，工程合成凭证只在隔离测试使用。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

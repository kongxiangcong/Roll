# 09: 账户估值与现金流调整绩效

**What to build:** 用户查看净资产、费用、已实现/未实现损益和基线以来的收益，能分清现金流、成本及每只证券报价的时点与陈旧状态。

**Blocked by:** [04 · 确认资金与权益变动](04-cash-corporate-actions.md)；[07 · 单源日线与报价证据闭环](07-market-evidence.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-50。

**References:** [规格](../spec.md) ID-04—06、ID-13、ID-17、Testing Decisions 1、3、6 与财务守恒组合；[PRD](../../../ashare_market_decision_prd.md) ACC-15—18、12.1 RiskAuthorization、附录 B 损失触发口径；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 从真实账户事件和有依据的原始价格计算当前资产、费用与已实现/未实现损益；页面和查询展示计算口径、账户确认时点及各证券报价时点，不混用研究调整价作实际成交计价。
- [ ] 券商冻结金额已经属于现金资产，不从净资产重复扣除；券商可用、可取、冻结与账面余额仍分列，不能用其中一个替代所有资金口径。
- [ ] 账户估值按已确认现金账面余额加持仓数量乘对应报价计算，其他已确认应收/应付按 04 的待结算记录另列金额、状态与依据，明确与所展示估值的关系，不提前计作已到账现金或券商可用资金。结算后现金与未结余额按关联事件衔接，待结算和到账不能重复计价或重复贡献收益；覆盖部分结算、税费应付、到账更正和陈旧报价组合。
- [ ] 部分卖出及费用后补的成本分摊可重放，精确金额与数量守恒；未知费用、未知基线前历史保持待核或未知，不伪造全历史收益。
- [ ] CASH_IN/CASH_OUT 不计入投资收益；明确选定并说明现金流调整方法，用追加现金、撤出现金、分红与利息到账组合证明金额与百分比收益不会因净投入虚增，利息也不会误增外部净投入。自基线核对净资产变化、期间净投入与已知范围总盈亏，待结算项使用明确且一致的处理口径。
- [ ] 停牌、无报价或异步报价按实际时点显示陈旧/缺失状态，最近价仅作为显式陈旧估值；无法计算的部分不得填零或用错误来源拼成看似准确的总额。
- [ ] 为资金损失判断提供可查询、可重放的有版本事实：账户及所请求范围、基线/截止时点、期间外部现金流、已实现/未实现损益、收入/费用、待结算口径和估值新鲜度；不能把当前收益率或未知部分直接当剩余额度。10 负责冻结授权损失公式与输入契约，25/27 接入这些实际事实验证预算/暂停，本票先完成事实与版本验收，不新增对 10 的执行依赖，也不自行代填用户金额或签发资格。
- [ ] 在 FastAPI 应用入口使用真实 SQLite/归档，验证资金和成本守恒、部分卖出、现金流、未知历史及陈旧估值；关键持仓页面可核对同一结果。记录输入、预期、实际与口径版本，重放结构化数值一致。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

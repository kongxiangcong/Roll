**What to build:** 在研究入口登记协议、候选和全部尝试，查看真实数据覆盖、封存证据访问及冻结缺口，使后续研究在事先确定的范围、方法和结束规则内进行。

## Acceptance criteria

- [ ] 用户可登记、查询并比较协议及后继版本，SQLite 保存协议身份、状态、候选与数据/代码指纹、全部尝试和封存访问记录；页面列明未完成字段，不把草稿登记称为完整实验已冻结。
- [ ] 实施代理依据实际数据覆盖确定并留证 M0 的主要目标、最小改善、研究范围、训练/校准/封存窗口、必要基线、支持度、统计依赖与判定方法；不要求普通用户选择统计参数，不虚构当前接口或历史数据已通过。
- [ ] 协议明确成本、人工执行/延迟、缺失处理、标签成熟、技术限制、检查点及最长三自然月停止规则；默认只有一个最终确认性 PASS 判定点，更多可判 PASS 的查看必须预登记并验证覆盖全部查看的方法。
- [ ] 预登记 G5 的跨时间段、成本压力、延迟和参数邻域检验及适用范围依据；看过结果后缩小范围不能使原协议改判通过，受限范围须登记关联新实验。具体窗口、压力幅度、方法与阈值由实施代理依据实际覆盖提出并留证，不在本票猜数值或让用户临场选择统计参数。
- [ ] 预登记正式使用期间对实际人工延迟、成交与费用、数据漂移及成熟结果的监测项、适用范围、方法/阈值和检查点，区分日常运行/资金风险检查与统计结论复核；未成熟结果不评分或学习。监测政策或方法变更须有修正依据与后继版本，不能临时调阈值、增加可判 PASS 的查看或改写原结论。
- [ ] 候选、特征、期限、阈值、提示词、人工筛选、失败和中止均可追溯；故意漏掉失败尝试会使完整性检查不通过，不能只提交最佳结果。
- [ ] 封存区间访问形成持久化记录；看过结果后改参数不能把同区间重命名为独立最终检验。未经登记的可选停止被拒绝并留偏离记录；新实验保留前序关联，不覆盖旧协议。
- [ ] 今天名单的回溯明确标为条件性研究，适用范围扩展不自动继承资格；收益预测模型与独立风险回退政策各自的证据要求分列。缺少候选、代码、数据或政策指纹时拒绝完整冻结；19 冻结模型，20 在首次确认性检验前完成全部协议冻结。
- [ ] 经 FastAPI 应用入口和真实 SQLite 验证登记、缺项拒绝、完整尝试和封存访问；网页可查看缺口及限制。记录主责任场景的输入、预期、实际和证据；协议登记完成不算研究 PASS 或前向启动。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

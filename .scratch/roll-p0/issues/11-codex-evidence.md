## Acceptance criteria

- [ ] 调查实际本机环境与官方接入能力，锁定 SDK/runtime、模型、认证方式、工具和必要桥接版本；完整 Codex 任务运行时接入共用 DataRequest/RetrievalRun，不将普通聊天补全或单次连通标作完整任务接入通过。
- [ ] 常规接口缺失的事实可由受控任务实际查找网页或其他依据；返回经宿主时间/口径检查的证据候选，保存原文/原响应、链接、获取时间及运行指纹，无依据时明确缺口。
- [ ] 生产任务使用独立工作目录、明确配置与允许工具，只收到必要对象和问题；不自动装载开发 AGENTS、SKILL、个人技能或参考仓库指令，不建设插件发现框架。
- [ ] 固定运行的 backend、model、config_fingerprint、sdk_runtime_version 和实际工具；工具结构或缺权限的真实限制记录为局部能力，不用已有订阅推断全部接口权限。
- [ ] 任务时长、调用量、并发、递归与取消由宿主控制；坏结构、缺工具、权限不足、超时、取消和部分证据分别返回可查状态，不伪造成功或无限重试。
- [ ] 取证工具不能直接写账本、风险授权或资格；外部材料的指令不改变权限，网络工具也受副作用限制。密钥不进上下文或审计，默认本地脱敏记录而不自动上传含账户数据的云 trace。
- [ ] FastAPI 发起的任务在真实 SQLite/归档中留下可查询结果，页面展示证据与缺口；真实运行验证多轮工具取证、结构化结果和取消/错误，固定归档补充确定性回放，二者分开报告。只测替身或单次 API 的项目不能标为真实接入通过。
- [ ] 本票独立验收 Codex，可与 12 并行；13 负责运行中切换和共同权限组合，23 另验技术审阅输出。记录环境、版本、实际输入/结果、工具及证据，不把本票通过推及 DeepSeek。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

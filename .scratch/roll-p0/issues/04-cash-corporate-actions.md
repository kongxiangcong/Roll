# 04: 确认资金与权益变动

**What to build:** 用户在同步入口处理出入金、分红、利息、税费和送转等真实变动，区分已确认待结算事项与实际到账；外部线索先成为待核事项，只有确认实际发生后才更新账户，并可追溯其依据和资金口径。

**Blocked by:** [02 · 同步真实成交与暂估费用](02-actual-fills.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-10、AT-11、AT-84。

## Acceptance criteria

- [x] 同步页支持现金转入/转出、分红及利息到账、税费与数量权益调整的草稿和差异预览；确认前保持实际现金持仓不变，确认后返回可查询回执及事件依据。03 的 CSV 若已交付，同步扩展其模板与整批确认验收以支持本票新增事件；若尚未交付，03 按届时全部已支持事件接入。
- [x] 公开公告、网页宣称的到账或成交只形成待核材料，不替用户确认实际发生；保留宣告内容、实际到账/发生时点和获知时点的区别。07/14 接入真实网页证据后复验同一边界。
- [x] CASH_IN/CASH_OUT 与投资收益分别保存，分红和利息按实际确认到账处理；利息属于投资收入，不记为外部净投入。资金类别在查询中可区分，存款不能提高投资盈亏；通过利息到账与追加存款的组合验明二者的现金变化、收入及外部现金流归类。
- [x] 用户确认的应收/应付待结算项单列金额、依据、确认时点、状态及关联标识，不提前改变实际到账现金、券商可用资金或持仓；金额未知保持待核。实际到账/扣款时经确认追加关联结算事件，原待结算记录保留历史且不再作为未结余额重复计算，收入/费用不能因待结算与到账各记一次。用分红待到账、应付税费、部分结算、重复确认和追加更正验证守恒；09 负责估值及绩效呈现，05 对账使用这些事实。
- [x] 税费、送转和股份变动使用精确数量和金额，验证成本分摊及总额守恒；未知日期、数量或税费标待核，不凭公告猜个人账户数值。
- [x] 全部变化复用现有原子确认、版本冲突和幂等规则；依据、数量、现金、账户版本与回执保持一致，更正只能追加而非覆盖原确认事实。
- [x] 从 FastAPI 到真实 SQLite 的用例覆盖未确认/已确认、重复请求和失败不提交；关键同步页面展示确认前后差异。记录原始依据、输入、预期、实际及证据，包含现金流和权益守恒样例。
- [x] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

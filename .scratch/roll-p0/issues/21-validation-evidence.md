## Acceptance criteria

- [ ] 应用入口仅接受完整冻结协议及匹配材料后执行确认性检验，登记封存访问、全部尝试与输入/输出指纹；修改模型或政策不能沿用原确认性检验资格。
- [ ] validation_manifest 保存协议/候选指纹、目标与最小改善、基线、窗口、尝试完整性、依赖与统计方法、停止规则、费用/延迟、门槛结果、适用范围、证据截止、局限和未决事项；页面可追溯每项依据。
- [ ] G4 评价使用受同一资金与持仓约束的连续历史策略及可比基线，联合检查费用后收益、尾部/回撤、资金占用、持有期与覆盖；不能用单机会收益相加、长期空仓零亏损或扩大风险换胜率来通过。
- [ ] 概率有效性检查覆盖损失、可靠性、区分能力、入选子集、有效支持与不确定性，处理同日多股及重叠期限；不是仅验证一个平均分或随机切分指标。
- [ ] 按冻结协议输出可复现的 G5 跨时间段、成本压力、延迟和参数邻域分项结果、适用范围依据及不足，关联输入、方法、阈值和结果指纹；不能用单个汇总分代替必需检查。测试后缩域不得使原协议改判 PASS，限制范围的研究须走关联新实验。
- [ ] 用固定输入验证已冻结的正式期执行假设、数据漂移与成熟结果监测方法：检查点、阈值、缺失/未成熟处理及复核输出符合协议，运行/资金风险检查不增加统计 PASS 判定点。方法验证证据供技术审阅和后续持续检查使用，不能充作已发生的真实漂移、实际用户行为或 G7 前向结果。
- [ ] 硬失败优先于证据不足，不能由其他得分平均抵消；置信区间跨边界或有效支持不足为 INCONCLUSIVE，不能写成已证明无效或已通过。尚未完成检查另列具体缺口，不伪装完整结论。
- [ ] 分别持久化实验、验证、审阅和能力状态；在线工程稳定只能支持 G6，缺少真实成熟前向结果时 G7 仍不足。本票可交付验证能力及当前缺口，不提前授予生产资格。
- [ ] 用 FastAPI 应用入口、真实持久化及已归档固定输入验证门槛组合、空仓、硬失败、区间不确定与重放，记录环境/实际结果；真实统计与 G7 证据另列，测试时钟与合成样例不得替代。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

# 12: DeepSeek 真实受控取证

**What to build:** 用户发起同一事实请求，可通过 OpenAI Agents SDK 的 DeepSeek 模型路径完成真实多轮工具取证，看到可追溯证据、缺口和明确的失败状态。

**Blocked by:** [07 · 单源日线与报价证据闭环](07-market-evidence.md)。

**Status:** ready-for-agent

**Primary acceptance:** 无新增 AT 主责任编号；本票独立真实后端验收不可省略，双后端组合场景由 13 主持。

**References:** [规格](../spec.md) ID-06—08、ID-17—18、ID-20—21、Testing Decisions 1、4、6—7、Further Notes 外部资产追踪；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 在实际环境核实并锁定 Agents SDK、DeepSeek 模型、协议、认证与必要适配版本；证明真实多轮工具调用可用，不因用户已有订阅、Codex 已通过或单次 API 可达推断本后端完成。
- [ ] 使用 07 的 DataRequest/RetrievalRun 契约，事实任务可经受控工具取得实际外部依据，宿主检查时间、单位/口径及结构后归档；证据、缺口、真实工具与后端指纹在查询和页面中可见。
- [ ] 独立验证多轮工具结果接续、结构化输出及实际模型支持范围；返回坏结构、无依据和缺权限不能变成已验证事实，兼容层仅处理已发现的协议差异。
- [ ] 宿主落实调用/时间/递归/并发限制和取消，超时或失败有限结束，允许部分证据与缺口；重新尝试保存关联的新运行记录，不覆盖已有运行。
- [ ] 生产取证仅有必要配置、工具与最少上下文，不装载开发技能或参考指令、不做插件发现；无正式账本/风险/资格写能力，外部文字不能改变宿主权限。
- [ ] 密钥、完整账户和资金授权不进入无关模型上下文；运行审计默认本地并脱敏，能查询实际错误/取消原因而不暴露凭据。
- [ ] 经 FastAPI、真实 SQLite/归档和任务结果页面验证完整路径；保存本后端真实多轮取证、取消/错误证据及固定响应回放，按实际覆盖标记通过、部分或未执行，不以替身通过代替真实验收。
- [ ] 本票可独立于 11 完成；13 再验运行中切换与共同边界，23 再验技术审阅契约。记录版本、环境、输入/预期/实际和证据，明确本票接入验收是完成条件而非附带说明。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

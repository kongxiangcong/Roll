# 06: 有限名单、交易日与规则范围

**What to build:** 用户在“持仓与关注”中看到自动纳入的全部真实持仓，添加少量关注，并查看证券身份、当前状态、适用交易日和已适配的规则范围。

**Blocked by:** [01 · 首次建立真实账户镜像](01-account-baseline.md)。

**Status:** ready-for-agent

**Completion:** complete

**Primary acceptance:** AT-17、AT-18。

**References:** [规格](../spec.md) ID-01、ID-03、ID-09、ID-11、ID-21、Testing Decisions 1、3—4；[PRD](../../../ashare_market_decision_prd.md) 1.3、2.1—2.2、MON-01、DEC-10、12.1 Account/InstrumentRule；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [x] 持仓自动进入有限名单，用户增删关注保留成员及时间版本；默认持仓与关注合计 20 只以内，超额清楚提示但不得隐藏真实资产。指数只作背景/基准，不产生指数交易能力。
- [x] 证券身份包含交易所、板块和类型，不靠名称或模糊代码猜测；沪深北的已适配范围明确可查，范围外真实持仓可记录展示，相关能力受限而非冒用已知规则。
- [x] 查询与页面分别展示证券规则适配和 01 已确认的账户 permission_profile，不把市场规则已支持解释为账户已开通；模型技术资格、资金授权也不能替代账户交易权限。覆盖规则已支持但账户未开通/未知，以及已有真实持仓的样例：保留资产和客观风险，明确依赖该权限的交易用途受限。25/26 在各自交付时联验新动作/执行意向不会越过该边界，本票不依赖它们才能完成名单与状态查询。
- [x] 在线个股观察/研究请求限制于当前持仓与关注，不自动扩大到全市场，不为了补齐机会添加股票；新增关注本身不授予模型适用资格。
- [x] M0 调查并记录实际规则/日历来源、版本、生效范围及缺口；交易日来自适用交易所日历，使用 Asia/Shanghai，休市、节假日和特殊阶段不以工作日猜测。
- [x] 当前证券状态和可支持的数量、价格、可买/可卖日期规则可追溯；未知或失效规则只限制依赖用途，既有持仓风险信息仍可见，不承诺建立全市场特殊股历史库。
- [x] 在 FastAPI、真实 SQLite 与名单页面验证成员版本、越范围请求、超额显示、未知板块及日历边界；保存真实来源查证依据与固定样本回放，区分日历/规则实际覆盖和未验证范围。
- [x] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

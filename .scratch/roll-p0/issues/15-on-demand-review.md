## Acceptance criteria

- [ ] 按需与仅盘后均可独立完成日常流程；Asia/Shanghai 和适用交易日历决定阶段，非交易日显示休市但账户同步/历史查看可用，盘前和盘中覆盖不是使用前提。
- [ ] 当前报价、累计成交与最近完整日线分别保存/展示实际时点；未完成 K 线或盘中量不能冒作完整日线，盘后未齐可有限补查，仍缺则局部待补，不用昨日值充当天。后续 19/25 接入预测时联验概率时点与资格。
- [ ] 将 07/08 已有的公告、公司行为、相关事件及指数/量价市场背景接入按需与盘后观察；事实风险和待核事项保留证券/对象、来源、披露或事件时点、实际获知时点与缺口。持仓风险不因无模型资格而隐藏，网上权益不直接入账；短依据可展开原证据，不生成无来源情绪评分或未经资格的持有/买卖判断。
- [ ] 持久化任务记录交易日、阶段、截止、账户/影子及数据版本，重试复用身份、不重复观察结果；单后台 worker 与 SQLite 任务支持实际退避/超时/取消及健康查询，不建设通用 DAG 或外部队列平台。
- [ ] 在实际运行日及按需/恢复入口形成可查询的运行审计，逐项保留数据覆盖、账户差异、未完成执行意向、建议失效数量、重复通知、动作翻转及模块错误，并能定位原任务、对象、版本和证据；未接入的指标明确未接入，不能以零值冒充正常。审计与首页短状态分层，不要求用户阅读诊断报告；达到关键复盘条件时关联核验任务，不自动把所有审计升级为多源核验。
- [ ] 为 27 提供按 Asia/Shanghai 和交易日历登记、触发并持久化维护检查的入口与幂等身份；程序运行时检查到期维护点，按需/恢复时记录逾期和实际检查时间。未运行期间只留缺口，不补造当时已检查、不要求常开；27 接入健康、标签成熟、资格到期及新实验条件检查，本票不提前声称其业务检查完成。
- [ ] 相同条件状态归并并保留前后快照关联，无新信息显示无实质变化；不重建未观察时段的触发顺序。后续 25/28/30 用同一入口联验动作、通知和确认性样本不重复，本票不以尚无这些输出推定已通过。
- [ ] 正常关闭/休眠记录实际覆盖缺口，不持续制造监控故障、不要求每日声明；恢复可补取事实与历史复盘，但原始覆盖不改，过期机会只归档，未曾归档的预测不能补为前向证据。
- [ ] 五个一级入口限于今天、持仓与关注、同步账户、历史记录、设置；首页优先显示能力/原因、账户时点、数据和最近运行、事实/待办与变化。无交易用户可完成声明、观察与历史查看，不选统计方法或必读报告；后端不可用不阻塞普通事实功能。
- [ ] 联网补查经过共用事实契约并与本地计算分开计时；在记录的实际设备、缓存和名单规模下验证首页读取 P95 ≤ 2 秒，不作分钟行情或秒级捕获承诺。
- [ ] FastAPI 与真实 SQLite/归档验证日历边界、未齐输入、持久化重试、恢复缺口、状态合并及运行审计；真实进程重启验证任务/维护触发身份，浏览器完成五入口无交易流程、事件风险/市场背景、时点和异常追溯。25/26 接入后联验真实未决意向、动作失效和翻转，28 接入后联验重复通知及渠道异常；后续票消费本票入口，不增加 15 对后续票的阻塞，待联验项保留到实际完成。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

# 20: 冻结研究政策与连续影子

**What to build:** 将研究预测按确定性政策转为动作或拒绝，从冻结基线推进受资金与持仓约束的连续影子；页面分列连续策略结果与一次账户条件诊断，并完成确认性检验前的完整协议冻结。

**Blocked by:** [19 · 透明候选、校准与模型冻结](19-transparent-model-freeze.md)；[05 · 补录更正、账户声明与对账](05-reconcile-account.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-39、AT-62、AT-63、AT-74。

**References:** [规格](../spec.md) ID-03、ID-10、ID-14、ID-15、ID-16；Testing Decisions 的主要边界 1、5、6 及“研究隔离”；[PRD](../../../ashare_market_decision_prd.md) EVAL-01/12/16/17、G5；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 以普通数据结构和计算函数实现本票的确定性研究政策，将冻结模型输出、规则和执行假设转为动作或拒绝，不建设策略 DSL 或通用规则引擎；开发样例验证稳定排序、联合预算、现金/数量守恒及日线执行，不能将多个无法同时成交的机会收益相加。
- [ ] 模型、校准器、特征、研究政策、规则、费用、执行/缺失假设和数据/代码指纹齐全后，持久化不可变完整实验协议；包括 17 预登记的 G5 检验、正式期执行/数据漂移/成熟结果监测方法、阈值、适用范围与检查点的版本和指纹。缺项或指纹不匹配时拒绝完整冻结与确认性检验，不能以 19 的模型冻结替代完整协议冻结；修改这些政策或方法须保留旧版并登记后继实验。
- [ ] ShadowAccount 从冻结现金/持仓基线连续演化，仅按所属实验的模拟事件和现金流政策更新；影子事件、结果和输入可追溯且可重放，不影响真实账户、现金或实际收益。
- [ ] 用户逆模型交易、补录、更正或调整真实费用后，真实镜像更新而既有影子状态及历史收益不重置；更改影子基线、模型、政策或现金流假设须新建关联实验，不能拼接旧成绩。
- [ ] 保存所有机会的动作或拒绝原因；拒绝机会的反事实结果成熟后仅作预测/筛选诊断，拒绝或未执行不直接记为模型亏损。重叠机会保留资金约束，不将诊断曲线混入连续影子业绩。
- [ ] 页面和服务查询分列 ACTUAL、HISTORICAL、SHADOW、ACCOUNT_CONDITIONAL；一次真实账户条件诊断不能成为连续策略收益，无正式执行入口。本票政策计算可供 25 复用，正式授权与用户执行门禁由 25 补齐。
- [ ] 通过 FastAPI 应用入口、真实 SQLite 和隔离归档验证多日演化、补录后影子不变、超预算拒绝、版本后继与重放；补充研究页面关键分列流程，并留存各主责任场景证据。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

# 10: 资金授权与默认关闭的正式能力

**What to build:** 用户登记资金用途、允许暴露和损失暂停条件，并在首页分别看到资金授权、技术资格和运行健康；没有合格能力时可继续看账户事实，但不会收到伪装成观察的交易判断。

**Blocked by:** [01 · 首次建立真实账户镜像](01-account-baseline.md)。

**Status:** ready-for-agent

**Primary acceptance:** AT-32、AT-33、AT-60。

**References:** [规格](../spec.md) ID-10、ID-12—13、ID-16—17、Testing Decisions 1、3、5、7；[PRD](../../../ashare_market_decision_prd.md) 1.3、AUTH-01/04、DEC-04、FLOW-06、12.1 RiskAuthorization、附录 B 损失触发口径；[目录与实施约束](../project-layout.md)。

## Acceptance criteria

- [ ] 用户可查看、确认和版本化保存 RiskAuthorization，资金用途、暴露及暂停边界采用实际输入，不由模型或开发代理猜金额；不存在运营金额预算或专业人工复核采购前提。
- [ ] 本票冻结损失计算公式、输入契约和版本，明确作用于整个真实账户还是已界定的试验资金授权范围、计算起点/基线、外部现金流调整、已实现与未实现损益、收入/费用、待结算项及陈旧/缺失估值的处理，并据此计算损失触发状态和剩余额度。授权范围的实际事实与隔离影子收益分开，不能拼接；必需事实不足返回待核/受限而非假定零损失。用户仅确认自身资金金额与用途边界，计算方法由实现提供并验证，不能让用户代选技术口径。
- [ ] 暂停阈值、剩余额度及恢复条件与授权版本关联，不因跨日、重启、价格反弹或扩大金额自动重置损失历史；缩小/撤回立即按新授权限制后续用途，扩大也不抹除旧结果或突破已验证范围。用固定输入验证出入金、利息/费用、已实现与未实现变动、陈旧估值、阈值前/等于/超过及跨日重启边界，保存公式版本、手工可核对预期和实际结果。
- [ ] 本票独立完成授权保存、公式与边界计算验收；09 提供实际账户估值/现金流版本，20 保持影子结果隔离。25 在正式预算中接入 09 与本票契约，27 联验达到阈值、缩权及恢复时真实动作/资格的限制；这些后续责任不成为本票隐含前置，固定样例通过也不冒充实际触发链已完成。
- [ ] 资金授权、模型技术资格和运行健康独立查询，默认技术能力 UNGRANTED；部署成功、用户模式切换或填写资金不能自动激活正式建议。
- [ ] 未合格时服务端拒绝 BUY、ADD、HOLD、REDUCE、EXIT 和判断型 WAIT，返回明确资格原因；页面保留 Observation/RiskAlert，不用“暂不能交易”推导默认持有或清仓。
- [ ] LLM 自述的高信心不能写为 ForecastBundle 的正式概率或正式动作依据；研究概率与技术资格分别表达，观察文案不得绕过相同服务端门禁。
- [ ] 页面按当前能力及原因、账户时点和待处理事实呈现；未启用正式能力不要求用户选统计方法、投资人格或阅读报告才能使用账户功能。
- [ ] 通过 FastAPI 和真实 SQLite 验证授权持久化、版本冲突、默认无资格及各判断类型拒绝，浏览器检查三类状态和事实可用；后续 24/28 验证真实资格签发及通知出口，本票不提前声称不存在的出口已通过。
- [ ] 遵守目录与实施约束；仅引入本票实际需要的模块、接口和校验，保留 PRD 必需控制，不新增假设性兼容层、审批或泛化框架。

# Roll 可用版：持续跟踪、探索回测与交易辅助

Status: ready-for-agent

日期：2026-10-23。实施规格 v1.0。用户在本会话明确同意可用版路线，授权按阶段推进。边界修订见 ADR 0005；实施完成与授权分别记录，不将旧研究票改为完成。

## 目标

用户在一个入口看大盘和持仓/关注股发生了什么，得到有证据的综合判断，查看固定策略在明确历史假设下的表现，并记录自己的实际决策与成交。系统可以持续积累观察与复盘，不依赖先训练出一个获正式资格的收益模型。

成功标准是可持续使用的完整流程；某个策略亏损或跑输基准也能完成研究交付。保留正式策略资格与账户确认的约束，不保证投资优势。

## 与原设计的关系

保留本地 React/FastAPI、worker、SQLite、原件归档、账户镜像、成交确认、现有来源、备份恢复和适用的模拟/报告逻辑。原 P0 SPEC 已允许无合格模型时继续账户与观察。

新增的交易辅助可以表达基于证据的方向倾向、理由、反证与条件，不能只用“事实观察”代替用户需要的判断。因此实施前须同步修订根 PRD、GLOSSARY 和 ADR 0003 的适用边界：区分人工采用的研究判断与已验证策略的正式 Decision。这是有实质含义的产品改变，不能仅添加免责声明、改名或放开原 CapabilityGrant 检查。研究判断没有旧正式动作的执行意向/资格标识，不产生实际成交；正式策略路径继续保留原检查。

## 范围与减法

- 第一条完整样例：江西铜业，加上上证指数、沪深300、创业板指作为建议默认的大盘背景；指数不作为可交易个股。具体来源证券代码与覆盖在接入时验证。
- 样例成立后扩展到现有账户持仓和关注清单，沿用原范围上限；不以单股硬编码作为最终多股完成状态。未适配持仓仍可记录与展示。
- 暂不做秒级行情、全市场扫描、自动下单、多 Agent 辩论、新情绪模型训练和参数搜索平台。需要上述能力时先证明现有闭环的具体不足。
- 现有真实实验、失败、预算与封存记录不变。首轮使用固定透明规则，不追加旧家族 fit/CAL，也不把新探索当成旧确认性证据。

## 用户流程

持续取得最低必要数据 → 保存来源/时点/口径 → 识别实质变化 → 综合辅助判断 → 按需查看历史回测 → 用户自行交易并确认记录 → 后续复盘。

所有页面分别呈现“来源状态、分析状态、回测状态、正式策略资格”，不以单一“系统可用：否”概括局部缺口。

## 数据与持续跟踪

复用已安装来源；妙想作为增量读取来源，首次适配处理自然语言接口实际范围、单位和未知复权口径。只读 MCP 成功不等于 Roll 已集成。保存原始响应和取得时点，稳定归一化后由不同任务消费。

建议运行节奏：交易时段每30分钟刷新轻量观察，盘后生成一次日结；随时手动请求。30分钟是可配置的观察频率，不是实时承诺，不构成分钟策略支持。财报按披露/缓存变化处理，不因报价刷新重复请求；新闻去重，重要变化才形成待办或站内提醒。外发通知另按用户选择配置。

复用现有 worker、租约和幂等任务，将当前固定 `SSE:600362` 的调度改为按证券与数据类别管理。实现有界重试、失败退避、来源健康和队列公平性，单一来源/证券故障不停止其他任务。

交付本机可管理的启动、停止和恢复方式；开机自启与异常重启属于持续运行实施范围，需要状态可见且可禁用。电脑关机、睡眠期间明确离线，不回填为当时已知的观察或预测。如果之后要求电脑关闭仍追踪，再讨论常在线主机，首轮不引入云端账户迁移。

缺失按用途处理：缺新闻不阻止量价回测；缺报表不猜财务比率；缺关键价格不算该段收益；口径不明可展示原返回但不可假定已经适合执行价格/总回报；持仓价格缺失不按零计净值。缓存必须标时，过期判断不能当当前有效。

## 探索回测

先用现金、买入持有和一个参数预先固定的透明规则，范围与日期由可用数据决定并明确记录；不为了好看反复调参。复用现有连续资金/持仓、费用和报告组件，但先证明可独立执行探索任务，不要求旧家族完整冻结或正式资格。无法以小改动拆开时，再评估一个隔离的成熟引擎适配器，避免并行造两套账本。

至少保存数据版本、策略参数、执行时点、费用/滑点、处理权益的方式、交易记录、净值、回撤、持有基准和缺口。日线信号不以同一根收盘数据生成后再假定早于它成交。适用的 T+1、买卖单位、停牌、涨跌停与无法成交要按模拟规则处理；未知规则限制对应结果用途。复权价不能无说明直接当实际成交价。

数据不足时返回可诊断的局部结果或拒绝相关计算，不补造数据。探索回测、严格历史时点验证、未来实际记录和真实账户收益分别展示；当前 LLM 读取旧新闻生成的分析不自动成为无泄漏历史策略回测。

## 交易辅助

复用当前 CODEX 后端能力，通过受限工具读取已归档资料；不新增后端或要求训练模型作为首轮前提。单次输出结构固定：

1. 当前观点与适用期限，明确区分有依据的中性判断和无法判断。
2. 最重要的支持证据，能回到来源及其时点。
3. 最重要的反证、数据缺口与不确定性。
4. 使判断改变的可观察条件；条件来自具体论据，不让模型随意编造价格阈值。
5. 与用户持仓的关系；账户未确认时只做证券分析，不猜现金、成本和可卖量。
6. 关联的回测结果与适用限制，区分历史描述与当前建议依据。

模型负责综合与解释；数值指标、账户约束、费用和情景计算由确定性代码完成。没有经过校准的依据，不显示“胜率”；回测胜率不能包装成当前上涨概率。若关键依赖缺失，说明无法作哪一项判断，并保留其余分析。

## 实施顺序与验收

| 阶段 | 交付给用户的结果 | 必须取得的证据 |
|---|---|---|
| 0. 收敛边界 | 一份修订后的主规格与对应术语/ADR，原研究明确保留 | 助研、探索回测、正式策略各自可做什么；旧票不再默认阻塞新基础路径 |
| 1. 一个完整日常样例 | 手动发起江西铜业分析，结合大盘，看到观点/反证/来源，打开固定规则回测与历史记录 | 实际宿主、真实来源和真实模型完成一次；差回测也正常交付；不写真实账户；缺关键数据有明确结果。无须等待持续运行验收才可试用 |
| 2. 自动跟踪与清单扩展 | 持仓/关注清单定时更新，断网/重启后继续，重大变化可见 | 实际多证券隔离、重复任务去重、来源失败与恢复；真实时钟覆盖至少5个交易日的运行日志，缺席如实记录 |
| 3. 决策复盘与交付 | 查看观点怎样变化、用户怎样行动、结果怎样，备份可恢复 | 观点版本、证据版本和实际成交不混淆；未执行建议不记成交；结果期限未到不评分；从备份找回记录 |

五个交易日用于稳定性观察，不代表策略统计验证，也不作为阶段1用户试用的前置。每阶段以完整可演示行为验收，不以增加表/接口数量或 METHOD 测试数量替代。

## 依据与已知未知

依据 [六项目对照](../../docs/research/2026-10-23-roll-workflow-comparison.md)、[助研源码调查](../../docs/research/2026-10-23-oss-assistant-workflows.md)、[原 SPEC](../roll-p0/spec.md)、[现有日常范围](../roll-daily-use/spec.md)。其中 Backtesting.py 官方样本与妙想一次查询已实际运行，其他完整平台未在本机运行。它们证明路线有可复用实现，不证明 Roll 新流程已完成。

当前已确认调度主要固定单股盘后；尚须核定多证券来源覆盖、盘中延迟/额度、妙想完整历史与复权口径、现有引擎解耦成本、真实 CODEX 辅助判断输出质量。本稿没有给未验证工作承诺准确天数。

竞争路线是维持原“只提供已验证正式动作”的目标；它仍需要数据、研究与前向证据且可能得到 FAIL。用户本轮明确提出交易决策的辅助，本稿优先独立交付该能力，正式策略作为后续路线。第一份真实完整样例是否帮助用户作判断，是区分此路线价值与单纯报告堆积的最小检验。

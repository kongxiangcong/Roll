# 01: 断网发起研究并重读阻塞性缺口

**What to build:** 研究者通过 roll research task run 提问，拿到缺证回执，重启后仍能查到当时用了哪些公开材料、还缺什么。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 在 M0a 验收库副本用 600362.SH、指定行情快照、截止时点及一个需要额外公告的问题运行正式 CLI。回执含任务与尝试 ID、阻塞原因和所需证据，无可发布草稿。
- [ ] 按 ID 重读问题、标的、用途、截止时点、行情快照、公开输入的内容或不可变引用及指纹，以及该次缺口。再次运行读取命令得到相同内容。
- [ ] CLI 支持本地公开文件和摘录，两种形式均要求标题、来源、定位、URL 或文档标识、实际取得时间。验证输入后修改原文件，仍可离线核对当次材料。截止后取得的公告不能用来填补该问题的缺口。
- [ ] 未建档股票也可建立任务并登记用户材料。用带私有标记的账户数据验证执行桩可见输入仅含本次获准的公开材料。

# 02: 为证据充分的尝试保存可审阅草稿

**What to build:** 研究者提供足以回答问题的公开公告，一次离线执行即可按回执版本阅读草稿和证据局限。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 从无已发布档案的库起步，通过正式 CLI 提交足够材料。按回执读取草稿、任务、尝试和清单，核对引文定位及指纹。
- [ ] 合并预检与执行桩声明的缺口。必要材料缺失时返回缺证结果；对不依赖的材料缺口，用可继续的样例验证草稿保留缺口及其影响。
- [ ] 复用档案的证据、时点及结构化引用校验。错标的、结论时点与任务不符、取得时间越界、未登记引用或冒用其他清单证据的回包均无法成为就绪草稿，原因可查。
- [ ] 由 Roll 分配版本。执行桩返回后以单个短事务保存草稿、结果关联及 draft_ready；模拟中途写入失败，重读看不到孤立草稿或虚假完成。

# 05: 在 M0a 副本核验研究发布与计划历史

**What to build:** 研究者在同一份验收库副本上贯通缺证、补证、重试和发布，核实每个阶段的交易计划读取了哪个档案版本。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 从 M0a 副本记录原冻结计划 ID、内容及预览基线。固定账户、行情快照和同一截止时点，经过缺证、补证、生成 A 和重试生成 B 后，roll plan --preview 与基线逐字段相同。
- [ ] 按 A 的回执审阅发布，安排与旧档案有效期衔接的时间。用正式 CLI 分别在 A 生效前和有效期内预览，计划依次引用旧档案和 A；同时确认 B、两次尝试和父子清单均可按 ID 重读。
- [ ] 按原计划 ID 离线重读，完整结果与首次归档逐字段一致。记录可复核的任务、尝试、版本、快照、时点、计划 ID 和比对结果，写入仅使用副本。

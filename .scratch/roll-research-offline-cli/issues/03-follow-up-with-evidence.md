# 03: 补证后按父子任务比较材料

**What to build:** 研究者从缺证任务补入公告，在关联的新任务中继续研究，并能解释前一次为何缺证。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 在验收库副本上先取得阻塞性缺证，再通过正式 CLI 指定原任务并补入公告。回执给出新任务、新尝试和父任务引用。
- [ ] 分别按两个任务 ID 读取清单，只有子任务含新增公告及其来源、取得时间与指纹；父任务仍能读到原尝试及缺证原因。
- [ ] 补证操作复用相同的研究问题和标的，记录新任务实际使用的截止时点和行情快照。若补入新的行情依据，验证父任务仍解析到原快照。
- [ ] 本票可用补入一份公告后仍缺另一项必要证据的案例独立验收；与草稿路径合并后，补足全部必要材料可得到子任务草稿。

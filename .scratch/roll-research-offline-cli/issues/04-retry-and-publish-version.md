# 04: 同输入重试并发布指定尝试的版本

**What to build:** 研究者用同一任务取得 A、B 两份草稿，在已有 B 的情况下审阅并发布 A，并从发布版本追溯来源。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 正式 CLI 手动重试只新增尝试，读取同一清单及输入指纹。即使桩两次自报同名版本，也取得不同的 Roll 版本 A、B；A 的内容保持可重读。
- [ ] 同一次尝试的结果重复提交至多产生一份草稿。用手工导入尝试覆盖任务持有的版本时，按原回执读取的内容与来源保持一致。
- [ ] 使用 roll research show 600362.SH --draft --version A 核对较早草稿，使用 roll research publish 600362.SH A --reviewer 研究者 显式发布。以实际回执替换 A。
- [ ] 按发布版本读到对应任务和尝试、审阅人、发布时间及生效窗口。B 仍是可重读的草稿；先前尝试、旧手工档案及其原有读取方式相容。

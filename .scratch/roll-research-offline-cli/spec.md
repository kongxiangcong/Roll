# 正式 CLI 的离线研究闭环

Status: ready-for-agent

Resolution: completed
Closed: 2026-11-26

## Problem Statement

研究者要核查江西铜业（600362.SH）的一个具体问题。M0a 已能导出行情、导入草稿和人工发布研究档案，但研究者仍需自行记住每次用了哪份公告、为何缺证，以及审阅版本来自哪次执行。同名草稿可以被再次导入，单凭最新草稿无法可靠回答这些问题。

## Solution

研究者断网运行 `roll research task run`，提交标的、问题、截止时点、行情快照及可选公开材料。Roll 冻结输入，登记研究任务和首次研究尝试，由离线执行桩交回可追溯的个股档案草稿或具体的证据缺口。研究者可以用原材料重试，也可以补证后发起关联任务，最后按回执中的版本审阅并显式发布。

## User Stories

1. 作为研究者，我希望按问题、标的和截止时点发起研究，以便明确结论适用的范围。
2. 作为研究者，我希望未有已发布档案时也能提交公开公告文件，以便开展首次研究。
3. 作为研究者，我希望也能提交带原文定位的摘录，以便只固定与问题有关的材料。
4. 作为审阅者，我希望看到标题、来源、定位、URL 或文档标识及实际取得时间，以便核对引文和时点。
5. 作为研究者，我希望重读当时的行情快照、公开内容和指纹，以便在原文件变化后复核尝试。
6. 作为研究者，我希望知道哪项必要证据缺失，以便确定要补哪份公告。
7. 作为审阅者，我希望草稿列出非阻塞性缺口，以便识别结论的局限。
8. 作为研究者，我希望补证形成带父任务引用的新研究任务，以便比较前后两份清单。
9. 作为研究者，我希望对同一清单手动重试，以便独立审阅两次尝试。
10. 作为审阅者，我希望回执直接给出任务、尝试和结果引用，以便重启后按 ID 找回指定结果。
11. 作为审阅者，我希望 Roll 拒收引用其他任务材料或标的不符的草稿，以便信任版本的归属。
12. 作为审阅者，我希望按版本审阅并发布较早的草稿，以便采用自己实际核对过的内容。
13. 作为复盘者，我希望从已发布版本追到任务、尝试及输入，以便检验当时判断的依据。
14. 作为计划使用者，我希望研究过程中预览结果稳定，以便继续按生效档案生成交易计划。
15. 作为复盘者，我希望发布后按历史时点选档并重读冻结计划，以便核查当时生效的决策输入。

## Implementation Decisions

- 正式 CLI 调用本地编排入口。Roll 在现有 v3 SQLite 中保存任务、不可变清单、尝试和结果引用。离线桩每次只消费获准的公开输入。账户快照、交易日志与风险预算由本地决策模块持有。
- 清单固定用途、标的、问题、截止时点、行情数据快照及本次实际用到的公开行情导出、档案版本和公告。文件与摘录均保存实际内容或可离线解析的不可变引用，并记录内容指纹和来源元数据。可变路径或 URL 只能充当来源定位。保留行情既有重建用途和可得性假设，公告按实际取得时间核对截止时点。
- Roll 合并预检和执行桩报告的缺口，按本问题是否依赖该证据决定阻塞性。阻塞结果可按尝试重读，明确所需材料；有充分依据时，草稿连同剩余局限一起交付。
- 草稿入库复用研究档案的证据结构、时间和结构化引用规则，增核原始标的、任务截止时点及证据是否出自本清单。人工确认依据、发布人、发布时间及生效时间由现有发布入口登记。
- Roll 分配每次成功尝试的唯一草稿版本，防止任务版本被同名导入覆盖。执行在写事务外进行。草稿、任务和尝试的结果关联、完成状态在同一短事务内提交。失败可追溯，每次尝试至多交付一份草稿。
- 重试复用原任务的冻结清单并新增尝试。补公告或更换行情依据时创建带父任务引用的新任务，按需重冻行情。历史任务、尝试和产物分别可查。
- 沿用指定版本审阅、发布和按时点选档语义。旧档案与手工研究继续可读；仅有任务来源的版本提供相应任务与尝试引用。

## Testing Decisions

以正式 roll CLI 为主要验收入口，在临时 v3 库中断网运行，以回执、按 ID 重读的对象、版本内容和逐字段计划差异判断结果。沿用研究档案测试的公开输入与生效窗口案例，以及交易计划测试的冻结输入重放案例。对事务中途失败和不合规执行桩回包，可在本地编排入口注入故障，随后从正常读取入口检查可见状态。

在 M0a 验收库副本上完成三组操作，保存各组的输入 ID 和结果引用：

1. 对 600362.SH 提问得到阻塞性缺证，补一份公开公告后建立关联任务。按两个 ID 重读，仅新清单含该公告。另验证有非必要缺口时可取得带局限说明的草稿。
2. 同一清单先后取得 A、B。用 `roll research show 600362.SH --draft --version A` 核对 A，用 `roll research publish 600362.SH A --reviewer 研究者` 发布。A、B 代表实际回执版本。验证 A 生效、B 仍可审阅，双方尝试与原材料可查。
3. 固定行情数据快照、账户及截止时点，新增草稿前后比较 `roll plan --preview` 完整结果。发布 A 后分别在生效前与有效期内核对计划引用，按 ID 重读原冻结计划并与归档逐字段比较。

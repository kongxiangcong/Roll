# 默认数据来源与有界换源

依据：2026-10-29 用户要求全面比较已有来源，优先扶摇及妙想，支持多方比较及额度不足备用切换。

- 按用途选源：扶摇历史日线/公司行为优先；逐证券带时钟报价新浪→腾讯→扶摇；交易状态/日历沿用已适配来源；研究检索妙想优先，原始披露继续单独核验。
- 新增 AUTO 选择；明确选择某个供应商的请求保持明确选择，不静默换源。通过 `ROLL_DATA_SOURCE_POLICY=OFFICIAL_FIRST` 设置默认策略，LEGACY 保留原行为。
- 自动路径在原请求调用、时间和字节总预算内顺序尝试；认证/额度/限流有有限冷却，不购买额度。归档原始响应，保留每次失败、实际来源及父子运行；重放零网络。
- 多源比较只在明确比较模式调用，核对对象、日期、复权、单位；不做投票，不把供应商不同视作独立原始生产。
- 妙想内容作为带来源的研究参考，不自动转换为财务原件、历史 PIT 或正式能力。
- 日常卡片/市场更新采用自动策略；交易辅助优先扶摇量价，回测所需停牌/ST/昨收必须取得真实补充，不伪造。
- 验证覆盖业务限流 HTTP200、认证/额度、回退、显式源不变、预算/取消、差异保留、原件重放；真实小范围只读取数与 METHOD 测试分别报告。

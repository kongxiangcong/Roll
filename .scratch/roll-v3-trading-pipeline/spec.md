# Roll v3 · 单股研究、盘后计划与前向复盘

Status: ready-for-human

Resolution: M0a 已验收。M0b 工具已交付，真实运行签收待连续 20 日记录。 [验收记录](acceptance.md)

## Problem Statement

我在收盘后需要决定明天如何处理持仓或关注股。今天的市场分数、风险卡和冻结日报能描述部分状态，但我还要自己拼起公司公告、行业表现、策略依据、可卖股数和可用资金。数周后，我也很难回答当时依据哪份公告、哪些候选被排除、自己是否照计划执行，以及结果差在哪里。固定 ETF 的回测和指数上涨频率无法直接回答这些单股问题。

## Solution

以江西铜业为首标，从多年真实量价和一份已发布的研究档案出发，用冻结的日频趋势策略完成实验。在本地按账户约束比较候选，形成一份可重放的下一交易日计划。连续影子账户记录按规则执行的结果，真实账户镜像记录用户实际发生的交易，两者都能追溯到当时的计划。

M0a 在数据、回测、研究发布、计划生成及前向机制演练通过后工程准出，可日常使用并启动 M1。M0b 在连续 20 个真实交易日的前向记录齐备后独立签收。后续研究按增量价值分阶段扩展。

## User Stories

1. 作为个股研究者，我希望对已有持仓或单纯关注的股票建档，以便账户数据尚未录入时也能开展研究。
2. 作为研究者，我希望取得江西铜业、沪深 300 和对应行业指数自 2020 年起的真实日线，以便比较公司、行业和市场在多个行情阶段的表现。
3. 作为研究者，我希望看到实际首末日、有效交易日、停牌、缺口和预热后的区间，以便判断哪些问题可以用这批数据回答。
4. 作为研究者，我希望查看不同交易日窗口的量价、回撤、波动与相对收益，以便区分短期变化和中期趋势。
5. 作为研究者，我希望知道行业归属在哪段时间成立，以便解释历史行业表现并识别只能与指定 ETF 比较的区间。
6. 作为研究者，我希望把有出处的事实、研究推断、反证和可观察的证伪条件写入同一份档案，以便下次公告披露后审视原判断。
7. 作为外部研究助手的使用者，我希望通过本地 CLI 取出公开指标、提交 Markdown 草稿，以便使用自己选择的工具并将账户资料留在本地。
8. 作为研究发布者，我希望给档案指定版本、生效时间和有效期，以便追查某日决策究竟使用了哪条研究约束。
9. 作为策略研究者，我希望在看结果前登记假设、基准、参数、成本和评价窗口，以便区分探索结果与独立验收。
10. 作为实验读者，我希望同窗比较趋势策略、买入持有和不主动交易，以便理解主动交易带来的收益、回撤、成本和换手。
11. 作为已有持仓的使用者，我希望三个方案从相同的现金和批次出发，以便辨认两条基准实际上重合的情况。
12. 作为实验读者，我希望收盘信号在下一合法时点按原始报价模拟成交，并看见无法成交的原因，以便判断策略的实际执行代价。
13. 作为账户使用者，我希望分别看到现金余额、可用现金、可卖数量、预留和风险预算，以便知道次日实际能用多少资金。
14. 作为持有人，我希望除权后尚未到账的红利和送转股反映在净值中，以便到账时间差不会制造虚假回撤。
15. 作为账户使用者，我希望目标交易日结束后自动收回未使用的单日计划额度，以便次日资金充足时仍能行动。
16. 作为账户使用者，我希望跨日有效条件和已登记的券商未决委托继续保留剩余额度，以便部分成交或程序重启后仍能核对占用。
17. 作为盘后使用者，我希望看到每个候选的适用条件、排除原因、唯一生效方案及其有效期、退出和撤销条件，以便自己做最终交易决定。
18. 作为多只股票的持有人，我希望所有候选使用同一份账户预算，以便两个加仓计划不会承诺同一笔资金。
19. 作为盘后使用者，我希望在证据缺失或没有合格主动策略时仍能看到观察或既定风险计划，以便了解今天可以做什么。
20. 作为复盘者，我希望并列查看当时计划、影子结算、实际成交或未执行原因，以便区分策略表现和个人执行偏差。
21. 作为复盘者，我希望补采、更正、改草稿及断网重启后仍能重读原计划，以便识别当时已知的事实和后来获得的材料。
22. 作为日常使用者，我希望工程准出后即可开始使用 Roll，以便在自然积累前向记录的同时继续完善研究。
23. 作为运行验收者，我希望按交易日查看观察、未成交、异常、已结算和待执行记录，以便核对 20 日前向窗口的连续性。
24. 作为后续研究者，我希望在相同机会集上比较新增市场、行业、ETF 和基本面特征，以便知道数据是否带来样本外增益。
25. 作为策略使用者，我希望多策略切换连同费用、暂停条件一起接受独立评价，以便只在获准范围内启用主动策略。
26. 作为概率研究读者，我希望同时看到预测事件、期限、样本、不确定性和简单基准，以便在证据不足时保留未知。

## Implementation Decisions

- **重构边界。** 使用 Python 本地模块化单体、SQLite 和 CLI。网页调用同一应用入口。新库、新命令直接切换，重写旧账户模块、固定 ETF 撮合和日报冻结流程。可移入交易日历、已核实的源字段映射、费用舍入及净值统计。
- **行情与时点。** 从 2020 年首个交易日拉至冻结的最近完整交易日。证券统一用带交易所后缀的代码。以交易日、可得时间、采集时间和来源修订标识区分观察版本；追加修订或撤回。快照冻结最大入库序号、输入范围、选源规则和用途。历史逐日采用当时可见版本，真实计划还受当时实际取得时间约束。显式假设下的重建研究另行标识。
- **取源与覆盖。** 按数据项优先复用本地版本及扶摇等已验证通道，按已授权任务范围使用 Investoday 补项或核对。普通回放离线，默认付费预算为零。63 日除息记录用于回归核对；M0a 仍须交付可评价的多年量价和连续趋势回测。行业比较限定于归属有据的有效区间。基本面材料按实际引用记录标识、定位和时间，原件按需留存。
- **研究发布。** 一份档案保存假设、证据、反证、有效期、基本面约束、策略白名单和失效触发条件。研究者可人工撰写或使用外部助手，再显式发布新版本。Decision 只读有效的结构化结论和获准策略。修改草稿不会改变计划。盘后决策零模型调用，账户、成交、资金预算仅在本地使用。
- **策略实验。** M0 冻结一个低参数日频趋势候选，预登记适用范围、信号与执行时点、进退规则、成本、比较基准及开发与样本外窗口。保留失败与证据不足的结果。未准入候选可在模拟账户运行，正式计划可采用观察和预设风险动作。独立验收和准入资格分别记录。
- **账户与共享执行核。** AccountSnapshot、TradeLog、PositionLot 和 RiskBudget 表示已知基线、变动、持仓批次及资金约束。真实、历史模拟、连续影子各有独立账本。实验与前向使用同一盘后裁决和次日执行规则。真实账户按用户确认的事实更新，事后更正生成新的可见状态。
- **执行与计价。** 使用原始报价执行，按交易日期和券种处理停牌、涨跌停、T+1、报价与申报单位、费用和滑点。开盘执行只读取其时点可知的输入。原始昨收、当日参考昨收、原始开盘和实际每股派息分别核算。登记持仓决定权益；现金或股份在途期间计入净值，到账或上市时转入并冲销一次。M0 历史策略、双基准、前向影子均按股息红利税前、含交易成本，真实账户以实际入账和扣税流水为准。
- **账户统一裁决。** P0 限定可执行方向与数量，P1 根据可用现金、预留和集中度建立共享预算，P2 应用已发布研究约束，P3 筛选策略资格及适用性，P4 在剩余范围内按预登记顺序分配并计入费用。同优先级按证券代码稳定排序，未成交卖出款不预支。保留全部候选及排除原因，每只股票同一交易时段仅一个生效计划。
- **计划版本及资金预留。** 同次账户裁决原子更新各股计划版本、当前指针和预留。单日计划在目标交易时段收盘后释放剩余额；跨日条件按有效期，券商未决部分保留至成交、撤单或失效。部分成交按实结算，重叠承诺和已反映在券商可用现金中的冻结款只计一次。确认、拒绝、迟到流水、影子结果追加到相应计划，原冻结版本可重读。
- **后续阶段。** M1 与 M0b 并行，由 Roll 编排单次研究，按 CLI 离线闭环、真实助手与江西铜业 E0/E1 对照、工作台接入的顺序交付。随后按证据覆盖扩展行业、ETF 和历史基本面实验。M2 验证多策略选择与切换，M3 评价跨标的概率，M4 再评估有限多轮研究。[主方案 §13](../../docs/design/architecture/roll_v3_trading_pipeline_spec.md#13-开发路线与里程碑验收)

## Testing Decisions

以用户确认的**本地 Roll CLI** 为主要验收入口。用独立数据目录经正常应用命令完成同步、草稿与发布、实验、账户录入、计划冻结、次日结算和复盘。网页复用这套应用入口。断言面向用户可见的金额、股数、日期、覆盖、选择理由与重放结果；数据库布局和私有函数的调用顺序可随重构调整。沿用现有测试中临时库、固定时钟与交易日历、离线价格样本、重复冻结重读，以及 CLI 与网页结果一致的做法。

| 验收场景 | 通过条件 |
|---|---|
| 多年真实数据与双基准 | 输出股票、宽基与对应行业的请求和实得区间、覆盖、缺口、停牌和预热。冻结趋势候选、双基准和费用后，可复现成交或未成交、现金、权益、净值、回撤及样本外表现。全现金时不主动交易留现金；已有持仓时沿用初始批次，若两个基准重合则注明。 |
| 除息与开盘执行 | 用江西铜业 2025-07-21 登记、07-22 除息的记录核对每股实际派息 0.70 元、除息参考扣减约 0.6965 元、参考昨收 23.70 元及原始开盘 23.73 元。合成案例中只改开盘后的高低价，两次开盘成交结论须一致。 |
| 在途权益与到账 | 单独演练 100 股原价 10 元、每股派 1 元，除息价 9 元。到账前持仓 900 元加应收 100 元，到账后应收转现金。另演练每股送 1 股、除权价 5 元，上市前原 100 股可卖，另有 100 股应收。两例净值均为 1,000 元，重复执行结转只记一次。 |
| 时点、研究边界与离线重放 | 先发布初版并冻结计划，再修改草稿、补数或录入更正。旧计划按原快照重放。新发布版本仅从生效时点起参与决策。无模型凭据、无网络但本地输入齐备时，计划与实验仍能生成。公开研究导出不含账户资料。 |
| 可执行性与共享资金 | 给两个合资格候选仅一笔可用资金，倒置输入顺序所得股数、总占用和排除理由一致。验证停牌、不可卖批次、基本面未知、策略未准入与现金不足时相应动作受限。 |
| 预留、部分成交与重启 | 预留 1,000 元，含费成交 400 元。普通单日计划收盘释放 600 元，全未成交则释放 1,000 元。分别覆盖显式跨日条件到期、未决委托部分成交后撤单、程序次日首次启动，最终可分配余额一致。 |
| 前向演练与真实记录 | 盘后冻结、次日结算、重启重读及迟到回报可追溯；重复结算不改变余额。真实未执行的计划也保留影子结果。错过的当日登记保留缺口，事后补算单列为重建。 |

**M0a 工程准出。** 同时交付多年真实行情、冻结趋势策略与双基准完整回测、带有效期和证伪条件的已发布档案，以及按冻结账户和规则生成的唯一计划。前向登记与影子结算通过上述演练即可投入日常使用并启动 M1。真实取数验收与确定性演练分别保留结果。

**M0b 运行签收。** 连续 20 个真实交易日逐日盘后登记。观察日计入，演练、漏登和事后回填不计入。已到执行或结算时点的计划应有结果，最后一个交易日面向下一时段的计划可保留待执行并于到期后追加。此门独立签收运行连续性，策略准入依预登记实验判断。

## Out of Scope

- M0 不含券商自动下单、常驻实时监控、分钟级预测和日内逐档网格撮合。
- 全市场选股、复杂组合优化、单股高维概率模型、自动调参与自动发布策略均不作为首版交付。
- 旧数据库、旧 CSV、旧 CLI 输出及旧前端兼容不在重构范围。按日归档所有公告 PDF 和追补历史基本面首发版本不作为 M0a 准出条件。
- M1–M4 属于后续条件性扩展。M0 的工程或运行签收不要求策略盈利、取得正式使用资格或输出概率。

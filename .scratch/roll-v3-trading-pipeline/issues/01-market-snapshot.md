# 01: 冻结并重读一段真实行情

Status: ready-for-agent

归属：共享数据基础。依据：[主方案 §5.2、§5.5、§11.1](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 经本地 CLI 同步江西铜业一段真实日线，冻结可引用的数据快照，按指定交易日和用途重读。

**Blocked by:** None (can start immediately)

## 验收

- [ ] 展示数据源、单位、交易日、可得及实际取得时间、质量和覆盖。记录输入范围、版本水位及选源规则。
- [ ] 演示初版、迟到更正及撤回。相同截止时点分别查询严格历史、重建研究与当时真实运行视图，可见值或缺项符合各自时间条件。
- [ ] 断网重启后旧快照仍返回初版；使用新快照能查到生效更正和来源。后续研究、实验和计划均可引用同一快照。

# 06: 次一交易时点模拟成交

Status: ready-for-agent

Resolution: completed
Closed: 2026-11-26

归属：共享执行核 · 次日撮合。依据：[主方案 §5.3、§7.3、§9.5](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 通过 CLI 给定盘后冻结的意图，在下一合法交易时点按当时已知原始报价和交易规则结算，显示成交明细或未成交原因。

**Blocked by:** [01 冻结并重读一段真实行情](01-market-snapshot.md)、[02 建立真实账户镜像](02-account-mirror.md)

## 验收

- [x] 跨休市日定位下一交易时段，使用日期及券种适用的停牌、涨跌停、T+1、可卖量、申报单位、费用和滑点条件。成交数量受当时可用资金约束。
- [x] 固定所有开盘可见输入，仅改变开盘后的最高价和最低价，两次开盘模拟的成交判断、数量和价格相同。
- [x] 成交后现金、批次与费用可对账；停牌、不可卖、限价无法成交各有原因，未成交时可查原意图。

## Comments

冻结原始开盘按日期和券种撮合。真实除息报价与开盘后高低价不影响撮合的案例均已核对。 [验收记录](../acceptance.md)

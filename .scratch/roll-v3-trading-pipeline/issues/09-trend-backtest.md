# 09: 完成多年趋势回测与双基准

Status: ready-for-agent

归属：研究流水线 · 实验结果与对照。依据：[主方案 §7.2–7.4、§13 M0a 第 2 项](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 在冻结的多年真实数据上，用盘后计划和前向模拟所用的裁决与执行规则，从相同初始账户运行趋势候选、买入持有、不主动交易三个连续账本。

**Blocked by:** [04 交付多年量价与行业对照](04-market-industry-research.md)、[05 跨除权日结算在途权益](05-settle-entitlements.md)、[06 次一交易时点模拟成交](06-next-session-fill.md)、[08 生成账户唯一生效计划](08-after-close-plan.md)

## 验收

- [ ] 三条路径同窗、同权益与成本口径。全现金起步时不主动交易保留现金；已有持仓时沿用相同初始批次，报告说明两条基准是否重合及原因。
- [ ] 逐日可追踪信号、次日成交或未成交原因、成本、权益、现金及净值；汇总收益、回撤、换手、费用和样本外结果。影响持仓路径的缺口须补齐再签收。
- [ ] ExperimentResult 可追溯到假设、协议、策略、数据、执行版本和初始批次。当前公告或新发布约束不会倒灌到历史；重建窗口明示可得性假设。
- [ ] 同一冻结实验离线再跑可复现。失败或证据不足也保留并可回引到研究档案，实验完成不自动更改策略资格。

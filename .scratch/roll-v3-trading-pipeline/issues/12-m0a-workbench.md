## 验收

- [x] 从公开研究输入发起个股研究，核查多年覆盖及行业依据，引用公告提出可证伪假设，查看冻结趋势实验与双基准，发布带有效期的结构化档案。验收记录列出所用快照、档案、实验和策略版本。
- [x] 从盘后入口按同一截止时间读取档案、注册状态和本地账户，检查状态与 P0–P4 理由，冻结唯一计划。演示正式观察与候选影子运行并存；离线 CLI 重放与网页显示的计划版本、动作和理由一致。
- [x] 用受控日历完成次日结算与复盘，将证伪证据送回研究，发布修订版。对照生效前后两份计划，验证旧版仍可离线重放，新版按新约束裁决。
- [x] 同时提交多年实取覆盖、完整趋势与双基准报告、已发布档案、唯一计划，以及在途权益、预留到期和前向演练结果。旧入口退出日常流程。签收后可日常使用并启动 M1。

# 11: 对照前向影子与真实执行

Status: ready-for-agent

归属：决策流水线 · 记录、复盘与研究反馈。依据：[主方案 §4.3、§10.1–10.3、§11.1](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 将盘后冻结计划带到下一交易时段。通过 CLI 并列查看当时计划、连续影子结果、真实执行及偏差，能把发现的问题带回同一股票的研究档案。

**Blocked by:** [05 跨除权日结算在途权益](05-settle-entitlements.md)、[06 次一交易时点模拟成交](06-next-session-fill.md)、[08 生成账户唯一生效计划](08-after-close-plan.md)

## 验收

- [ ] DecisionLedger 引用冻结计划、数据、账户、策略与研究版本。影子账本独立连续演化；真实成交须经用户确认，未执行或拒绝时仍保留原因与影子结果。
- [ ] 固定时钟下演练盘后登记、次日成交及未成交、重复运行、离线重启和迟到回报；每笔只结算一次。漏登留缺口，补算标记为历史重建。
- [ ] 复盘区分研究假设、适用性、数据质量、执行偏差、用户偏离与正常波动。用一条触发证伪的证据生成可追溯的研究待办，关联原假设和计划；重新研究须经显式发布才影响未来计划。

# 10: 结清计划资金预留

Status: ready-for-agent

归属：决策流水线 · 计划到期与可用资金。依据：[主方案 §9.3、§11.1、§14](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 在 CLI 查看当前计划的剩余承诺及下一轮裁决可分配资金。按目标交易所收盘、条件有效期及实际委托结果结清对应余额。

**Blocked by:** [08 生成账户唯一生效计划](08-after-close-plan.md)

## 验收

- [ ] 单日预留 1,000 元，含费实际成交 400 元，收盘释放 600 元；全未成交释放 1,000 元。程序跨收盘重启首次读取也得到相同余额。
- [ ] 显式跨日条件保留到期或撤销；券商未决部分保留至成交、撤单或失效。两者重叠时只占用一次，跨日条件到期仍保留待决委托的余额。
- [ ] 覆盖部分成交、撤单和迟到回报；券商可用资金中已冻结的同笔款项只计一次。新裁决使用更新的余额，能按原快照读回此前计划。

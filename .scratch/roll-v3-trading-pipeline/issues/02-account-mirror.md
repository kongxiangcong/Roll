# 02: 建立真实账户镜像

Status: ready-for-agent

归属：决策流水线 · 账户输入。依据：[主方案 §9.1、§11.1](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 从用户确认的现金和存量持仓建立本地账户，经 CLI 录入真实成交和生效的风险预算，按决策时点查询。

**Blocked by:** None (can start immediately)

## 验收

- [ ] 展示账户总现金、可用现金、已知可卖量、持仓批次以及资金需求、单股和行业集中度、总仓位限制；未知买入日可保留。
- [ ] 录入一笔实际买入和一笔迟到更正，重启后可分别读出原快照与后来获知的现金和股数；同一笔成交重复导入只记一次。
- [ ] 真实、回测和影子账户可从相同批次结构分别初始化；模拟账本变动后真实账户余额和持仓维持原值。

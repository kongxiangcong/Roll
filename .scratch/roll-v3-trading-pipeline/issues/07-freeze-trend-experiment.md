# 07: 冻结趋势实验并重放信号

Status: ready-for-agent

归属：研究流水线 · 策略实验与登记。依据：[主方案 §4.3、§7.1–7.4、§11](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 将研究命题落实为一个低参数日频趋势候选，经 CLI 在检验前登记实验协议和 StrategySpec，再按冻结快照逐日输出信号。

**Blocked by:** [01 冻结并重读一段真实行情](01-market-snapshot.md)

## 验收

- [ ] 登记假设或其引用、基准、适用范围、参数、进退条件、成本、信号及成交时点、评价标准、开发与样本外窗口，取得可查的协议及策略版本。
- [ ] 按日重放可见行情，报告预热、条件、信号或缺项。改参数生成新版本；已经揭示的验收区间标明其用途限制。
- [ ] StrategyRegistry 可按版本与时点返回候选的状态和范围。此趋势版本可供模拟账户指定运行，正式主动策略集合可以为空；研究档案白名单本身不会授予准入。

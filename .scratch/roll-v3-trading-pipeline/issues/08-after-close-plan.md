# 08: 生成账户唯一生效计划

Status: ready-for-agent

Resolution: completed
Closed: 2026-11-26

归属：决策流水线 · 盘后裁决与计划发布。依据：[主方案 §4.2–4.4、§9.1–9.5、§11.1](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 一次本地盘后 CLI 调用按 as_of 冻结行情、账户及预算，读取当时有效的 ResearchDossier 和 StrategyRegistry，识别市场、行业和个股状态，生成账户内各标的下一交易时段唯一生效的 TradingPlan。

**Blocked by:** [02 建立真实账户镜像](02-account-mirror.md)、[03 发布第一份个股研究档案](03-research-dossier.md)、[07 冻结趋势实验并重放信号](07-freeze-trend-experiment.md)

## 验收

- [x] 按顺序展示 P0 可执行方向和可卖数量、P1 现金与风险上限、P2 投资逻辑、P3 准入与适用性、P4 信号与目标。市场、行业与个股状态可各异或未知。每个候选均可查看选择或排除原因。
- [x] 演练过期档案、基本面 unknown、命题 broken 和策略仅为候选。依赖这些条件的新增风险受限，既定风险退出仍遵守 P0；真实账户可出观察计划，影子账户可使用冻结候选。
- [x] 两只候选股共享一笔可分配资金，颠倒输入顺序后分配和理由一致。按预登记优先序和证券代码稳定分配，计入预计费用及有效预留，未成交卖出款不参与分配。
- [x] 每个账户、证券、交易时段仅一个生效版本。原子保存替代关系、资金占用与快照引用；计划列出目标、执行窗口、失效、撤销、退出及无法成交时的处理方式。
- [x] 无网络、无模型凭据时同一组冻结输入生成相同计划。改草稿或加入自由文本后结果一致；新发布约束仅影响生效后的新决策。

## Comments

按 P0–P4 原子冻结计划与预留。双标的反序、过期研究、停牌退出待执行及离线重读均已验证。 [验收记录](../acceptance.md)

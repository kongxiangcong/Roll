# 13: 签收连续 20 个真实交易日

Status: ready-for-agent

归属：决策流水线 · 真实运行签收。依据：[主方案 §13 M0b](../../../docs/design/architecture/roll_v3_trading_pipeline_spec.md)。

**What to build:** 在日常使用中逐交易日登记盘后计划，通过 CLI 核对连续 20 个真实交易日的当时冻结记录及到期结果，独立签收 M0b。

**Blocked by:** [12 切换 v3 工作台并签收 M0a](12-m0a-workbench.md)

## 验收

- [ ] 按交易所日历逐日列出登记时点、计划版本、观察或交易、实际执行或未执行原因、影子结果及异常；观察日可计入。
- [ ] 漏登打断连续窗口；演练或事后重建保留自己的标记。用当时冻结的记录核查 20 日连续性以及所有已到期结果。
- [ ] 第 20 日面向下一交易时段的计划可显示待执行，到期后追加结果。签收对象为日常运行连续性，策略资格仍由实验协议决定。

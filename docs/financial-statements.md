# 单股三表联读

“持仓与关注”中打开单股“三表联读”，可查询已保存事实或指定系统已知截至时间。当前版本按当时实际可得观察选择；后来的修订不倒填旧知识截止。资产负债表是报告期末时点，利润与现金流是年初累计。

只有证券、报告期、主体、币种、单位和来源更新匹配的事实才同组，未知口径分别显示。每表显示版本、原字段、缺口及原响应；已核验语义附发行人PDF页码。资产−负债−权益按来源舍入精度显示差异，失败待核，不改变原值。当前仅600362最近五期观察；2026半年报已验证合并人民币元，其余资产负债/现金流语义缺口仍可见。

“有限采集资产负债与现金流”要求来源配置显式启用、合法有限范围及独立AKShare运行环境，采用共同8HTTP/18秒/8MiB、零隐式重试预算。可取消并保留已收原件。已封口验收预算不自动重开。原利润表入口保留；联读不自动新增利润表请求。

GET /api/market/financial/{instrument}/statements，支持known_by；POST同路径/collect复用幂等命令；POST /api/market/financial/runs/{run_id}/cancel。查询不访问网络，不修改账户，不授模型或资金权限。

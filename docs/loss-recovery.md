# LOSS原因绑定恢复

在设置中先重新确认损失边界，保留原损失范围；在模型维护登记与原撤回或到期记录显式关联的后继资格，然后打开“LOSS原因绑定恢复”，读取当前条件、选择后继资格并核验。核验READY后，明确确认保留原起点、峰值和暂停历史，再提交恢复。

该操作只解除所绑定的LOSS新风险限制。旧资格保持关闭，其他暂停原因和恢复锁仍生效；资金增加、行情反弹和重启均不自动恢复。新的阈值须高于历史峰值，且再次越界会重新暂停。条件变化需重新核验；请求结果不确定时保留原确认重试，不换键重复操作。

恢复回执、父检查和规则均需原件可验证。缺少当前账户/估值/资金/部署/验证/后继资格时保持暂停并显示缺口。METHOD回执仅供隔离工程验收，不授予真实权限。

公开接口：POST /api/funding/loss-recovery/checks；GET checks/{check_id}；POST checks/{check_id}/activate；GET /api/funding/loss-recovery/receipts。调用方必须使用实际读取的账户/资金/生命周期版本及独立幂等键。

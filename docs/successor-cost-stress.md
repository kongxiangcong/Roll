# 后继政策保存前缀的费用诊断

后继政策完整设计与验证区，在参数绑定和 METHOD 帧已经保存后，展开“已登记费用压力诊断”。显式运行使用冻结 g5 的三档佣金、三档滑点，逐项改变一个费用字段；不允许客户端提供网格或选择赢家。

同一原模拟器处理完全相同的保存帧、政策、现金、迁移和各 lot 期限。基准场景逐帧核对原结果，保存六个场景的成交、费用、净值、缺失和指纹。原模拟器、政策、统计方法和参数冻结模块字节不改。原完整冻结依赖和本次方法/输入/结果以内容地址归档。

计算在业务 Python 的隔离子进程执行，网络禁用；最多200帧、30秒，输入/结果各8MiB。只查询指定前缀，后续帧不改变旧重放。幂等命令不可换内容。读取保存结果不重算，显式重放使用原归档输入并检查方法与继承依赖指纹，在同一预算内重新计算。

始终是 METHOD 工程诊断，不能输出 PASS。已知回撤突破原冻结风险界限则保留 FAIL，否则 INCONCLUSIVE。存在未知净值时完整期收益/回撤不计算；已观察净值能证明的回撤下界仍可保留先前硬失败。该下界不伪装完整期统计量。费用来自研究场景，不是账户真实券商费用。

剩余真实输入、共同风险匹配基准、时间分段、执行延迟、冻结邻域与迁移、独立成熟支持仍逐项缺失，本功能不能使完整实验冻结或正式资格成立，也不改变拟合、SEALED或确认性访问预算。

API：`POST/GET /api/research/policy-successor-freezes/{id}/cost-stress`；`GET /api/research/successor-cost-stresses/{id}`；`POST /api/research/successor-cost-stresses/{id}/replay`。

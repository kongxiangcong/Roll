# 来源输入与冻结模型消费者

中心绑定下 POST/GET `/api/research/successor-primary-center-bindings/{id}/input-consumer`；GET/POST replay `/api/research/successor-input-consumers/{id}`。此消费者拥有独立状态，不修改原手填帧、旧冻结、训练额度、账户或真实前向时钟。

RESEARCH只接受同证券、当前盘后宿主截止、冻结之后生成且离线重放一致的原PostClose输入包；模型必须为非METHOD，所有原来源缺口、版本来源、当期规则与特征日历均核对。当前原输入包仍明确状态/行动UNKNOWN，真实正向准入未验收。这里提供原件到特征、冻结模型预测及独立v2模拟的管线，不称已解决02—04实际authority。

METHOD_VALIDATION仅测试环境允许：按原CAL观察日读取冻结输入。状态、行动、规则、bar及连续21特征日期核对后才调用冻结predict；拒绝时不调用预测。冻结模型和校准器只读，不拟合、不读SEALED。小数价格/概率不静默舍入。

版本原子比较，幂等键冲突拒绝；拒绝记录也保存版本和缺口，但不推进会话或状态。修复了版本200可保存201却不能续写的请求上限：版本不等于会话数；资源仍独立限制200会话/8MiB输入输出/30秒worker。两次消费之间漏掉的日期加入无bar、无预测的UNKNOWN帧，不补历史成交或预测。仅支持显式空初始持仓，不假定清仓或平移迁移期限。

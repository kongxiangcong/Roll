# 17 · 研究登记、取数边界与后继责任

协议登记保存设计，不能授予模型资格或构成前向起点。当前 M0 仅为 `HISTORICAL` 今天名单条件性回溯，历史名单、历史特殊状态和当时可得性未证明。07/08 的工程账户与资金是隔离合成输入，不能导入为用户真实基线、资金授权或前向起点。

## 公开接口

| 路径 | 实际行为 |
|---|---|
| `POST /api/research/datasets` | `archive_id` 只选宿主 `ROLL_DATA_DIR/research-inputs/<id>/browser-live.json` 包；校验每份原件 SHA、原 Parquet 与原快照逐行一致；不接任意文件路径，不导入来源账户 |
| `GET /api/research/datasets[/{id}]` | 原运行/快照版本、覆盖日期/缺字段、明确股票身份、数据指纹、分片及限制；不返回封存事实 |
| `GET /api/research/datasets/{id}/partitions/DEVELOPMENT` 或 `CALIBRATION` | 直接返回宿主生成的对应 Parquet 分片事实。19 不需先读全档再过滤。校准前20行只为历史特征上下文，不拟合其标签；未知/错误行保留，不因清洗缩窗 |
| `POST /api/research/protocols` | `dataset_id` 可缺（DRAFT），`basis` 必填；已登记证券/重叠日期需 `predecessor_id` 关联，不能换包名或协议名恢复独立封存 |
| `GET /api/research/protocols[/{id}]` | 不可变身份、设计、数据/登记代码/设计指纹、缺口、前序、未授能力；旧版本不会被新访问/失败改写 |
| `POST /api/research/protocols/{id}/attempts` | 先登记 `category/partition/configuration/basis` 再计算；配置保存候选、特征、期限、阈值、提示词及人工筛选依据。17不执行拟合 |
| `POST /api/research/attempts/{id}/finish` | SUCCEEDED/FAILED/ABORTED 与原因、产物指纹追加；SQLite短事务并发只允许一次终态，成功执行不等于研究PASS |
| `GET .../attempts` / `GET .../attempt-manifest` | 本版本尝试 / 全部关联前序尝试。失败、中止和启动后中断保留；manifest不能借后继版本丢弃失败 |
| `POST .../freeze` | `attempt_ids` 必须覆盖完整谱系。漏项、运行中、模型/校准/政策/验证代码缺口拒绝并持久审计；19/20完成真实产物前本实现不会接受完整冻结 |
| `POST .../sealed-input` | 需要非空访问理由，返回封存分片并先持久记录输入暴露；不计算标签/候选策略结果，不是确认性PASS查看 |
| `GET .../audit` | 登记、拒绝、失败、中断、暴露、检查点及偏离按顺序持久保存 |
| `POST .../checkpoints` | OPERATIONS/SAFETY_STOP/USER_STOP只记运行/停止，不改统计结论。EARLY_PASS拒绝并记OPTIONAL_STOPPING_DEVIATION；STATISTICAL_FINAL在完整冻结前拒绝，21后续负责实际判定 |
| `GET /api/research/deadline-preview?start=...` | 仅预览现代中国标准时间三自然月、月末夹取，含跨年/闰年；不写实际起点。实际首个冻结模型未来预测归30/32 |

每个实际 `PRIMARY_FIT/G5_NEIGHBOR` 计算必须先登记，五次预算包含失败、中止、中断及关联前序；一次校准同理。FEATURE/HORIZON/THRESHOLD/PROMPT/MANUAL_SELECTION 是变更/选择记录，不能以此冒充未登记实际拟合。阈值邻域可重用同一已冻结预测，不额外训练。19负责执行60秒实际拟合限制、实际标签支持/训练/校准与真实产物校验；17不造训练结果。宿主无法证明外部未报告尝试不存在，完整性结论限于登记及执行边界，不接受只提交最佳结果作为全尝试证据。

数据 fingerprint 包含源包SHA、原件/Parquet SHA、源适配版本、明确身份、过滤代码SHA和分片SHA。原 `available_at` 保留；分片返回本次消费知识截止，消费者用自己的截止重新检查，原 request 的 `point_in_time_input_allowed` 只针对原请求。当前修订历史不因此成为当时可得。缺值、未确认状态/公司行为不可评分时必须保留未知/区间，不默认无事件、无费用或训练未知标签。原容器可包含 qfq 和其他组；模型输入只选明确RAW分片，不混复权。

## 真实覆盖驱动的 M0

实际源 SSE:600519、181交易日（2026-01-05—09-30）。窗口分为80开发（至05-08）、20标签隔离、40校准（06-08—08-03）、20隔离、21封存（09-01—09-30）。选择使用日期/身份/覆盖元数据，未计算候选收益、标签或最终策略结果。历史原输入先前已公开；本轮误打印06-22—06-30与09-21—09-30原价/qfq输入的具体来源SHA/日期在宿主 `engineering-exposure.json` 和协议登记审计保存，独立性UNPROVEN，不能声称未见输入。工程取价/哈希检查与一次确认性结果判断分开。

一个候选 PRICE_VOLUME_LOGIT_V1：开发拟合价格5/20日收益、20日波动、相对量；L2逻辑回归λ1、标准化仅开发；校准截距仅校准窗口，阈值0.60、期限20交易日。19实际验证可评分支持，不满足则保留失败/不足，不用方法数据冻结真实模型。20完成实现与方法验证，21再确认性访问。

主要目标为与必要CASH/START_HOLD/MA5_MA20对照的20日费用后NAV改善，一次最终单侧95%下界高于25bp，全部必要比较及风险/支持门槛同时满足。研究假设普通沪市100股/T+1、100万元合成模拟现金、最高50%敞口、10%最大回撤、比匹配持有基线额外回撤不超2pp、20%最低覆盖；不是用户实际资金或收费事实。25bp依据显式研究往返成本21.2bp、半仓10.6bp NAV、约两倍上调取整，未根据收益调阈值。

依赖处理提出按日配对的20交易日移动块bootstrap，同日证券整组，2000次/seed1701，20/40块长度敏感性；至少30有效块、校准每类20、选中成熟40、五个固定概率箱每占用箱20。30块是保守资格条件，不是已验证定理；平稳/弱依赖、有限样本覆盖、概率可靠度/区分与选中子集支持须20实际验证/技术审阅。当前21封存输入最多1个20日期限成熟标签，有效20日块上界0，无法确认性PASS；尚未计算实际标签。新未使用窗和前向成熟证据仍需30/32，三自然月不会因支持不足而延期。

G5预登记时间三段、佣金3/6/30bp、双边滑点5/10/20bp、NEXT_OPEN/NEXT_CLOSE/额外一交易日/价窗外不成交、0/50/100%部分或错过执行，λ0.5/1/2、回看15/20/25、阈值0.55/0.60/0.65一次一项邻域。只一个主要候选，邻域不能挑赢家；压力净值不反转到对照以下、风险仍受限，支持不足INCONCLUSIVE，不能事后缩域翻原结论。19/20/21逐项实现/执行，不把此登记当这些检验通过。

正式期每日实际运行检查人工延迟/成交/费用/输入；开发拟合特征1/99百分位参考，最近20个合格观测≥20%越界或必需输入覆盖<80%限制对应能力，是运行哨兵而非收益统计FAIL。成熟结果在事先30交易日复核点和资格到期复核，不增加确认性PASS点；未成熟不评分或学习。政策变更登记依据+新指纹+后继。第一次实际冻结模型未来预测起点后三自然月硬终点、月末夹取，原期限不因切后端、缺数据、亏损或成熟不足延长。用户/安全暂停和统计判定分别留痕。

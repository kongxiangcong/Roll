# 版本化诊断绑定工程检查

在联合证据汇总版本下选择同源已终态阈值记录与迁移审计。核对费用、时间分段、CASH、原基准、入场、CAL概率、联合场景、阈值与迁移九类工件。未终态可变父记录、错前缀或协议不接纳；CAL窗口仍单列，不拼入执行窗口。

九类绑定可报告一致，表示这些诊断已保存且来源一致。工程交付仍未完成，完整冻结仍NOT_ADMITTED：后继真实输入消费者/准入与拟合邻域绑定尚缺。原主要模型中心值可在另有精确工件映射后复用，不能凭名称假定已有邻域工件，更不能补训或选择赢家。

METHOD与训练家族清单在创建时分别快照；任何RUNNING阻断当时诊断包完整性，后来的终态不改旧快照。历史失败保留。阈值候选硬FAIL继续进入G5，其余INCONCLUSIVE。G6/G7属于启运后资格，不作先有成熟前向才能冻结的循环前置。

最多8MiB输入，不重跑组件引擎/拟合/采集，不改旧协议或确认性额度。原件/方法/代码指纹保存，嵌套损坏拒绝，支持幂等、查询、重启与重放。API：`POST/GET /api/research/successor-joint-reviews/{id}/completion-check`、`GET /api/research/successor-completion-checks/{id}`、`POST /api/research/successor-completion-checks/{id}/replay`。

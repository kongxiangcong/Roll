# 公司研报页面

主导航选择“公司研报”，输入已登记名称、别名或上市代码，点击解析。多身份时明确选择；未匹配只表示本地映射未登记，不能猜公司或宣称没有公开资料。

已有报告可直接阅读，点击“复用此报告并查看生成任务”查看原任务和已保存阶段。该操作不重新生成章节。报告历史与文件交付历史独立选择，下载链接固定绑定该交付版本。来源缺口和报告PARTIAL照实显示；文件COMPLETE只表示文件已生成，不改变经济审核。

新研究选择截至时间和资料策略，可固定共享快照。未来时间拒绝；现在取得旧资料按当前重建阅读，不冒充历史时点可得。复用材料生成新报告仍可能调用CODEX；刷新仅请求已配置来源范围。任务可取消/显式重试，错误及检查点保留。明确选择公司会保存深链，重载可恢复该公司的上次新任务；查看旧报告任务不会替换该恢复指针。

PDF失败保留Markdown，重试只追加新交付版本，不重新研究或覆盖旧文件。完整正文以安全React文本/标题/表格呈现；来源HTML不执行，外部图片不自动加载。受控文件合同见company-report-delivery-api.md。

“打开同快照公司跟踪”使用同公司/快照读取共享经营研究、时点、原件与用途限制，支持返回同快照报告。独立跟踪只读，不自动把公司加入账户或关注名单。要持续检查来源，在“持仓与关注”明确登记后使用日常工作流。A/H证券在列表分别显示市场/币种，多证券跟踪需明确选择，不把公司价值当某一类股价格。

真实当前样例为承德露露的既有PARTIAL报告，当前定价blocked、历史基准研究conditional。10网页验证沿用08已归档真实CODEX结果，没有新CODEX请求；新任务控制在API-only隔离副本演示并最终取消。完整联合验收以12票矩阵为准。

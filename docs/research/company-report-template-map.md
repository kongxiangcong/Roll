## 第9节的扩展

| 子节 | 原依据→Roll输出 | 宿主检查 |
| --- | --- | --- |
| 9.1 方法适用性 | 02§9、05、15→FCFF/周期正常化/专用模型缺口，说明行业惯例 | 金融企业不强套；EPV不当独立验证；未实现银行/SOTP等仅方法章节 |
| 9.2 事实与正常化口径 | 15年报三项→事实版本、利息分类、税盾、调整前后值/理由/证据 | 工业贸易金融/合并抵销、联营、受限现金、维持投资、少数股东不重复；江西铜业两年不等于全周期 |
| 9.3 年度经营与FCFF预测 | 15完整路径→量价/收入/利润率/税/Capex/NWC逐年现金流 | 披露/确定性/假设标记，同单位同主体，增长与再投资/回报一致 |
| 9.4 折现率与权益桥接 | 15 WACC分解及equity_bridge→日期/币种/税盾/风险溢价/beta/债务权重、EV至归母权益逐项 | FCFF配WACC；桥接只一次；稀释股数与金额同尺度，净债务和明细互斥 |
| 9.5 情景估值 | 02参照带、15场景→经营条件、输入/结果版本、有条件范围 | 权重为研究假设、范围非置信区间；blocked不显示可用区间/速览价格 |
| 9.6 敏感性与终值依赖 | 12模型自检、15→WACC/g网格、终值占比及翻转条件 | WACC>g、终值基础有效；75%为复核提示非失效定理；样本外写明外推 |
| 9.7 反向现价要求 | 15→固定前N年路径，N+1终值FCFF要求/可比稳态收入 | A+H同日币种两类市值；无利润率不转收入；不是唯一隐含增长或市场因果 |
| 9.8 适用交叉参照 | 02、05→同业/资产/历史估值分位、周期位置和证据 | DCF情景与EPV共享输入不构独立检验；缺外部对照如实未通过 |
| 9.9 经济审核与缺口 | 12/15→逐项审核、用途、局限、下一验证 | unreviewed/conditional/blocked/reviewed保留证据；计算通过不等审核、收益或正式资格 |

所有质量记录保存`rule_id/source_hash/source_line/applies/severity/outcome(PASS/FAIL/UNKNOWN/NOT_APPLICABLE)/evidence/reason`；NOT_APPLICABLE必须有行业或产品范围依据。原硬项失败不被删除/静默降warn，完整报告必须满足全部适用硬项。有限取数后允许PARTIAL并列所有失败，避免因为没有完整年报/行业数据永久等待。完整模型输出不是完整报告，不等于事实已核验。模板字数、图数和厚底稿仅用于独立报告，日报消费同一共享核心但不调用整份模板。

# 用自动验证与模型技术审阅替换必须由专业人士独立复核的准入前提

用户在 Q7 明确没有专业人士、全依赖模型能力，不安排独立人工复核费用；在 Q9 确认取消专业人士独立复核的必备门槛，采用自动验证、模型技术审阅、确定性资格检查和用户资金启用的正式准入路径。本决策于 2026-10-07 接受，Codex 与 DeepSeek 为可切换的模型技术审阅后端。

原 PRD V1.2 的 EVAL-14 要求非候选主要开发者的专业人士完成独立复核，EVAL-15 将其列为发布前提，AT-53/75 检查缺人时正式能力关闭。保留这一前提会使产品在已确认的人力条件下只能停在监控/影子。本决策修改该准入制度；人工独立复核不再是 P0 前提，模型技术审阅也不被称为人工独立复核。

正式准入保留如下证据链：

1. 按冻结协议自动执行收益预测模型 G1—G7 所需的数据、工程、时间外、经济价值、稳健性与前向成熟结果验证，保存输入、代码、全部尝试、测试与统计结果。确定性风险回退政策仍按其单独冻结的协议验证，不借此替收益模型免除 G1—G7。三个月期限到达仍可结束为 FAIL 或 INCONCLUSIVE，不承诺取得 PASS。
2. Codex 或 DeepSeek 承担模型技术审阅，读取冻结材料、开展复现检查，形成 ReviewRecord，记录模型与后端、审阅范围、材料指纹、异议、处理依据和局限。模型意见不能替代检验结果、成熟样本或统计证据；两后端一致也不构成人工独立复核。
3. Roll 的确定性资格检查依据冻结协议、验证证据和审阅记录判定是否满足正式资格条件。模型自然语言不得签发能力授权、修改门槛或抹除未解决的必需问题，研究 Agent 不得自签资格；无法自动核实的必需项保持未通过或证据不足。
4. 正式验证结论 PASS、模型技术审阅记录完整且阻断事项已按证据处理、确定性资格检查通过后，用户确认是否在自己的有效资金边界内启用正式建议。用户不承担选择统计方法或代签技术复核的职责；部署指纹、账户、行情、适用范围、期限和撤回门禁继续有效。任何必需条件缺失，继续监控/影子。

界面、验证交付与资格说明须如实标注“未经人工独立复核”，并区分自动验证结果、模型技术审阅与正式能力状态。完成协议、证据归档与审阅记录即可按实际结论交付验证工作，FAIL 或 INCONCLUSIVE 不因缺少 PASS 被视为未完成；也不能因此启用正式建议。

这一决定提供了适合当前人力条件的自动验收路径，也减少了人工独立专业质疑这一层保障，不能表述为与原人工独立复核完全等价。对应要求见 [PRD V1.3](../../ashare_market_decision_prd.md) 的 1.4、3.3、13.4—13.6、EVAL-14/15、RUN-05、AT-53/75、M3/M4 及附录 B/D；相关术语见 [GLOSSARY](../../GLOSSARY.md)。

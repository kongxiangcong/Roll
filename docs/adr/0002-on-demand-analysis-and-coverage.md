# 允许盘后或手动按需分析，不以每日三阶段覆盖作为使用前提

2026-10-07 实现对齐中，用户明确不需要交易时段持续覆盖，允许只进行盘后复盘，或由用户手动发起复盘与账户同步；用户也可在任意交易时段唤起分析，查看趋势、量价关系及符合资格与时点约束的机会概率。Roll 因此以按需分析和盘后复盘为可独立成立的使用路径，不要求用户为使用系统维持每日盘前、盘中、盘后完整覆盖。

后续 Q5/Q6 已确认：采用“当时可得市场观察＋最近完整日线的机会概率”，概率保留原数据截止时点、期限和资格状态；未通过验证的概率仅进入研究视图。采用“按需分析＋盘后自动记录”：程序运行且存在已冻结、可运行的影子实验时，在约定盘后检查点保存一次影子记录；未运行或条件不满足则保留缺口，不要求交易时段常开。此决定约定产品行为，不是在开发期间创建桌面自动化或安排外部任务。

该决定收窄 PRD V1.2 的 BR-06“盘前、盘中、盘后均留记录”、第 5 章默认调度，以及 M1/AT-82 对三阶段记录的交付表述；已合入 [PRD V1.3](../../ashare_market_decision_prd.md)，后续规格与验收以修订后的条款为准。[V1.2 原文](../alignment/baselines/ashare_market_decision_prd.v1.2.md)仅作历史基线，原三阶段强制条件不再是当前必验门槛。保留阶段类型和已有记录的连续关联，不为没有运行的阶段补造当时观测。

代价是无法承诺覆盖未运行时段，也不能将事后补取数据视作事前预测归档。每次分析仍保留实际数据截止时点、获取时间、缺口、账户确认时点与预测期限。按需方式下正常未启动不等于承诺覆盖期间的运行故障，不因未每日使用就持续制造“监控中断”告警。账户确认在依赖账户的分析或动作入口按用途检查；没有使用系统的日期不因此要求用户每日打卡。

只有盘后/手动运行的使用安排不解除账户确认、日线模型输入完整性、技术资格、资金授权或影子隔离要求；任意时点唤起也不自动引入分钟级预测能力。

连续影子试验的账本连续性仍须保留，采样与缺失政策需要适应实际运行安排并预登记。重复点击同一输入不增加独立研究样本；按需诊断与预登记盘后样本保留来源区别。不得在次日重跑时将补算结果写成昨日已归档的前向预测。

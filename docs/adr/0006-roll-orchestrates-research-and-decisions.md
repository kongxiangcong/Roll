# 由 Roll 编排研究与盘后决策，研究助手按任务单次执行

2026-11-26 决定将标的、研究问题及其进度交由 Roll 管理，以便从一条复盘线索追溯到输入材料、实验结果和发布版本。用户从 Roll CLI 或工作台发起任务，二者调用同一本地编排入口。Roll 按需调用进程外的研究助手，盘后决策则由 Roll 的确定性规则独立执行。本决定取代 ADR 0005 中由外部助手主持研究的调用方向，沿用其中的人工发布、策略独立准入与本地账户约束。[ADR 0005](0005-external-research-and-deterministic-admission.md)

Roll 在 SQLite 中保存任务、尝试和结果引用。每次尝试使用固定的公开材料，在受限环境中单次执行。助手仅取得本次研究获准的公开输入，返回假设、证据缺口、草稿或开发实验请求。Roll 在本地执行开发实验，将实际结果及引用附入草稿，由研究者显式发布。独立验收、样本揭示和策略准入各有专用入口。账户快照、成交和风险预算由本地决策流水线读取，已发布计划可以断网重放。

单次受控编排提前到 M1，以江西铜业 E0/E1 对照验收。M0b 按真实盘后登记独立推进。根据新结果自动选择下一组实验属于 M4 的条件性工作。[开发路线](../design/architecture/roll_v3_trading_pipeline_spec.md#13-开发路线与里程碑验收) · [可行性评估](../design/roll-v3-research-pipeline/roll_v3_harness_feasibility.md)

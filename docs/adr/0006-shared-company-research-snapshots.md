# 日常研究与独立报告共用不可变公司分析快照

依据已确认的[规格](../../.scratch/roll-research-valuation/spec.md)，日常研究和独立研报共用公司身份、原件事实、经营假设与条件估值，由同一分析快照绑定数字和结论；报告保存快照引用及其独立交付版本，更新追加父子版本。相比为报告另建事实库或每次重新生成核心分析，这增加输入冻结和版本关联成本，但能使两个工作流一致并保留原文重放依据。

公司与上市证券分开，A/H同公司但报价分别引用；核查是否完成与经营判断分开；账户计值仍由现有账户服务负责，条件估值仅用于研究。新增服务复用SQLite、证据归档和既有worker租约，不复制参考技能的代理权限。ADR0001/0004/0005及原实验预算、封存与正式资格边界不变；经济审核reviewed、报告FULL均不构成能力授权。字段与错误合同见[研究合同](../research/company-research-contracts.md)，模板与部分交付见[模板映射](../research/company-report-template-map.md)。

# 独立交付交易辅助与探索回测

日期：2026-10-23。用户已同意持续跟踪、回测、交易辅助与复盘的可用版路线。

## Context

原 PRD 和 ADR 0003 将模型交易判断统一纳入正式资格。基础观察虽能独立使用，用户仍缺少综合判断；数据与旧实验的资格缺口不应阻塞所有助研功能。

## Decision

新增独立的交易辅助判断：允许提供方向倾向、证据、反证、条件、期限和缺口，供用户独立决定是否采用；不宣称已验证收益优势，不以模型自述信心充当事件概率。未确认账户时只做证券分析，不猜测用户资金与可卖数量。

辅助判断不创建旧正式 Decision、CapabilityGrant 或 ExecutionIntent，不自动下单、确认成交或改变真实账户。缺关键证据时仅拒绝依赖它的判断，其余可用材料保留。界面必须清楚区分无法判断、有依据的中性观点与正式动作。

探索回测可独立执行并报告负面结果；保留数据、费用、执行假设、参数与结果版本。不消费或重置旧研究家族预算，不把已看过的探索样本视为未接触的确认性证据。

ADR 0003 的 G1—G7、审阅、资金授权与确定性资格检查继续适用于已验证策略正式动作；本决策明确改变其对全部研究辅助判断的统一限制。旧接口权限不直接放开。

## Consequences

用户可先获得研究辅助和探索结果，但须明确其不同于已获正式资格的策略。代价是增加一种输出对象及其清晰呈现、证据追溯和失效处理责任。实现须验证两条路径不会互相冒充。

范围、分阶段验收见 [实施规格](../../.scratch/roll-decision-assistant/spec.md)。本决策接受不表示新功能已完成。

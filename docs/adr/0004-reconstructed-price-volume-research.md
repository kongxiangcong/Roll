# 将当前历史版本的量价重建研究与严格历史时点资格分开

2026-10-10 用户明确授权 ticket 19 使用当前取得的真实历史版本完成研究训练、时间隔离校准及模型工件冻结。此前把完整历史原版存证与修订链作为所有拟合的统一前提，会同时拒绝可追溯的重建研究。本决策只修改这一用途边界，保留 ADR 0003 的正式资格要求。

原始采集保留证券身份、原值、单位依据、发布时间（未知仍未知）、Roll 实际接收及可消费时刻、版本和内容指纹。`RECONSTRUCTED_RESEARCH` 是用途，不改变 REAL_ACQUISITION 来源身份；METHOD_CASE 永不升级为真实研究。宿主校验原件、身份、单位、日历、冲突及限定窗口后，生成新清理版本和 DEVELOPMENT/CALIBRATION 分片，不覆盖旧登记。

日线研究可得性采用显式的“所属交易日盘后 15:05 完成，下一交易日开盘消费”假设，与实际 `available_at/received_at` 分列。当前接收时刻只检查本次重建消费者是否已收到数据；不得拿它与旧观察时刻比较后将全部研究误判为未来泄漏，也不得回填原始接收时间。只消费观察日及以前的量价、已经生效的现金权益；禁止引入后来财报、新闻、预测或 LLM 情绪。

原 RAW 收益遇现金除息会产生机械跳变。新候选 PRICE_VOLUME_LOGIT_RECONSTRUCTED_V2 保持四项量价、λ=1、20交易日、NEXT_OPEN、固定截距校准；前三项以观察日及以前已生效的现金分派构成逐日复合经济回报指标：单日因子 `(close[t]+gross_cash_effective[t])/close[t-1]`，5/20日乘积减1和20日单日收益标准差；不是实际再投资账户。相对股数定义不变。成交始终 RAW；单机会标签包含已知现金权益及持有期税负。未知复杂权益、缺行、停牌、无法退出、冲突按局部政策留为不可评分，不标负例。新协议关联旧家族，保留暴露、失败和五次拟合/一次 CAL 预算。

模型训练成功、校准器 FITTED_UNVALIDATED、模型工件冻结、完整实验冻结和正式能力授权分别保存。同一 CAL 的指标只作拟合内描述；每类20的拟合支持保持，确认性有效块/可靠性箱/选中量/G1—G7不前置为本票拟合要求，也不降低其后续门槛。模型冻结包含输入、窗口、预处理、执行、权益、费用和代码依赖指纹。

`STRICT_HISTORICAL_AS_OF` 仍须可核验的历史可得性和版本依据，无证据继续拒绝；当前重建不构成严格 PIT、独立封存、真实前向观察、投资优势或正式建议资格。本轮不读受保护 SEALED、不创建前向起点、不实施 ticket 20 及以后，不修改后续依赖或完成状态。

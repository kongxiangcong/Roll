# 基本面估值计算与接入

## 何时使用

Step 5 遇到可预测现金流的非金融企业，或需要解释现价隐含经营假设时，读取本文件并运行 `scripts/fundamental_valuation.py`。周期股仍先用 `05` 的周期位置与 `cycle_valuation.py`；DCF 只能使用正常化现金流作为交叉检验。银行、保险优先剩余收益、股息折现或行业特定模型，本脚本不适用。

输出是附条件的估值参照，不生成评级或交易动作。三种 DCF 情景不是三种独立方法；无增长盈利能力价值（EPV）也共享现金流与资本成本，不能把两者接近写成独立证实。用同业估值或资产价值再做一次口径一致的外部对照，不机械凑齐方法数量。

## 工作流程与完成条件

1. 从 `examples/valuation-assumptions.json` 建立本次假设文件，放入 `02-工作底稿/估值/`。示例全为合成数据，逐项替换后才能用于真实公司。metadata.sources 逐字段写原始披露 URL、财年、页码/表名、获取日期；metadata.assumptions 写预测依据、正常化调整、概率依据与失效条件。
2. 先完成口径表，再计算：FCFF 是付息前、税后、扣除再投资的企业自由现金流，搭配加权平均资本成本（WACC）；FCFE 搭配权益成本，不能输入本脚本。现金流、债务、股数单位与价格币种保持一致；金额与股数只能使用 unit/share、million/million_shares、100_million/100_million_shares 配对。
3. WACC 使用估值币种的无风险利率、可核验的权益风险溢价、beta、税后债务成本和市场价值权重构建，记录各分项及日期，不预设一个“A股通用折现率”。长期增长、通胀口径与币种一致。EPV 使用同一个 WACC。
4. 按年输入完整 FCFF，或收入与 FCFF 利润率。显式期末必须已正常化；过渡期直接写入年度序列。股数使用估值日可参与分配的股数（扣库存股）并核查稀释工具，不直接把已发行股数或历史EPS加权股数当作期末分母；本版固定股数，不模拟未来增发回购。优先用 `equity_bridge` 逐项记录企业价值至归母权益调整：每行 `name/amount/source/treatment`，正数扣减，负数加回。净债务兼容字段 `net_debt` 与明细只能选一个。现金、债务、租赁、少数股东和非经营投资各计一次，账面代理与公允价值须区分。
5. 运行并留档：

   ```bash
   python scripts/fundamental_valuation.py --config <项目>/02-工作底稿/估值/assumptions.json --output <项目>/02-工作底稿/估值/result.json --require-reviewed
   ```

6. 将输入文件、输出文件、命令、模型版本哈希、情景表、敏感性表与来源映射记入 `估值参照带.md`。按 `12` 完成 `模型自检.md`，再把结果写入正文第九节。输入 `review` 包含 `status` 与 `limitations`：状态可为 unreviewed、conditional、blocked、reviewed，默认未审核。参数或主体口径未核清时输出诊断结果，并保持 conditional/blocked；`--require-reviewed` 在非 reviewed 时仍保存结果但退出3，输入错误退出2。reviewed只能由有底稿证据的经济审核得出，不能为了命令成功而修改。现有 `check_gates.py` 检查报告结构，不替代此审核。

## 从年报进入模型的三项检查

1. **现金流分类与重述。** 优先本期年报重述比较数，保留旧数差异。CFO中的利息为经营分类时，机械FCFF代理为CFO−Capex+I×(1−T)；若利息已列筹资活动，则为CFO−Capex−I×T，前提是税盾确实可在同年实现。函数 `fcff_from_cfo` 只完成这一步，不等于正常化。财务公司存贷款、套保结算和保证金需按主体/科目剥离；整体剔除营运资金变化后不得重复加回其组成项目。
2. **现金和权益调整。** 货币资金、非现金等价物、受限资金是不同集合。先定维持经营所需现金，再判断富余资产；金属融资、票据贴现可能已在借款内，避免再次扣除。联营企业权益法利润不代表合并现金流，持股价值可另列，但不能同时资本化其收益并加回全额投资。
3. **A/H及反推解释。** metadata.listing_structure 标为 `A+H` 时，反向模型必须输入同日同币种 `market_equity_value`：A股流通经济股数×A股价+H股数×H股价×汇率。禁止单一价格乘全部股数。`reverse` 可以只提供 scenario 与 market_equity_value，仅反推终值现金流；只有收入与利润率口径可对齐时，才同时给 steady_margins/base_revenue。

真实案例：`python scripts/validate_jiangxi_copper.py` 使用 `examples/jiangxi-copper-2025-facts.json` 复算2025年报。它有12项金额/算法核对，但经济审核为blocked：缺工业与金融业务抵销拆分、正常化资金占用及终值再投资证据。案例不是当前估值或无前视偏差回测。用它检验“不合格的估值也能被明确识别”，而不是验证某个价格。

## 算式、时间与边界

- 年末折现：EV = Σ FCFF_t/(1+WACC)^t + [FCFF_N×(1+g)/(WACC−g)]/(1+WACC)^N。
- 归母权益价值 = EV − 净调整额；每股参照值 = 归母权益价值 / 同尺度稀释股数。
- 反向 DCF 固定前 N 年现金流，解第 N+1 年终值现金流；收入要求 = 该现金流 / 稳态 FCFF 利润率；从基期到该收入的增长率按 **N+1 年**算。它不是唯一隐含增长率，也不是把所有年度路径同时求解。若所需终值现金流非正，输出无正终值需求，不强行输出增长率。
- EPV = 扣除维持性再投资后的正常化 FCFF / WACC，再做权益桥接。不可直接把 NOPAT 当作可分配现金流。这里是无增长近似，不是完整的 Greenwald 资产重置与特许经营价值模型。
- 三情景概率由研究者给出且总和为 1；加权结果不是客观概率预测，最小至最大值不是统计置信区间。必须解释每个情景的可验证经营条件。
- 终值占比超过 75% 是人工复核提示线，不是估值无效的定理。检查终值占比、末年正常化水平、隐含资本回报与再投资能否支持增长，并用 WACC/g 网格展示敏感度。
- 脚本拒绝非有限数、非正股本、WACC≤g、负/零终值基础、口径混用和未支持的情景字段。允许早期负现金流及负净债务。它不能验证披露真假、股数稀释充分性或币种是否被正确换算。

## 接入来源与未纳入项

计算层改编自本地 `equity-research-skill/scripts/dcf.py` 的 DCF、反向 DCF、EPV 算式，许可与快照标识见 `THIRD_PARTY_NOTICES.md`。不依赖该项目安装位置；复制当前技能目录即可使用。

本版修正反向 DCF 的 N/N+1 年口径，统一无增长现金流口径，补充严格输入检查、JSON 结果与回归测试。暂缓源项目的 Kelly 仓位、自动评级、蒙特卡洛与 EVA；前两项不服务研究参照目标，后两项需分别先解决概率校准、投入资本与再投资路径一致性。SOTP、银行剩余收益、REIT NAV 尚无新增执行器，仍需按行业方法单独建模。

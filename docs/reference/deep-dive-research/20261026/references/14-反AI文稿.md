# 反 AI 文稿

> **这不是一份改稿指令，是一份找线索的清单。**
> 原文：*"This list is descriptive, not prescriptive; it consists of observations, not rules."*
> *"The patterns listed here are also only potential signs of a problem, not the problem itself.
> Please do not merely treat these signs as the problems to be fixed."*
> —— Wikipedia《Signs of AI writing》

---

## 怎么用这份文件

1. **先过第三层「不许动」**，再动第一层。顺序反了，会把稿子刮平。
2. 命中的条目**不是必须改**。改之前问一句：**删掉它，意思有没有损失？**
3. 改的是**模式**，不是**单词**。一个词出现是巧合，一段里出现三四个才是模式。
4. 逐项报出来，**别合并成一次通改**。有实测依据：逐项审计能找出 95% 的问题，
   合并成一遍只找出 68%。
5. 本文件只做「去味」。**立意、事实、判断、结构骨架不归它管。**

## 零、第一原理：为什么会有 AI 味

LLM 用统计方法猜下一个词，因而**回归均值**——结果总偏向"最普适、能在最多场合成立"的那个。
再经 RLHF 调向"最广泛可口的文风"。

后果是具体的：**它省略统计上稀有的、具体而微妙的事实，换成统计上常见的、泛化的正面描述。**
那个极其具体的"第一个火车挂钩装置的发明者"，会变成"一位革命性的行业巨擘"。

> **"It is like shouting louder and louder that a portrait shows a uniquely important person,
> while the portrait itself is fading from a sharp photograph into a blurry, generic sketch."**
> —— 喊得越来越响，说肖像上是个独一无二的重要人物，而肖像本身正从清晰的照片褪成一张模糊的通用素描。
> **主体同时变得更不具体、更夸张。**

**这条原理给出可迁移的判断标准**（比记清单管用）：

| 问法 | 结论 |
| --- | --- |
| 删掉它，意思有损失 | 它在承担信息 —— **是加分项，留** |
| 删掉它，意思没损失 | 它只加了音量，没加分辨率 —— **是为修饰而修饰，改** |

**"空"和"对称"都从这一条推出来**：空 = 泛化描述替换了具体事实；对称 = 回归均值必然给出的最"典型"形状。

## 一、用词

### 1.1 朴素动词 vs「体面」动词

人类 25 年的维基写作里，**朴素的那个词出现得更多**；AI 系统性地换成更硬、更委婉的同义词。

| 人类更常写 | AI 更常写 |
| --- | --- |
| 写了 | 撰写 |
| 用了 | 运用 / 采用 |
| 试了 | 尝试 |
| 搬了 | 迁移 |
| 死了 | 逝世 / 与世长辞 |
| wrote / used / tried / moved / died | authored / utilized / attempted / relocated / passed away |

### 1.2 万能动词（中文）

赋能 · 助力 · 打造 · 构建 · 实现 · 聚焦 · 落地 · 沉淀 · 拉通 · 抓手

> 改法不是换一个近义词，是**换成那个动作本身**：
> "赋能团队效率" → "让三个人干的活两个人能干完"。

### 1.3 拔高词

关键 · 至关重要 · 里程碑 · 标志性 · 具有深远意义 · 扮演着重要角色
（英文对应：pivotal / crucial / vital / testament to / beacon of / hallmark of）

### 1.4 术语黑话当卖点（L3 层重点）

跑反模式 · 真问题 · 底层逻辑 · 第一性原理 · 重新定义 · 范式 · 心智 · 颗粒度 · 对齐

> **这是正式书面体里最重的 AI 味。** 研究报告读起来该像一本经济类著作，
> 不是"满篇 AI 词"的文章。**用术语替代思考，就是用音量替代分辨率。**

### 1.5 分时代的高频词（**会过期，务必看复核日期**）

| 时期 | 高频词 |
| --- | --- |
| 2023–2024（GPT-4） | delve · tapestry · testament · pivotal · intricate · meticulously · underscore · landscape · interplay · vibrant |
| 2024–2025（GPT-4o） | align with · bolster · enhance · foster · highlight · showcase · endure · vibrant |
| 2025–2026（GPT-5） | emphasizing · enhance · highlighting · showcasing ＋ 拔高来源与媒体曝光 |
| **2026 起（GPT-6）** | challenge · clearer · dependable · echoed · foster · leverage · matters · multifaceted · practical · prioritize · quietly · steady · universally |

> **注意**：词表是**移动靶**。`delve` 在 2023 年是最强 tell，2025 年已基本消失。
> **不要拿一份过期的词表改稿。**

### 1.6 拟物化抽象物（把判断说成会死的东西）

把结论、前提、某一环节说成"会死的东西"：死在××环节、最软的一环、致命伤。
这类话术来自工程与军事语境，放进正式文书里读起来像内部口令，不像写给读者的句子。

| 禁 | 改成 |
| --- | --- |
| 这套判断最可能死在利润验证环节 | 这套判断最经不起检验的地方在利润端：利润尚未验证 |
| 最软的那一环 / 最薄的一环 | 最薄弱的一环 / 最容易被推翻的一项 |
| 命门 / 致命伤 / 被卡住脖子 | 直接说是哪一项、被什么卡住（"关键在××，一旦××就……"） |

> **来由**：2026-10-15，`deep-dive-research` 生成的速览页里出现"这套判断最可能死在利润验证环节"。
> 这句不是模型自造，而是**skill 写作提示语里的原话**（速览页「最大证伪点」那一行原本写着
> "这套判断最可能死在哪"）被照抄进了正文。**口令被抄的，只改词表只治一半——
> 写作提示语本身也要改成直白说法**，否则下一稿还会长出来。

### 1.7 工具比喻：尺子

把估值方法、判断标准说成「尺子」，读起来像模型顺手抓来的一个比喻。
意思并没有变清楚，反而把本来能直说的「估值方法」藏进了喻体里。

| 禁 | 改成 |
| --- | --- |
| 估值没有一把通用尺子 | 不同行业要用不同的估值方法 |
| 行业换了，尺子也得换 | 行业换了，估值方法也得换 |
| 拿同一把尺子量所有公司 | 用同一套估值方法看所有公司 |

> **来由**：2026-10-21，`deep-dive-research` 推广文里写了「行业换了，尺子也得换」，
> 用户指出「尺子这个词很 AI，以后不要再出现」。成稿改用「标准 / 估值方法」。
> **这条只禁「尺子」这一个喻体，不扩大到所有工具比喻。**

## 二、文章结构

> **这一层比用词层耐久。** 有实测：只用篇章层特征检出 AI 的 F1 达 **93.2%**；
> 而一个很专业的表层润色器，只让检出率掉 **1.6 个点**。词汇层最容易衰减（微调后风格检测从 97% 掉到 3%）。

### 2.1 段首零回指评论（中文实测最强，4.4×）

新段落开头直接给出评价，**不说评价的是谁**——读者得回头翻上文才知道所指。

> 反例：「值得注意的是，这一变化并非孤立事件。」
> 改法：补一个指示成分 —— 「**这**一变化并非孤立事件。」

> 注意：段首衔接词的**总体密度**人机无差别（生成 14.4% / 人类 15.1%）。
> 差异只在**评价句省略了回指成分**。别把正常的衔接词一起删了。

### 2.2 相邻句结构同构（2.0×）

相邻两句复用同一个句法骨架。
**中文实测的分界**：句内同构排比**人类用得更少**（留），**相邻句复用同一骨架**才是 AI 特征（改）。

### 2.3 三连排比（Rule of three）

「更高效、更稳定、更省心」——三项并列、格式完全对齐、长度接近。

### 2.4 序数词当小标题（3.1×）

「第一点 / 其次 / 最后」这类**无信息量**的小标题或段落领头。

> **判据：序数词有没有带来新信息。** 用「第一、第二、第三」逐条讲三件不同的事，不算；
> 在已经有类别名的清单前面再加「一是判定、二是业务与单位经济……」，序数词只是把后面的标签又说了一遍，才算。
>
> **来由（2026-10-21 补）**：`deep-dive-research` 推广文的公众号初稿，十节清单写成
> 「一是判定……十是判断的边界」，用户把十个序数词整串删掉，只留「判定：…… 业务与单位经济：……」。
> 同一篇前面「看完有三件事」下面仍保留「第一、第二、第三」——所以这条**不覆盖正常的三条列举**。

### 2.5 段段下结论 / 结论式收尾

每一段都以一句总结收尾。人类写作会留几段**直接停**。

### 2.6「挑战与展望」式结尾段

「尽管有着……的优势，X 也面临着挑战……」——以一段笼统的正面评价或对"未来举措"的猜测收尾。

### 2.7 句长被压进窄区间（2026 新 tell）

GPT-6 时代的新特征：**句号逗号变多、句子变短、长度卡在 8–20 词的严格区间**。
人类侧句长变异系数 0.67 / 生成侧 0.58。

> ⚠️ 但**不要为了制造参差去调句长**——相邻句长差两侧都是 21.7，段长离散度 0.94 vs 1.00，
> 均**无差别**。这里的判据是"是不是被压进了窄区间"，不是"够不够参差"。

### 2.8 结构与上一篇收敛

五模型挤在结构空间的同一小块，人类是分散的。
**"这一篇的骨架，跟上一篇是不是同一个？"** —— 是，就是信号。
**稀有性才是人的信号。**

### 2.9 小标题写成设问或绝对否定

小标题不告诉你这段讲什么，而是**抛一个问题或下一个断语**：「它到底帮你看什么」「它做不到什么」。
读者得读完整段，才知道标题指的是什么；标题本身没承担信息。

| 禁 | 改成 |
| --- | --- |
| 它到底帮你看什么 | 这个 skill 能帮你做什么 |
| 它做不到什么 | 它有什么缺点 |
| 为什么这件事这么难 | 难在行业指标不能通用 |

**判据：** 把小标题单独拎出来读，能不能知道这一段要给什么？

> **来由**：2026-10-21，`deep-dive-research` 推广文的公众号初稿用了「它到底帮你看什么」「它做不到什么」，
> 用户改成「这个skill能帮你做什么」「它有什么缺点」。
> **只小标题算**；段内自己补一句问句不算（用户会主动这么写，见共享档案 `S-36`）。

## 三、表达习惯

### 3.1 开场主持腔

大家好 · 今天分享一个 · 在当今这个时代 · 随着……的快速发展 · 让我们一起来看看

### 3.2 情绪靠身体表演

AI 通过身体反应演情绪（"心跳加速""手心冒汗"）占 **81%**，人类只占 **38%**——人类直接说感受。
这是 StoryScope 研究中**差距最大的一项**。

### 3.3 限定词缺失

通篇确定、通篇顺，没有一处犹豫。人类更常用 very / perhaps / tends to / 可能 / 大概 / 我不确定。

### 3.4 系动词回避

AI 回避最简单的 is / has 结构。人类更常写 there is a / it has a；AI 更常绕成更"高级"的表述。

### 3.5 标点（**时代性最强的一项，逐条看日期**）

| 标点 | 实测 | 状态 |
| --- | --- | --- |
| 冒号引列表 | 空转句引列表 **9.4×**、提示语 3.8× | 现行，主张仍成立 |
| 顿号并列过密 | 1.8× | 现行 |
| 破折号 | Claude 4.25‰ / DeepSeek 5.16‰ / GPT 0.11‰，极差四十倍 | **2026 年 9 月起已列为「历史指标」**——不再单独判死刑，且模型间差异极大 |

> 破折号这条最能说明问题：**"AI 文风"不是单一形态**。同一特征在模型间能差四十倍。
> 引用单一模型的样本得出的结论不具普适性。

### 3.6 排版

加粗撒在句中 · emoji 当项目符号 · 标题全大写 · 两个事实做一张表 · 主题分隔线滥用

## 四、语言逻辑

### 4.1 对举结构（3.4×，中英两份清单的唯一交集之一）

「不是 X，而是 Y」·「不只是 X，更是 Y」·「与其说 X，不如说 Y」

> 单次出现正常。**连着出现两次以上就是模式。**

> **来由（2026-10-21 补）**：`deep-dive-research` 推广文里保留了「它不是帮你判断买不买的。而是帮你把一家公司看明白」。
> 用户明确说这是人类表达，不按 AI 味改。**这条只按出现次数判模式，不按句式本身判死刑。**

### 4.2 模糊归因 / 含糊其辞

研究表明 · 业内普遍认为 · 被广泛视为 · 有观点认为（而不给具体是谁）
以及**夸大来源数量**：只有一两个来源，却写成"多方认为"。

### 4.3 拔高重要性

「在……中扮演着重要角色」·「具有深远意义」·「标志着……的新阶段」

### 4.4 对着空气辩论

「我不是说 X，但……」·「有人可能会问……」·「当然，这并不意味着……」

### 4.5 虚假洞见

「真正重要的是……」·「本质上……」·「说到底……」·「Here's the thing」

### 4.6 概括表述覆盖已有数据

实测：**AI 的数字密度只有人类的 0.35**（6.34 vs 17.92）。
明明有具体数字，却写成"显著提升"。

### 4.7 貌似平衡

「一方面……另一方面……」，两边都不落地，谁也不得罪。

### 4.8 空转句引列表

一句不含信息的提示语（「以下是几个关键点：」），后面跟一串项目符号。

### 4.9 单句收尾 / 金句式收尾（中文清单未单列，英文列为最强 tell 之一）

「细品。」「这就是全部。」——把话写满，不给读者留动作。

### 4.10 内部术语与自检口令不上稿

写作者自己的脚手架漏进正文，读者看到的是一份没写完的底稿：

| 漏进来的 | 长什么样 | 正文该写什么 |
| --- | --- | --- |
| 判定表的行名 | `C · 顶部结束` | 先看这一轮走到哪一步 |
| 自检计数 | `读数 4 条对 3 条` | 哪几项已经出现，逐项点名 |
| 底稿指针 | `理由即顶后四条` | 把理由写出来，不指位置 |
| 栏目代号与记法 | `甲／乙／丙`、`n=` | 用中文名称呼 |
| 规则编号与"要做几项" | `（08 4.6 六项）`、`（08 4.2，两列都要写）` | 删。编号是写给我自己的，读者手里没有那份文件 |
| 表头里的圈内词 | 表头写"读数""取数" | 换读者看得懂的：本轮的实际情况 ／ 当前值 ／ 来源 |
| 编号式波次说法 | `第一波上涨`、`第二波` | 换成相对当前的说法："下一轮由供给收缩驱动的上涨"——读者不知道你从哪儿数起 |

- 表格里有栏名，正文里只有句子。栏目名（如"最大证伪点"）可以进正文栏位，
  但它下面必须是写给读者的话，不是写给作者自己的提醒
- 计数与代数不进句子：写"哪几项已经出现"，不写"已出现 3 项"
- **来由**：2026-10-15，`deep-dive-research` 的速览页出现上述三类写法，
  源头是该 skill 自己的提示语要求"写清各几条"。**见到这类句子先回溯提示语，别只改正文那一处。**

### 4.11 写作过程不进正文（不向读者介绍自己的作业流程）

报告写的是这家公司，不是"我怎么研究这家公司"。作者选了哪个角色、按什么给它排章节、
启用过哪些模块——读者不需要知道。写出来只是把心里话说了出来，读起来像作者的自述。

| 禁 | 改成 |
| --- | --- |
| 行业专家角色取稀有金属（钽铌）研究员，他的第一问是……；章节顺序按这一问排列 | 直接写这家公司看什么：矿端供给与出口管制、电容靶材与超导三条需求线哪条在拉量、高纯环节的加工溢价 |
| 盈利特征判定直接决定各节权重：……是重点，……不适用 | 删。权重体现在篇幅与先后上，不用讲给读者 |
| 本报告按"先看供给、再看需求"的顺序展开 | 删导语，直接进第一节 |
| （四层判定表"行业专家角色"栏） | 删。底稿栏位不进正文 |

**判据一条：句子的主语应该是公司或行业，不是"我这份报告"。**

> **来由**：2026-10-15，`deep-dive-research` 生成的东方钽业报告第 1 节出现
> "盈利特征判定直接决定各节权重……行业专家角色取稀有金属（钽铌）研究员，他的第一问是……
> 章节顺序按这一问排列（四层判定表"行业专家角色"栏）"。用户的原话是
> "这句话像是 AI 给自己执行过程说出来了，类似于人在表达的过程中给心里话说出来了。
> 对文章的流畅度有影响"。这句同属**口令外溢**：`references/01` 写着"决定了启用哪些模块、
> 重点写哪几节"，`references/09` 写着"按该角色的第一问排序章节重点"——两处都是底稿指令，
> 被当成要向读者交代的内容写了出来。

### 4.12 报告要自足（不把读者指去别的文件）

报告是给投资者的成品，读者手里只有这一份 PDF。**凡是指向底稿、附件、其他文件的句子，
等于承认"这里我没讲清楚"。**

| 禁 | 改成 |
| --- | --- |
| 按分流三问（底稿《四层判定表》4.0，两问为否），这条路走 B 类 | 直接给证据：需求增速连续三年高于供给增速、矿端新增产能最早要到 ×× 年，所以瓶颈在资源端 |
| 完整的 13 段见底稿《历史股价复盘》 | 放进附录，或把段落写完；不指路 |
| 前提写在参照带底稿第 0 节 | 把前提写出来 |
| 每个自算单位数的口径与对照在底稿《单位数核查》逐行登记 | 先在正文说清口径与对照，再说它登记在哪；说不清就别留这句 |
| （详见底稿） | 删。要么写出来，要么不写 |
| 股价见顶信号（`08` 4.6 六项） | 表题只写名称："表 4-2　股价见顶信号" |

**判据一条：假设读者手里只有这一份 PDF，这句话他读不读得懂？读不懂，就是指向了外部文件。**

> **来由**：2026-10-15，`deep-dive-research` 生成的东方钽业报告正文出现 10 处「底稿」
> （"按分流三问（底稿《四层判定表》4.0，两问为否）""完整 13 段见底稿《历史股价复盘》"
> "（详见底稿）"）。用户的原话是："我这是一份呈现给投资者的报告。怎么会让我去查底稿然后
> 搞清楚你是怎么分类的呢。报告呈现的目的就是为了把问题直接在当前报告中说清楚，
> 而不是指向其他文件，这是机器会做的事，不是人会做的事。"
>
> **边界：附录 G 溯源表里列文件路径不算违规**——那是来源登记，不是让读者去看；
> **正文里的指向才违规**。底稿本身照旧要写，只是不进正文。

### 4.13 自我重复：同一件事在一句里说两遍

刚说过的意思紧接着再写一遍，最容易长在**加粗、高亮、标注**的位置——
因为那正是作者觉得"这里重要、得再说一次"的地方。读者读到的却是结巴。

| 禁 | 改成 |
| --- | --- |
| 行业处在阶段二（缺口打开）向阶段三（供给追赶）的过渡，**处阶段二向供给追赶过渡**，缺口七项两项转向补上 | 行业处在缺口打开向供给追赶的过渡，缺口七项里已有两项转向补上 |
| 这说明**需求正在增长**，需求正在增长 | 删掉后一句 |

**两个自检动作：**
① **把加粗与标注的符号去掉再读这句。** 句子通顺，说明标记圈的是原词；断了，说明标记里又写了一句。
② **把标记里的文字拎出来单看**：若它和紧邻的前一句说的是同一件事，删掉重复的那一半。

> **来由**：2026-10-15，`deep-dive-research` 的东方钽业成稿里写成
> "……向阶段三（供给追赶）的过渡，==处阶段二向供给追赶过渡，缺口七项两项转向补上=="，
> 标注那一半与前半句是同一件事（用户指出）。
>
> **这条不设机械项。** 实测过：按"标注与前文的最长公共子串 ≥ 4 字"扫，
> 那份成稿 11 个标注命中 3 个，只有 1 个是真重复，另两个是正常的词面共享（"国内唯一""参股收益"）；
> **同义改写本来就扫不出来**。硬扫只会制造噪声——与"死"字那条同理，只挂人工动作。

### 4.14 提示语骨架：先说……再说……最后……

用三个提示词把段落串起来，内容退到提示词后面：
「先说慢。再说数据。最后是决定权。」
读者记住的是这三个词，不是你要说的事。

| 禁 | 改成 |
| --- | --- |
| 先说慢。跑一篇要一两个小时。再说数据。……最后是决定权。…… | 生成一份报告可能会很慢。跑一篇要一两个小时。…… |

**判据：** 删掉提示词，句子还成立吗？成立就删。

**只针对提示语骨架。** 正文里用「第一、第二、第三」逐条讲三件不同的事，不按这条处理；
序数词本身见 2.4，那里也只在它没有增加信息时才算。

> **来由**：2026-10-21，`deep-dive-research` 推广文的公众号初稿，「它做不到什么」一节用
> 「先说慢／再说数据／最后是决定权」串了三段，用户改掉前两段的提示语，只留内容。
> 同一稿十节清单里的「一是……十是……」也被整串删掉（与 2.4 同源）。

## 五、不许动 —— 不作为改写理由

> **这一节和第一至四节同等重要。**
> 理由：**去味最容易变成把稿子刮平。**
> 下面每一条都有实测依据，标明"不算 AI 味"或"人类用得更多"。

| 形式 | 为什么不许动 | 依据 |
| --- | --- | --- |
| **比喻** | 人类侧比喻标记是生成侧的 **2.4 倍**，以比喻独立起段者是 **8 倍** | 中文语料实测 |
| ↑ 真正该改的 | **喻体选择**：AI 爱用理想化的职业人格（"像一位智慧的导师"，**7.3×**）；人类爱用具体的熟人（"像个老师傅"） | 同上 |
| **设问** | 正文设问**人类是 AI 的 17 倍**。照"删设问"改，越改越不像人 | 同上 |
| **句内同构排比** | 人类 3.87 vs AI 2.35 —— **人类更多** | 同上 |
| **长短句参差 / 毛边** | 句长变异系数 0.87、相邻句长差 1.00、段长离散度 0.94 —— **人机无差别** | 同上 |
| ↑ 关键一句 | **"毛边是写出来的结果，不是改出来的手段。"** 不为制造参差去调句长或拆段，也不把原本参差的改齐 | `qu-ai-wei` |
| **被动句** | 被动本身不改。**只有一种情况改**：文章要追责，而被动句正把责任人藏起来 | 同上 |
| **连接词（单独看）** | 维基明确列为**无效指标**："不是强信号" | Wikipedia |
| **语法完美** | 无效指标 —— 很多人类作者本身就是专业写作者 | Wikipedia |
| **口语与正式混写** | 无效指标 —— 可能只是技术背景、年轻、顽皮或神经多样性 | Wikipedia |
| **"平淡/机器人味"** | 无效指标 | Wikipedia |
| **"高级/学术/正式"腔** | 无效指标 —— **"这种相关性并不延伸到所有正式、学术或'高级'的散文"** | Wikipedia |
| **没有出处** | 无效指标 —— 57 万+ 篇维基条目挂着"缺来源"，且大多早于 LLM | Wikipedia |
| **最高级与确定表述** | 人类用得更**多**（"最好的之一""唯一的""第一个"） | Wikipedia |
| **限定词与程度词** | 人类用得更**多**（very / perhaps / tends to） | Wikipedia |
| **啰嗦但具体的结构** | 人类用得更**多**（as a result of / in order to / the fact that） | Wikipedia |

**一句话**：删掉有损失的，就是修饰；删掉没损失的，才是去味。

## 六、别靠直觉 —— 检查者自己的偏差

> **"不要过度依赖你自己的判断。人类辨别 AI 文本的能力，不比随机猜测好。"**

- 2025 研究：**人类辨别 LLM 文本的能力不比随机好**
- 2025 德语论文研究：AI 文本识别率 **57%**、人类文本 **64%**
- 只有"专家标注者"能到 **90%**
- **不要拿 AI 检测器当判据**（GPTZero、Pangram）：误差非平凡，改动标点、改述、换模型都会失效
- 提防**确认偏差**与**邓宁-克鲁格效应**：你想证明它是 AI 写的，就一定能找到证据
- 人类语言正被 LLM 影响，两者在**趋同**；但反向不成立 —— LLM 输出并没有变得更像人

**结论**：本文件是**找线索**的工具，不是**下判决**的工具。

## 七、分层清单

> **没有文体能豁免。** 正式书面体不是不查，是**换一套查法**。
> 判断层级的依据是「**读者是谁、他期待什么**」。

### L1 · 短文案（小红书 / 公众号 / 朋友圈）

- **反什么**：账号感、营销腔、模板化开头
- **重点查**：3.1 开场主持腔 · 一、用词全节 · 4.1 对举 · 4.9 金句收尾 · 3.6 排版
- **判断标准**：**读者相不相信屏幕后面是个具体的人**
- **本层允许**：口语、语气词、不完整句、情绪起伏

### L2 · 文章体（散文 / 随笔 / 新闻体 / 评论 / 视频旁白）

- **反什么**：结构上的过度整齐
- **重点查**：二、文章结构全节 · 2.8 与上一篇收敛 · 3.2 情绪靠身体表演 · 3.3 限定词缺失
- **判断标准**：**这一篇的骨架，跟上一篇是不是同一个**
- **本层允许**：毛边、离题、留一条线不收回

### L3 · 正式书面体（研究报告 / 经济类著作 / 公文 / 技术文档 / 学术）

- **反什么**：**空话、术语黑话、机械连接词** —— **不是反口语化**
- **重点查**：1.4 术语黑话 · 4.2 模糊归因 · 4.3 拔高重要性 · 4.5 虚假洞见 · 4.6 概括覆盖数据 · 2.5 段段下结论 · 2.6 挑战与展望段
- **判断标准**：**每一句是不是都在承担信息**。研究报告该是字字珠玑、严谨、逻辑层层嵌套；
  读起来该像一本经济类著作，不是"满篇 AI 词"的文章
- **本层允许**：长句、嵌套结构、密集的连接词（只要它在承担逻辑，不是装饰）
- **本层特别注意**：**用术语替代思考，就是用音量替代分辨率** —— 这是 L3 最重的 AI 味

# 行业专家视角

同一份数据，不同行业的顶级专家会先看不同的东西、在不同的时点做出反应。
这份文件把"行业专家"这个角色**写进流程**：研究开始时先选角色，按该角色的第一问排序章节重点，
成稿前用该角色的"常见误判"自查。

**为什么需要它。** 用一套通用框架套所有行业，写出来的报告会"什么都提到了、什么都没说到点上"。
例如纯碱研究里不看资本开支与新增产能三张表，民爆研究里不把牌照与事件日历当主线，
汽车研究里只写销量不写库存系数与单车盈利——这些都不会让报告显得残缺，却会让它没有用。

## 怎么用（三步）

1. **Step 2 判定阶段选定角色，写进 `02-工作底稿/四层判定表.md`**，与行业归属、盈利特征一起落盘。
2. **按角色排序章节重点**：本文件"第一问"里提到的指标，进正文；没提到的，进附录或省略。
   **排序是作者的事，不是报告的内容**——正文按这个顺序写，但不写"角色取××研究员"
   "章节顺序按这一问排列"，也不引用底稿栏位（见 `references/00` 第六节·过程自述）。
3. **成稿前用"常见误判"自查**：逐条对照，命中就回补。
4. **写明本行业的领先关系**（见下方「通用第二栏」）：本行业股价通常先于什么反应、
   见顶时最早松动的是哪个读数。写进 `02-工作底稿/四层判定表.md` 的角色那一行，
   并在成稿里落成一句话——**这一句决定位置判断会不会写反**（判据见 `08` 第四节 4.8／4.9）。

清单里没有的行业，先按最接近的大类定角色，并把新条目回填本文件。

## 复合角色：一家公司叠了多重身份

有些公司同时落在几个大类里，硬塞一个大类是错的。例：海南橡胶同时是**上游资源**（橡胶）、
**资产重估**（胶园土地）与**事件驱动**（农垦改革、资产注入）；国泰集团同时是
**特殊结构·民爆**与**事件驱动**。处理规则：

1. 按 `01` 的复合类型判定，先写清**哪一层主导当前定价**；
2. 主导层决定章节重点与估值锚，其余层作修正项；
3. 两个角色的"第一问"取并集，但**排序不能并列**——并列等于没有重点。

清单里没有的行业，按最接近的大类定角色，并把新条目补进本文件。

## 通用一栏：这个指标的常识区间是多少

行业专家的标志之一，是**心里有一张本行业的指标常识表**。看到"某车企 NPS 82.5 分、行业第一"，
专家第一反应是问两句：这个行业的 NPS 通常在什么区间、这是哪家的口径。
**不知道常识区间，就没法判断一个数字是荣誉、是常态、还是异常。**

三条通用做法：

1. **先问口径，再问数值。** 同一个名字在不同机构下不是同一个东西。NPS 在杰兰路（只调研新能源
   车主、只覆盖新能源品牌）与 J.D. Power（燃油＋新能源，产品／销售／服务三维加权）之间可以差
   三十多分，而两家都得出"第一"。**带机构与口径的数值才有意义**；不带口径的"行业第一"是一句
   无主语的话，不能用来支撑任何结论。
2. **每个大类至少记一两条本行业的公开基准**，并在报告里给出处。查不到基准的，写"无公开基准
   可比"，不要默认它可信。
3. **名次类指标都要看时效**：同一榜单的上一期与下一期，第一名可能已经换人。

下面这张表只放**已核到公开基准**的条目（用到时仍须回原始来源核对当期口径与样本），
不追求全，查到就补、补的时候带出处与年份：

| 大类 | 常见指标 | 已核到的公开基准（供参照，不是当期值） | 背离时要看的经营数据 |
|---|---|---|---|
| 乘用车（整车） | NPS、交付量、单车毛利、库存系数、终端折扣、市占率 | J.D. Power《2026 中国汽车品牌口碑指数 NPS》（2026-09-29，`china.jdpower.com`）：整体燃油 44.3、新能源 42.7；细分新能源豪华 45.7、新能源主流 42.4、燃油豪华 48.8、燃油主流 42.9；样本 59 个品牌、69,162 名车主。杰兰路口径的行业平均为 60.9（2026 上半年，媒体转述）——**两家口径不可混用** | 月度产销快报的量与价、终端折扣、渠道库存系数 |

（其余大类的基准与各自的"第一问"合并使用：第一问决定看什么，本栏决定这个数在哪算高、在哪算正常。
完整判据与三档采信写法见 `11-反向质疑与遗漏排查.md` 第九节。）

## 通用第二栏：本行业的领先关系（股价先于什么动）

**为什么单列一栏。** 不同行业"股价先于什么动"完全不一样：周期股看**供给投放进度与增速拐点**，
消费看**渠道库存与动销**，TMT 看**大客户资本开支与技术代际**，牌照型看**事件日历**。
用一套节奏套所有行业，位置判断必然写反。

| 行业大类 | 股价通常先于什么反应 | 见顶时最早松动的读数 |
|---|---|---|
| 上游资源与材料 | 供给投放进度与价格拐点 | **利润增速与价差**（不是价格本身） |
| 中游制造 | 产品与原料的价差、产能利用率 | 单吨／单平盈利、开工率 |
| 公用与基础设施 | 利率与调价、政策机制 | 股息率与无风险利率的利差 |
| 消费 | 渠道库存与终端动销 | 批价与终端价、经销商回款 |
| 医药 | 政策与管线节点（集采、医保、临床、获批） | 集采落地节奏、管线读出 |
| TMT | 大客户资本开支与技术代际 | 订单与库存周期 |
| 金融与地产 | 信用与政策周期 | 不良生成率、销售与新开工 |
| 特殊结构（牌照、事件驱动） | 不按基本面节奏，按**事件日历** | 催化剂兑现或落空 |
| 港股特有 | 美元利率、南向资金与结构事件（分拆、回购、私有化） | 南向持仓与折溢价 |

**用法：** 选定角色后，把该行抄进 `02-工作底稿/四层判定表.md` 的角色栏，成稿里写成一句
"本行业股价通常先于 X 反应，本次最早松动的是 Y"。**行业特殊、表里没有的，按最近的大类填写，
并把该行业的领先关系回填本表。**

| 家居轻工 | 地产竣工、订单、原材料价格 | 竣工改善、订单回升 | 竣工下行 | — |

# 问题链与报告结构

正文按**问题链**组织，不按信息类型组织。每一节只回答一个非答不可的问题。

**但"问题链"只解决了写的问题，没解决读的问题。** 一份按研究顺序写成的报告，读者读完
往往记住的是一堆并列事实，而不是这家公司的模型。所以结构要同时满足两件事：

- **写得出来**：每一节有明确的必答问题，不写空话；
- **记得住**：全文有一条主线，读者合上报告能复述出"这是家什么公司、靠什么赚钱、
  什么变量决定它、现在贵不贵、雷在哪"。

下面的结构就是为第二件事服务的。**2026-10-12 修订：由"正文十节"改为"速览 + 四部分九节"。**
**2026-10-15 修订：第四部分由两节扩为三节，新增第八节「历史股价复盘」，全文为"速览 + 四部分十节"。**

## 一、结构总览

| 层 | 包含 | 回答的问题 |
|---|---|---|
| **速览** | 一句话 / 核心模型 / 必记数字 / 优势 / 风险 / 排雷灯号 / 档案卡 / 尚未核实 | 只读这一页，也要能拿到全部结论 |
| **第一部分 生意模式** | 一 判定 · 二 业务与单位经济 · 三 变量 | 它靠什么赚钱，哪个变量说了算 |
| **第二部分 外部条件** | 四 空间与周期位置 · 五 竞争与产业链 | 外部条件现在处在什么位置，钱被谁赚走 |
| **第三部分 财务与风险** | 六 财务 · 七 排雷 | 赚不赚、真不真、哪里会赔 |
| **第四部分 尺子与边界** | 八 历史股价复盘 · 九 估值口径与参照带 · 十 判断的边界 | 市场过去怎么给它称重、什么价位对应什么状况、这套判断何时会错 |
| **附录 A—I** | 背景与底稿 | 厚，但不进正文 |

### 为什么是这个顺序

- **变量（第三节）紧跟生意，不放在财务之后。** 变量是理解这门生意的钥匙，不是财务的附注。
  先讲"收入靠贸易、弹性靠自产"，紧接着讲"决定利润的五个外部变量"，读者才拿得到主线；
  放到第六节，读者读完五节财务才知道什么最重要，主线就散了。
- **排雷（第七节）紧跟财务（第六节）。** 账面利润的来源与报表的可信度是同一问题的两面，
  分开写会让读者以为排雷是个附加章节。
- **估值与边界放最后。** 估值是前面全部结论的函数；边界是估值的函数。顺序颠倒，
  读者会在还不知道周期位置时先看到一个市盈率。

### 四条让读者记得住的做法

1. **速览自足。** 速览页必须能独立成篇：一句话、一张核心模型表、六个数字、优势三条、
   风险三条、灯号。读者只读速览，也知道这家公司是怎么回事。
2. **每个部分有导语页。** 部分名下面写 3~5 行结论，再逐条列出**本部分各节的一句话结论**
   （一条对应一节）。读者只翻四个部分页，也能复述全文。
   **导语写结论，不写预告句**——不出现"本部分回答……现在处在什么位置"这类开场
   （见 `references/00` 第六节·报告体不是讲解文）。
3. **正文每节标题写成"主题：结论"。** 例："六、盈利结构与财务质量：连亏三年，账面由补贴支撑"。
   只写"盈利结构与财务质量"是分类标签，读者从目录里读不到任何结论。**不许写成问句**，
   也不要写比喻。
4. **每节第一句是判断。** 后面才是证据。节与节之间靠因果衔接，不靠"接下来我们看……"。
   这句判断**就是要被标注出来的那一句**——读者只读每节的标注，也该拼出全文的骨架。

## 二、速览页（一页，全文最重要的部分）

按下列顺序写，顺序本身就是一条推理链：

1. **一句话**：这家公司靠什么赚钱、由哪几个外部变量决定。写成一句陈述句，把驱动它的外部变量
   一次点清。**不用比喻**——"杠杆""外壳""一台什么机器"这类壳子一律不写（见 `00` 第六节）。
2. **核心模型**：一张表，按利润贡献把公司的几块业务分层列出，每块给出内容、当年数字、在报表里的
   作用（哪块贡献收入、哪块贡献利润、哪块是拖累）；表后一段话写传导链（什么涨、什么变、
   最后谁受益、被什么抵消）。表后附一张三行小表，
   列出读者必须带走的三个问题，并标出各自在哪一节回答。
   **另起一行写周期坐标**（周期型必写）：**先写这条周期走的是哪条路（A 类过剩出清型 /
   B 类需求拉动与资源约束型）**，再写处在第几阶段、库存周期第几个象限；A 类一句话点明
   **出清走到哪一步、方向是在恶化还是在改善**（不写"第一波"这类编号，也不写"触发条件凑齐了没有"
   这类进度词），B 类点明"缺口是打开了还是正在被补上"；
   **写完把这一句与下一行（股价节奏坐标）连起来读**：读成两个故事就改到一致；
   手上正好有上一轮的起止与幅度就顺手写上，没有不必凑
   （2026-10-15 中粮糖业实盘，见 `references/08-产业周期与择时.md` 第二节末）；
   最后给一句**见顶与否**的结论——**写哪些信号已经出现、哪些还没有，不写"已出现几项"式的计数**
   （计数留在第 4 节的表里）。
   这一行让读者合上速览就知道"现在是什么时候"，见 `references/08-产业周期与择时.md` 第一、四节。
   **再另起一行写股价节奏坐标**（2026-10-15 新增，见 `references/13-历史股价复盘.md`）：
   **这一轮落在四态中的哪一态**（底部反转／上升中继／顶部结束／下跌中继）、上一轮高点在何时、
   调整已持续多久、**按本公司自身历史与行业经验这类调整通常持续多久**、
   当前更像中继还是更像见顶——**说清差在哪一个读数上，不写"两侧证据各几条"**。
   周期坐标说的是"行业到哪了"，这一行说的是"这只股票到哪了"。
3. **必记的数字**：5~6 个数字，每个数字带一句含义。选那些"改动一个，全篇结论就要重算"的数字。
   **这里只放公司的属性，不放解题结果。** 产量、收入结构、价格敏感度、估值分位这类，
   是这家公司本来就有的东西；**由反推得到的临界值**（盈亏平衡价、隐含价格、临界成本）
   不得出现在这里——它们随假设移动，换一个基准年就变一次，写进速览会被读者当成公司的属性记住。
   反推值属于第 9 节，且要写明假设与移动幅度（见 `references/12` 第五节）。
   数目给到精确个位的自算单位数（吨成本、吨毛利）同样慎入：未过口径与对照的，
   按 `00` 数据规范第 8 条降级，不进速览。
4. **优势**：三条，每条独立成段。**与风险同权，不许缩水**（见下）。
5. **风险**：三条，每条独立成段。
6. **最大证伪点**：一行写清"这套判断最经不起检验的地方在哪"——多空两侧各证伪一遍之后，
   最薄弱的那一环是什么，**再带一句它被推翻时该看到什么**。
   来源见 `references/11-反向质疑与遗漏排查.md`。**这一行让读者拿得到反面，不只是正面结论。**
   正文写"最经不起检验的地方在利润端"，不写"最可能死在利润验证环节"——后者是底稿口令，
   照抄进正文就是机器腔（见 `references/00` 第六节·生死类说法）。
7. **排雷灯号**：绿灯 / 黄灯 / 红灯 + 一句话理由 + 事件对照表（最多三行）。
   灯号**只评价"财务信息质量与治理"**，不得外扩成对整家公司的定性。
8. **公司档案卡**：代码、**上市地与注册地（A 股 / 港股 / A+H，注册地是否为开曼、BVI 等）**、
   上市时间、总股本、市值（注明币种）、实控人、员工数、主营、所属行业、经营性资产、产能、
   **会计准则（CAS / HKFRS）与年结日**、审计机构与关键审计事项。
9. **尚未核实的事项**：每条三行（缺口 / 影响 / 去哪里找），见第十节。
10. **重点标注**：速览页是全篇标注最密的地方，取 4~7 处——核心模型里那一句主线、
   优势侧那条稀缺性、风险侧最重的那条雷、灯号本身。写法与密度上限见 `06-成稿与PDF交付.md` 第四节。

> **优势与雷点同样重要，不许写死结论。** 有硬伤的公司仍然可能有好资产、有独一无二的
> 行业位置。以海南橡胶为例：它十年内三次因财务信息质量被监管问责，但它同时是
> **国内唯一一家天然橡胶上市公司**——天然橡胶现货价格上涨时，它是全市场唯一能直接
> 承接这个涨价的股票。这类"稀缺性 / 唯一性"必须单独成条写出来，不能被一排红灯盖过去。
> **报告的主角是这家公司的生意，不是它的雷。排雷是护栏，不是结论。**

## 三、四个部分与十节

### 第一部分 生意模式

#### 1. 判定

必答：它属于哪一类（四层判定：行业归属 / 盈利特征类型 / 定价权归属 / 周期位置）？
哪一层主导当前定价？
失败写法：只贴行业代码，不解释这意味着什么。
**另一种失败写法是把判定过程讲给读者听**："盈利特征判定直接决定各节权重……"
"行业专家角色取××研究员，他的第一问是……""章节顺序按这一问排列（四层判定表××栏）"。
判定过程、角色、章节装配顺序都写在底稿里，正文只留结论——**不交代自己是怎么取角、怎么排章节的**
（见 `references/00` 第六节·过程自述）。

#### 2. 业务与单位经济

必答：一句话商业模式；收入结构（分产品 / 分地区）；成本结构；**单位经济模型**
（一个最小运作单位赚多少钱）；客户是谁、怎么定价、怎么结算、账期多久；供应商；人效。

**单位经济模型不许留空。** 表里不得出现"—"或"未获取"就完事的格子。给不出精确值时，
必须写清：① 为什么给不出（口径未披露 / 披露受限 / 无公开源）；② 怎么估（价格源、
取哪一段均价、怎么换算）；③ 量级判断及其依据。例：天然橡胶一天一个价，年度口径就定为
"上期所主力连续合约的年度结算均价"，并写明现货与期货的基差如何处理、由此得到的吨毛利量级。

**表里的每个单位数要过口径与对照。** 吨成本、吨毛利、单店收入、单客价值这一类是自算的，
年报里没有现成的。落进正文之前：分子与分母的口径必须一致（集团还是分部、含不含贸易量、
含不含财务费用），并拿一个独立来源的同量级数字比一次；比不上的降为"推算值，仅供量级参考"，
且不得承担关键结论。每个单位数在 `02-工作底稿/单位数核查.md` 留一行：
**数值 ／ 来源 ／ 实测或倒推 ／ 对照基准 ／ 档位**。做法见 `references/12-模型自检与交叉验证.md`。

**客户要写到名字。** 能查到的（年报前五大客户披露、招投标与中标公告、重大合同公告、
官网客户案例、行业媒体交叉验证）就写名字；确实查不到的，写明"公司仅披露前五大占比
XX%，未披露客户名称"，并给出可继续查的具体路径。**不许用"客户较为分散"含糊过去。**

失败写法：复述年报"公司主营业务为……"；单位经济模型留空；客户只写行业不写公司。

#### 3. 变量（本框架的核心一节，前移到此处）

必答：决定利润的 3~5 个变量是什么，**按影响权重排序**（给出**一阶敏感度**：
"X 每变动 1 单位，净利变动多少"）；用什么高频指标跟踪；好 / 中 / 坏三情景下数字落在哪；
**国际变量**（汇率、大宗价格、关税、出口管制、海外需求）。

**价格类变量必须做归因。** 不能只写"价格处在历史高位"。要写清这一轮价格变化由什么驱动：
供需缺口、成本推动、政策，还是突发事件（天气、地缘、装置事故）。**不同原因对应完全不同的
持续性判断**，也直接决定第九节该怎么读分位。周期型的库存、供给、需求数据至少给近 5 年。

失败写法：罗列 20 个指标，不排序、不给敏感度；只报价格位置、不给归因。

### 第二部分 外部条件

#### 4. 空间与周期位置

必答：行业怎么界定（按什么口径分类、边界划在哪）；TAM/SAM/SOM 各是多少、怎么算的；渗透率处在
什么位置、对应生命周期哪一段；增长从哪来（量 / 价 / 新市场）；**全球市场规模 vs 国内规模**；
**周期位置**（价格分位 + 涨价归因 + 供给刚性 + 库存）。

**必答时序数据：** 至少给出**近 5 年**的产量、消费量、进出口、库存、价格（均价）序列，
据此判断处在库存周期的哪一段。**只写一年的供需量等于没写**——库存周期是判断价格
持续性的唯一依据，而价格持续性决定了后面全部估值判断的前提。不涉及国际定价的品种，
就给国内的供需与库存序列。

**周期型必答"阶段"，而且要先答"哪条路"。** 按 `references/08-产业周期与择时.md` 第一节先分流：

- **A 类（过剩出清型）**：写清处在四阶段（出清前夜 / 出清兑现 / 产能重启 / 供给放量）的哪一个，
  逐项给出清判据八项（资本开支增速、在建工程÷固定资产、行业亏损面、价格 vs 现金成本线、
  开工率、库存三口径、新增产能三张表）的读数，回答**出清走到哪一步、方向是在恶化还是在改善**。
  **结论照判据的方向写**：判据没转好就写"出清没有进展、基本面还在走坏、价格缺乏上行动力"，
  不写"触发条件尚未凑齐"。**这一句要与速览页的股价节奏坐标对得上**；
  已经涨过一轮、手上正好有起止与幅度的，顺手写上（见 `08` 第二节末）。
  产业仍停在"尚未出清"时，报告要直说这层判断——它比再补十个分位数字更有用。
- **B 类（需求拉动／资源约束型，如小金属、原油、种植品）**：写清处在五阶段（需求启动 /
  缺口打开 / 供给追赶 / 供给放量 / 再平衡）的哪一个，逐项给缺口判据七项（现货价与加工费、
  上下游库存、下游开工率与订单、新增供给投放进度、配额与管制、进口与回收料、替代与减量使用）
  的读数，回答**缺口是打开了还是正在被补上**。
  **这一类禁用"尚未出清""触发条件尚未凑齐"这套词**：它的供给受矿山与种植的物理周期约束，
  不存在全行业亏损到产能退出那一段，硬套 A 类语言会得出方向相反的结论（东方钽业实盘）。
- **两类都要补"见顶判定"**（`08` 第四节）：行业见顶信号与股价见顶信号各逐条写"已出现／未出现"。
  只看出清、不看见顶，行业走完一轮数倍上涨之后，报告仍会写成"还没开始"。

**事件驱动型（牌照 / 许可）**改给**事件日历**：政策、许可与产能置换批复、整合与资产注入、
重大订单、提价、监管处罚，各自的可能时点。

失败写法：只有"市场空间广阔"，没有测算过程与假设；只给一年的产需数字；
**把判据指去底稿**（"按分流三问（底稿《四层判定表》4.0，两问为否）""完整 N 段见底稿
《历史股价复盘》""（详见底稿）"）——报告要自足，判据与结论写在正文里，
完整版放附录（见 `references/00` 第六节·报告要自足）。

#### 5. 竞争与产业链

必答：产业链全景；横向格局（CRn、公司排第几）；可比公司对照（**国内 + 国际**，
比业务结构、份额、毛利率、ROE）；护城河属于哪一类、有多宽；
**这家公司的稀缺性 / 唯一性**（是不是某个细分里唯一的选择）。

**产业链要列全，并带占比。** 上游原料逐项列出、下游应用逐项列出，各自给出占比与数据年份。
只写"下游主要是轮胎"是不合格的——必须写清轮胎、胶管胶带、鞋材、乳胶制品、医用手套、
翻新胶等各占多少。**列示时参照期货软件（文华、同花顺、博易）的产业链图谱搭骨架，
再逐项去找占比数据**；确实找不到占比就写"未取得，需 XX 数据源"，不许用"主要是"打发。

**利润分配要落到数字上：** 同一时点各环节的毛利率各是多少，钱落在产业链的哪一段。

**国际对标不许因为"查不到"就跳过。** 拿不到可比公司数据时，写清为什么拿不到
（无上市纯标的 / 数据源反爬 / 官网改版），并给出可替代的口径与下一步渠道。

失败写法：只列国内同行；把"市占率第一"当护城河结论；下游只写一个品类。

### 第三部分 财务与风险

#### 6. 财务

必答：赚了多少（三表关键项，不列全表）；ROE 靠什么撑（杜邦分解）；赚得干不干净（经营现金流/净利润、营运资本）；钱花到哪去了（**资本配置**：再投资回报、分红、回购）；关键资产科目；**母公司报表 vs 合并报表对照**。
最后一项在"账面赚钱但主业不赚钱"的公司上往往是全篇最有说服力的一张表——海南橡胶 2026 年上半年母公司净利 +0.93 亿元、合并归母净利 −1.30 亿元，差额全部来自母公司口径的政府补助与营业外收入，钱从哪来一眼就看完了。
失败写法：堆财务比率，不回答"这家公司赚不赚钱、赚得真不真"。

#### 7. 排雷

必答：跑完整检查表（`04-排雷清单.md`），只写命中项与接近阈值的项，给出绿/黄/红。
失败写法：写"公司经营稳健"这类没有检查动作的结论。

### 第四部分 尺子与边界

#### 8. 历史股价复盘

必答：上市以来（或近 10—15 年）的**中长线**上涨与下跌各由什么驱动；把每一段的涨跌幅
**拆成利润与估值两侧**（每股收益的变动、市盈率的变动），说明这一段是利润推的还是估值推的；最近一轮调整从何时开始、
已持续多久、幅度多少、期间利润与关键变量怎么走；**事后看什么结束了上一轮调整**、
**当时最早能看到的先行信号是什么**；按本公司自身历史与行业经验，这类调整通常持续多久；
当前这轮走到哪一步。上涨段与调整段**对称着写**，只写一侧即为不合格。

**每一轮调整要判性质：上升中继还是顶部结束**（`08` 第四节）。把本轮回撤的幅度与时长，
分别与这只股票历史上"中继调整"与"见顶后调整"两条分布对照，写明更像哪一条，
并给出排除另一条的理由。**只写一侧不合格**——只说见顶、或只说没走完，都等于没判。
同时给出**三个读数的位置**：商品价格、利润增速、股价各自的方向（谁领先、谁滞后），
以及两条硬判据（供给短期增不出来、需求还在增加）的读数，见 `08` 第四节 4.8／4.9。

**不做逐日／逐周涨跌归因。** 短期是投票机，日线波动没有可复现的因果；
这份复盘要的是中长线段与可核对的驱动。切法、利润侧与估值侧拆解（每股收益、市盈率）、调整段专项九列、
行业调整期对照基准、结束信号清单、催化怎么写，全部见 `references/13-历史股价复盘.md`。

**禁止**：逐日涨跌归因；把一次性催化（事故、传闻、大盘暴跌）写成公司竞争力；
由"跌了 X%、PE 为负"直接推出结论（与铁律 8 同源）；任何交易指令。

#### 9. 估值口径与参照带

必答：该用哪个模型、为什么；**关键估值指标**是什么（写清是市盈率、市净率还是 EV/EBITDA，
不写"倍数"这个笼统说法）；当前处在历史什么分位、同业什么分位；
这个行业通常还用哪些模型（**按行业实务与卖方惯例写，不写成与任何方法论文献的对照**）；以及**估值参照带**。

**同一个估值指标在不同周期阶段含义相反，所以指标必须连着阶段一起报。** 估值节要把第 4 节判定的
产能周期阶段带进来：周期启动阶段（第一阶段）的高市净率不是贵，盈利兑现期（第二阶段）的低市盈率
也不是便宜，产能重启期（第三阶段）的高盈利对应的低市盈率才是风险信号。每一个分位数字后面都要跟一句
"这个读数落在周期的哪个阶段"，否则读者会照着静态分位得出反向结论；分位还要与**第八节的历史段**对齐——脱离历史价格区间谈分位，等于把刻度尺的零点随手挪
（见 `references/05-估值模型库.md` 与 `references/08-产业周期与择时.md`）。

**估值参照带（必答，2026-10-12 新增）。** 只报分位是不够的——读者知道了"现在在哪"，
仍然不知道"价格变了会怎样"。参照带要回答的是后者：把决定利润的核心变量（周期股是品种价格，
成长股是渗透率与份额，红利股是现金流与分红率）分成若干档，逐档给出该行业惯用估值指标的
参照区间与折合每股区间。

- **周期股实例**：给出胶价 1.3 万 / 1.8 万 / 2 万 / 4 万元每吨各档位下的正常化归母净利、
  ROE、对应的历史 PB 参照区间与折合每股区间，另附盈亏平衡价与临界价反算
  （详见 `05-估值模型库.md`）。
- **样本外要标注**：价格从未到过的档位没有统计样本，只能外推，**必须写明"这是外推，不是统计"**，
  并退回上一轮周期的极值锚。
- **四项缺一不可**：推导链、样本区间、假设清单、局限说明。**单独给一个数字就是目标价。**
- **每个模型都要过一遍自检**：这个模型的分子分母同不同口径、结果有没有越出样本区间、
  哪个假设挪一下结论就会翻转。记录落 `02-工作底稿/模型自检.md`。见 `references/12`。

**禁止**：给出目标价、合理价位、贵/便宜的买卖结论、买卖评级。只描述位置与推算，
不替读者做决策。参照带与目标价的界线见 `00-铁律与偏好.md` 第一节。

#### 10. 判断的边界

必答：关键假设是什么；什么信号出现说明这套判断错了（证伪条件）；哪些数字没查到——
**每条写成三行**：已试路径 / 还能去哪些具体渠道找 / 拿到它需要什么条件。

**另加两张短表（Gate 3.5，做法见 `references/11-反向质疑与遗漏排查.md`）：**

- **多空对垒表**：两列，条目数相当，每条带数字或事实，**不给谁对谁错的判断**；表后不写收口句。
  一侧明显写不满，说明取证没做完，回 Step 1，不要硬凑。
- **本报告未能回答的关键问题**：四栏——问题 / 为什么重要 / 答不上来会改变哪个结论 / 具体去哪里找。
  **清单必须非空**；它与同一节的数据缺口（写成 `10.3 已知的数据缺口` 一类的子节）分工不同——
  **数据缺口管"数字没拿到"，这里管"问题答不上来"**，两者都在本节内，都是正文，不进附录。

**"回答不了"不等于"不用回答"。** 国际同业对比、下游占比、单位经济这类关键信息，
即使暂时拿不到，也要把"去哪里找"写清楚，让读者知道这是缺口而不是定论。
**一句"未获取"就收尾，是不负责任的。**

## 五、写作规范

### 数据不进段落（2026-10-15 新增，源自东方钽业成稿的结构体检）

**一句话：段落用来说理，表格与图用来装数据。** 上一版成稿里最难读的地方，是把七家公司、
十年产量、四类下游塞进同一段——读者被迫在句子中间干表格的活。

**一段一件事。** 一个段落只承载一个判断：一个主语（一家公司、一个变量、一段时间范围）、
一条因果链。要换主语、换口径、换层级（价格 → 产能 → 财务 → 治理），就换段。

**触发线（到了就改写，不商量）**：段落里出现下面任一条，**一律改成表或图**，
段落只留判断与一句指向（"见表 5-2"）：

- **两个以上主体的同类数字**——多家公司、多个产品、多个地区、多类客户；
- **同一指标四个以上时点的数字**——价格、销量、库存、产能的逐年序列；
- **同一段里五个以上数字**（不论是否同类）；
- **三个以上公司名或机构名**——名单一律进表（名称 ／ 国别 ／ 口径 ／ 来源）。

**例外**：全段只讲一件事的那个核心数字可以留在句内，例："2025 年销量 949 吨、同比 +34.97%"——
它是判断的证据，不是数据的仓库。

**时序出图，清单出表。** 上面三条触发线里，"同一指标四个以上时点的数字"这一类**优先画折线**，
不要满足于塞进表格——同一件事列成表只是把它归了位，画成图才看得出形状。
图的张数下限、必画清单与画法见 `06` 第五节。

**拆段按内容，不按字数。** 判断标准只有一条：**这一段是不是在说一件事。**
字数不是判据——同样 150 字，写一件事就是一段，写两件事就该拆成两段。

- **该拆的**：一段里换过主语（从行业换到公司）、换过口径（从产量换到价格）、换过层级
  （从价格换到产能再到财务），或者出现了第二条独立的因果链——**拆成两段**。
- **该并的**：同一件事被拆成一串两三句的碎段（连续几段都在给同一个判断补证据），
  **并回一段**。**拆得太碎与塞得太满一样伤结构**：读者会在频繁的断句里丢掉主线，
  节下面的标题层级也会被拉乱。

**只有一种情况要看一眼长度：某一段明显长于本节其他段落（两三倍以上），又说不清它在讲哪一件事。**
这时要解决的是"它装了两件事"，不是"它太长"。**按字数机械拆段，只会把一段完整的话
切成互不衔接的碎片。**

**成稿前过一遍两侧判据，结论落 `02-工作底稿/成稿自检记录.md`：该拆的几处、该并的几处，各写一行。**
脚本在这里只做一件事：某段超过 400 字时给一个提示（"疑似一段多事，回去读一遍"），
**它不判断该不该拆，也不要求按字数拆。**

**逻辑关系也要重排。** 段内顺序固定为**判断 → 证据 → 边界（或反方）**；不许先堆三段数据再给结论；
**并列的事不要写成因果**（"随着……，同时……"这类混用一律拆开）；一段只允许一条因果链，
第二条因果另起一段。层级不同的事（价格、产能、财务、治理）不塞进同一段。

**清单不进句子（同日补）。** 段落里不止数字会把人绊住，**并列清单与代号一样会**：
把四个证据塞进一个括号、用"A／B／C"点代号、写"读数四条对三条"，读起来就是状态行而不是文章。
**清单与计数属于表，判断与读数属于句子**——判定表里的 A／B／C／D 不出口；
两侧证据按条数数出来的那件事，写进第 4 节的表。七类机器腔写法与改写示例见 `00` 第六节·机器腔。

**表格与图的分工见 `06-成稿与PDF交付.md` 第五节**：横比与清单走表，时序走折线图，
占比与排名走横向条形图，两三条要点才留在句内。

- 结论先行：每节第一句就是判断，后面才是证据
- 标题要有信息量：写"六、盈利结构与财务质量：连亏三年，账面由补贴支撑"，
  不写"财务分析"，也不写问句
- 每个数字带来源；同一数据有多个口径时，说明取了哪个、为什么
- **面向非投资圈读者，用词按 `00` 第六节·行话与术语执行**：圈内简称（"倍数""主导侧""共振"
  "双杀""双击"）一律换成通用说法；字母缩写、财务词与行业词首次出现写成
  "中文名（缩写，一句话算法或含义）"；附录 H 逐条成行
- **语言按 `00-铁律与偏好.md` 第六节执行**：正式书面语、不用口语词、过渡词每篇最多一次、
  各节句式不许雷同、不修辞不煽动
- **优势与风险对等**：凡写到风险，同节要给出对应的优势或对冲因素，不写"一边倒"的段落
- **下限是机械的，不是感觉的。** 附录 D、E、G 的行数，以及成稿字数低于复核触发线时的处置，
  按 `00-铁律与偏好.md` 第三节与第八节执行——这几处都能数出来，不靠自觉。
- **改了节序就要同步编号**：正文交叉引用（"见 X.Y"、"第七节"、"表 3-1"）必须一并改，
  改完全文再搜一遍 `[0-9]\.[0-9]` 与 `第[一二三四五六七八九]节` 核对。

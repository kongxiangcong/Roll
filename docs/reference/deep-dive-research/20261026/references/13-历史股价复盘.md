# 历史股价复盘：这只股票过去为什么涨、为什么跌

这份文件回答一个此前被整个框架跳过的问题：**价格本身的历史。**
前面十二份文件都在讲"这家公司是一桩什么生意、值多少钱"，这一份讲"市场过去是怎么给它称重的"。

用户 2026-10-15 指定新增。起因是海南橡胶与双环科技的成稿：**周期位置判对了，
但读者仍然不知道"历史上每次这类阶段转换时，这只股票是怎么动的、动了多久"**，
而这恰恰是周期型标的里最有用的一层信息。

## 零、先划两条界线

**第一条：不做每日涨跌归因。** 股价短期是投票机——每天的涨跌由资金、情绪、
消息面与噪声决定，不可预测，也没有可复现的因果。**把日线的涨跌逐条编解释，
是研究里最典型的伪工作量。** 一份报告如果出现"3 月 5 日下跌是因为……"这类句子，
说明这一步做错了。要做的是**中长线段**：一段通常以年计，周期型的长段可以到十年以上。

**第二条：只写位置与节奏，不写交易指令。** 措辞规范与 `08-产业周期与择时.md` 第八节
**共用同一张允许／禁止表**，本文件不另立一套。所有关于涨幅、时长、领先滞后的表述，
是对历史节奏的复述；一旦写成"建议买入""目标价""仓位"，即违反铁律 1。

## 一、第一步：把历史切成若干中长线段

用**月线**切段，不用日线（日线的噪声会让人把反弹当成反转）。段的边界是**趋势反转**，
不是"某天涨了跌了"。切段规则：

| 规则 | 说明 |
|---|---|
| 段的边界 | 上一段的高点／低点，且后续没有在同方向创出新极值 |
| 最短一段 | 一般 ≥ 6 个月。成长股与科技股的回撤可以短到 6—12 个月；周期股一段可以长到 10—15 年 |
| 起点 | 上市首日，或上一轮周期低点（两种起点都要能说清各自的口径） |
| 上市不足 3 年 | 不强行切段，写明"上市时间不足，只做 N 段"并说明哪些判断因此不成立 |
| 段数 | 至少 3 段（上市确实太短的另说）；段数太少说明要么历史确实短，要么段切得太粗 |

**每个段必须能回答四件事**：从哪到哪（含时间）、持续多久、涨跌幅多少、
**这段的涨跌是利润推的还是估值推的**（下一节）。

## 二、骨架：把涨跌拆成利润与估值两块

这一步是整份复盘的地基，**不做这一步，归因就是在讲故事**。
"股票价格短期是投票机，长期是称重计"这句话落到操作上，就是这个拆解：

> **区间涨跌幅（大致）≈ 每股收益的变动 × 市盈率的变动**

两个词先给读者交代清楚（首次出现即展开，写法按 `00` 第六节·行话与术语）：

- **每股收益（EPS，归母净利 ÷ 总股本）**——对应"利润"这一侧；
- **市盈率（PE，股价 ÷ 每股收益）**——对应"市场愿意给多少估值"这一侧。

三项的含义完全不同：

| 组合 | 含义 | 读法 |
|---|---|---|
| 每股收益涨、市盈率平或小动 | **称重计在工作**：利润真的涨出来了，价格跟着盈利走 | 这类上涨具备延续性的基础 |
| 每股收益不动、市盈率大涨 | **投票机在工作**：盈利没变，是流动性、风格或叙事推的 | 这类上涨要问"钱从哪来、能持续多久" |
| 两者同时上升 | 利润与估值一起涨 | 幅度最大，回撤时也最容易被"两者同时下降"抹平 |
| 两者同时下降 | 利润与估值一起跌 | 调整期里最常见的一段 |

**算法（写进底稿，可复算）：** 取区间起点与终点两个时点的 TTM 归母净利与总市值
（或每股收益与收盘价），分别算两个变量在区间内各自涨了（跌了）多少，看哪一侧贡献更大。
两者之积应当接近区间实际涨跌幅，**差得远就说明中间有股本变动或口径断层，要查出来而不是略过**。

**口径陷阱（每一条都会让结论失真）：**

- **股本变动**：定增、可转债转股、送转、回购注销都会让每股口径断裂。
  **一律按当前股本折算每股**，或者干脆用总市值与归母净利的总额口径，不要混用。
- **会计政策变更**：追溯调整会造成同一年的利润有两个数（可参照齐翔腾达实盘：
  2023 年归母净利调整前 −3.84 亿元、调整后 −3.81 亿元）。
  **区间跨过调整年份时，两个端点必须在同一口径上**，否则算出来的每股收益变动是假的。
- **借壳、重组、更名、主业更换**：历史价格属于另一个主体时，**不要并入同一条序列**，
  在段表里断开并写明原因。
- **长期停牌与退市整理期**：停牌期间没有价格，段的时间跨度要标注出来。

产出：段表里的**「涨跌来源」**一列，写 **利润推动 / 估值推动 / 两者同升 / 两者同降**（四选一）。
**列名与取值都按 `00` 第六节·行话与术语走**——不写"主导侧"，不写"双向共振""双向双杀"，
底稿的表头与成稿一致，免得写进正文时才来回改。

## 三、归因分层：五层，逐段勾选

每段写**主因一条、次因一到两条**，每条都要带证据（哪个变量同期同向变动、从哪里取的数）。

| 层 | 内容 | 证据变量 | 取数去向 |
|---|---|---|---|
| 一 · 公司与基本面 | 利润、份额、产能投产、产品结构、治理事件 | 归母净利、毛利率、销量、在建工程 | 年报、季报、公告 |
| 二 · 行业与商品价格 | 品种现货价、价差、开工率、库存、供需缺口 | 现货价与价差序列、开工率、社会库存 | 行业协会、卓创／隆众／百川、生意社 |
| 三 · 产业周期位置 | 产能周期第几阶段（对接 `08`） | 资本开支、在建工程／固定资产、亏损面、新增产能三张表 | 上市公司汇总、统计局、行业协会 |
| 四 · 市场整体与流动性 | 指数、无风险利率、风格、汇率、资金面 | 指数区间涨跌、十年国债、风格指数、成交额 | 行情接口 |
| 五 · 事件与政策催化 | 事故、并购重组、配额与管制、股东行为 | 公告日期、政策文件日期 | 公告、部委网站 |

**两条硬规矩：**

1. **不许拿"市场整体下跌"当兜底解释。** 大盘下跌可以解释个股的一段，
   但只有当个股跌幅与所属风格指数、行业指数**大致同步**时才成立；
   个股跌幅显著大于同业时，原因一定在第一、二层里，不在第四层。
2. **区分结构性驱动与一次性驱动。** 产能出清、牌照、配额、渗透率这类是**结构性**的，
   可重复、可前置判断；事故、重组传闻、大盘暴跌这类是**一次性**的，只能事后解释。
   **段表里要标出这一段是哪种**——这是它与"对未来有没有参考价值"的唯一分界线。

## 四、调整段单独成表（这份文件最要紧的一节）

上涨段可以简写，**调整段必须单独立表**，因为读者最需要的判断是"现在这轮调整走到哪了"。
每一轮调整给十列：

| 列 | 说明 |
|---|---|
| 高点 | 时间（年·月）与价位或市值 |
| 低点 | 同上；尚未走完的写"进行中，截至 X 年 X 月" |
| 时长 | 月数；与行业经验值对照（见第五节） |
| 幅度 | 最大回撤，注明是收盘价还是最高最低价口径 |
| 期间利润与关键变量 | 归母净利、毛利率、品种价格、库存同期怎么走 |
| 期间催化 | 期间发生了什么（政策、事故、重组、大盘） |
| **事后看什么结束了它** | 事后回看，真正让这轮调整结束的变量或事件 |
| **当时已有的先行信号** | 事后看，最早能在什么时点看到拐点信号（这是全表最有价值的一列） |
| 同类对照 | 本行业同类调整的历史长度区间 |
| **调整性质** | 上升中继 / 顶部结束后的调整（四态与判据见 `08` 第四节）；**两类分开统计**，供本轮对照 |

**判读规则（三条，都与铁律 8 一致）：**

- **周期股跌幅最大、利润最难看的时点，往往不是股价的最低点附近就是它的前夜。**
  股价通常**领先盈利见底**，见底时点就落在"产能即将出清但尚未出清"这一段。
  所以"跌了 X%、PE 为负"不能推出"还要跌"。
  **这一条只对 A 类（过剩出清型）成立**：B 类（小金属、原油、种植品）没有出清这一段，
  它的低点对应的是缺口闭合、下游需求重新企稳，套用"出清"措辞会把位置判反
  （`08-产业周期与择时.md` 第一节）。
- **股价通常在商品价格见顶前 1—2 个季度见顶**（对应 `08` 阶段三：产能重启）。
  复盘时要验证这只股票历史上有没有这个提前量，提前多久，而不是假定它必然成立。
- **上涨段与调整段要对称着写。** 只复盘上涨会写成看多材料，只复盘下跌会写成看空材料，
  两者都不合格（与铁律 7 同源）。

**调整段要分两类统计（2026-10-15 补）。** 同样是回撤三成，落在"上升中继"与"顶部结束"上，
后面完全相反。所以调整段表按 `08` 第四节的两列判据标性质，并把**中继调整**与
**见顶后调整**分别算出中位幅度与中位时长——**这两条分布就是判断"当前这轮走到哪了"的坐标系**。
本轮读数与两条分布都要对照，写明更像哪一条，并给出排除另一条的理由。

## 五、调整期的长度：按行业的对照基准（不是预测）

**先看这张表用来干什么。** 它是**对照基准**：知道"这类行业历史上调整通常多长"，
才能判断当前这轮调整**是长于还是短于同类**，从而知道"还没走完"是常态还是异常。
它**不是**对这只股票的预测，也**不能**由它推出"还要跌几年"。

**主证据永远是该公司自身的历史段。** 表里的区间只做对照，研究时必须写成
"本公司上一轮调整 N 年 ／ 本行业同类调整通常 X—Y 年 ／ 当前这轮已 N 月"。

| 类型 / 品种 | 典型调整期 | 时间常数从哪来 |
|---|---|---|
| 大宗化工（纯碱、氯碱、碳四、聚氨酯等） | 2—3 年 | 新建装置建设期约 1.5—3 年，叠加从盈利见顶到资本开支决策的滞后；装置停车成本低、退出相对快 |
| 水泥、玻璃（地产链） | 3—5 年 | 需求跟随地产销售与新开工，对应库兹涅茨周期 15—25 年的下行段；窑炉停产与复产成本高 |
| 钢铁、电解铝 | 3—7 年 | 产能置换、环保与能耗政策拉长出清过程；重资产、退出成本高 |
| 基本金属（铜、锌、镍） | 3—5 年 | 矿山从勘探到投产 5—10 年，但既有产能的出清较快 |
| 小金属与稀有金属（钨、钼、锑、稀土、锂） | 5—10 年 | 矿山建设、复产与审批周期长，资源禀赋稀缺；配额与出口管制改变供给曲线；下游盘子小、波动大 |
| 贵金属（金、银） | 随实际利率周期，常见 3—8 年 | 不是产能周期，是货币与利率周期 |
| 农产品与种植（天然橡胶、白糖、棕榈油） | 5—15 年，橡胶最长 | 生物学周期：胶树种植到开割约 6—8 年、经济寿命 20—30 年，砍树是慢决策 |
| 航运 | 5—10 年 | 造船周期（下单到交船 2—3 年）叠加拆解缓慢；需求由全球贸易决定 |
| 面板 | 3—5 年 | 世代线建设期 2—3 年；厂商数量少，供给端可以做协同 |
| 养殖（猪、禽） | 3—4 年 | 能繁母猪到出栏约 10 个月，叠加补栏与去化的羊群效应 |
| 白酒与食品饮料 | 3—5 年 | 渠道库存与需求周期；去库靠动销，不靠产能收缩 |
| 医药与消费成长 | 2—4 年 | 估值消化与增速换挡；集采、医保等政策会拉长 |
| 科技与半导体 | 估值回撤 1—3 年，行业库存周期 3—4 年 | 库存周期短、技术迭代快；估值波动远大于盈利波动 |
| 红利与公用事业 | 1—3 年 | 主要跟利率与风格，盈利本身稳定 |
| 金融（银行、保险） | 2—5 年 | 信用周期与不良暴露的滞后（不良确认通常滞后放贷 2—3 年） |
| 事件驱动（牌照型） | 不按周期，按事件日历 | 波动由催化事件驱动，本身没有产能周期意义上的调整 |

**区间给得宽是有意的。** 它要能容纳不同研究者切段口径的差异；**任何把这张表当成
精确预测的写法都是错的**。表里的数字是历史区间的归纳，不是这只股票的时间表。

**这张表管跌，上涨期看 `08`。** 每个品种的**上涨通常持续多久**（化工 2~3 年、
天然橡胶 5~6 年、小金属 3~8 年……）见 `08-产业周期与择时.md` 第四节 4.9 的对照表。
两张表合用才能回答"这轮涨了五年，在本品种里算长还是短"。

**除行业时间常数之外，还有三个会改变调整长度的因素，必须单独写一句：**

- **市场整体环境**：大盘处在熊市还是牛市，会让同类调整的长度差出一年以上。
- **金融市场的流动性**：利率水平与资金面松紧直接影响估值端的压缩幅度与恢复速度；
  同样的基本面，流动性差的年份调整更长。
- **制度与政策环境**：注册制、退市制度、行业配额、出口管制、收储，
  都可能**改变供给曲线的形状**，从而改变这个行业调整期的长度本身——
  遇到这种情况要在报告里写明"本行业的调整期长度可能已经与历史不同，原因是……"。

## 六、什么标志调整结束（按类型给可核对的信号）

写"调整结束的标志"时，**不要写"情绪修复""预期改善"这类不可核对的话**。
下面每一条都能从公开数据里数出来。

| 类型 | 可核对的结束信号 |
|---|---|
| 周期型（商品价格驱动） | 价格跌破边际产能现金成本并维持足够时间；行业资本开支增速转负、在建工程／固定资产回落；亏损面扩大、停产检修与产能退出公告出现；厂库／社会库／交易所仓单同步去化；下游开工率回升、价差转正 |
| 成长型 | 渗透率越过临界点；单位经济模型转正；收入增速重新加速；获客成本不再上升；机构持仓与卖方覆盖出清到低位 |
| 科技型 | 技术路线未被替代；新产品进入大客户供应体系；下游资本开支周期见底；研发人员结构与专利产出恢复 |
| 红利型 | 股息率相对无风险利率的利差扩大到历史高位；自由现金流对分红的覆盖（自由现金流 ÷ 分红）≥ 1；资本开支周期结束 |
| 金融型 | 信用周期底部、社融增速企稳；不良生成率见顶回落；净息差不再收窄 |
| 消费型 | 渠道库存出清；出厂价与终端价的价差收敛；终端动销回升；提价周期重新启动 |
| 事件驱动（牌照型） | 政策文件、配额调整、许可证批复、行业整合与资产注入、重大订单与中标、提价机制调整 |

**周期型的结束信号要与 `08` 第一表的出清判据对齐**，不要在这里另起一套标准。

## 七、催化剂怎么写（写了，但要标明它不可复制）

消息催化与政策催化**可以写进当轮涨跌的归因**，它们是事实。但必须做两件事：

1. **归到正确的层。** 一次性催化（事故、传闻、大盘暴跌）是第四、五层，
   不是第一、二层。**不许把一次性事件写成"公司竞争力提升"。**
2. **标注不具前瞻性。** 一次性的催化**不可复制、对未来的参考价值有限**，
   报告里要明确写出这一句。措辞可用：
   "该轮上涨的主要驱动是一次性事件，不可复制；对判断未来的参考价值有限。"

**结构性催化则相反**——产能出清、牌照、配额、渗透率越过临界点这类，
**可以前置判断、可以重复发生**，属于第三层，是复盘里真正有延续价值的部分。
**复盘的价值高低，取决于能否把"结构性驱动"从"一次性催化"里挑出来。**

## 八、与产能周期的对接（与 `08` 的分工）

| 文件 | 管什么 |
|---|---|
| `08-产业周期与择时.md` | **行业状态**：这条周期走 A 类还是 B 类、处在第几阶段、库存周期第几象限、方向是恶化还是改善、**是否见顶** |
| 本文件 | **价格事实**：历史上每次阶段转换时，这只股票怎么动、动了多久、提前或滞后多少 |

**复盘的产出必须回收进 `08` 的框架**：把历史每一段贴到产能周期的阶段上，
形成"阶段 → 该阶段的股价特征"的对应。读者拿这个对应去对照当下，就知道自己在什么位置。

**但桥只搭到"位置"，不搭到"该买"。** 复盘的终点是"历史节奏是这样"，
不是"所以现在该买"。这句话是这份文件与投资建议的边界。

## 九、取数与口径

| 要什么 | 从哪来 | 注意 |
|---|---|---|
| 月线行情序列 | 行情接口（见 `03-数据源地图.md` 的行情与估值序列接口） | 复权口径统一，全篇只用一种 |
| 估值序列（PE-TTM / PB） | 同上 | 亏损年份 PE 无意义，改用 PB 或 EV/EBITDA |
| 分位 | 与本文件第四节的段起止时点对齐 | 分位是"位置"，不是"贵贱"（铁律 8） |
| 公司财务序列 | 年报、季报 | 区间跨会计政策变更年份时，两端同口径 |
| 事件与政策日期 | 公告、部委与协会网站 | 只记日期与事实，不写因果 |
| 品种价格序列 | 行业协会、卓创／隆众／百川、生意社、期货行情 | 现货均价怎么算要写明（日度均价／月度均价／算术平均还是加权） |

**拿不到价格序列时怎么写：** 不许留空、不许用"约"字糊过去。
写明"哪个渠道可以拿到、大概什么口径、需要什么条件（付费库／权限／线下调研）"，
按铁律 2 的缺口三行处理。

## 十、落点与产物

**底稿：`02-工作底稿/历史股价复盘.md`**，至少含三块：

1. **段表**（第一节 + 第二节）：段 / 起止 / 时长 / 区间涨跌幅 / 每股收益变动 / 市盈率变动 /
   **涨跌来源** / 所属产能周期阶段 / 主因 / 次因 / 证据 / 结构性或一次性。
   表头用词按 `00` 第六节·行话与术语：不写"倍数""主导侧"，写"每股收益变动""市盈率变动""涨跌来源"。
2. **调整段专项表**（第四节九列）。
3. **调整期长度对照**（第五节）：本公司历史各调整段时长 ／ 本行业经验区间 ／ 当前这轮已持续多久。

**正文：第八节。** 标题写成"主题：结论"（例："八、价格的历史：两轮上涨由利润推动，
当前一轮调整已 N 年"）。**节的写法**：

- 先给段表，再给调整段专项表，最后给判断；
- 每段的第一句是判断，不是时间线叙述；
- **不写"这一段当时是因为……所以涨"的因果堆砌**，只写主因、次因与证据。

**速览页：一行"股价节奏坐标"。**
与已有的"周期坐标"并列，写：上一轮高点在何时、调整已持续多久、
**按该公司自身历史与行业经验，这类调整通常持续多久**、当前依据哪些信号判断走到哪一步。
这一行回答的是读者合上报告前最想知道的那个问题："现在是什么时候"。

**这一行是给人念的**——读者合上报告前最后看的一行，要能一口气读完。所以只写判断与读数本身：
**不写字母代号（"C · 顶部结束"）、不写条数计数（"顶后读数 4 条对中继 3 条"）、
不把四个证据塞进一个括号、不写"排除的理由即前四条"**——这些是表与底稿的语言。
两侧证据的逐条对照放第 8 节的表，速览页只留"更像哪一侧、差在哪个读数上"。
七类机器腔写法与改写示例见 `00` 第六节·机器腔。

## 十一、闸门（可数的那几条）

`scripts/check_gates.py` 会核这几项：

- `02-工作底稿/历史股价复盘.md` 落盘且有实质内容（不是一句话）；
- 段表数据行 **≥ 3 段**；
- 表里有**利润侧与估值侧两列**（每股收益变动 / 市盈率变动，或同义的全称写法；只写"涨了"不算）；
- 有 **调整段专项表**，且写出**结束标志**；
- 有**本公司历史调整段时长与行业经验值的对照**；
- **调整段分了两类**（上升中继 / 顶部结束后的调整），并分别给出中位幅度与中位时长；
  本轮读数与两条分布都对照过，写明更像哪一条、为什么排除另一条（`08` 第四节）；
- 成稿里能定位到这一节，且速览页有股价节奏坐标一行。

**没跑过这一节，不等于"这家公司历史太短"**——上市不足的按第一节的例外写法处理并写明，
不许直接跳过。

> **方法论示例（不进交付物）。** 本文件里若要举例，用行业公认的经典案例即可：
> 白酒龙头历史上的三次大跌分别对应行业事件、金融危机与市场长期低迷，
> 而长期上涨由利润与资产推动；橡胶种植股的上涨直接绑定现货价格，调整期以十年计；
> 钨钼这类小金属的上涨由下游需求放量与矿山投产滞后共同驱动。
> **这些是训练用的例子，除非研究的就是该公司，否则不许写进成稿。**

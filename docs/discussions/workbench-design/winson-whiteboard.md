# 五模块数据流与三视图工作台设计

产品与工作台专题白板，2026-11-27。归属分组：**产品与工作台**。讨论边界：如何在保持 `Data Foundation → Research → Experiment → Decision → Review` 底层五模块与双流水线严格隔离的前提下，从用户看盘与决策视角重构工作台视图、入口与信息密度。阶段 03 实验证据归属见 [研究证据如何进入决策](../research-decision/winson-whiteboard.md)。

## 目标与边界

- **成功标准**：打开首页 30 秒内看清「市场环境、个人账户大纲、自选池涨跌与每只股的下一步动作」，一键同步日常数据或进入单股复盘/研究；常规界面零哈希 ID、零原始 JSON、零证据审计长表。
- **硬约束**：底层不破 [ADR 0005](../../adr/0005-external-research-and-deterministic-admission.md) 与 [ADR 0006](../../adr/0006-roll-orchestrates-research-and-decisions.md)（盘后裁决零模型调用、未发布草稿与开发实验不污染生产计划、复盘跟进剥离私人账户与成交）。
- **已有资产**：Stage 01–03 全部后端闭环已交付（`8336dd0`）；现有 [workbench.css](../../../backend/src/roll/v3/workbench/workbench.css) 已具备暖米白纸面 + 松墨绿 + 等宽数字的基础排版体系。

### 布局推导链与竞争路线对比

- **前提（事实）**：用户日常高频关心 5 类信息（A 股/ETF 环境、个人财务大纲、自选池涨跌、当前个股量价/策略、待复盘事项），低频进行 2 类重操作（深度个股研究、策略对照实验）。
- **推导**：设自选池有 $N=5\sim 10$ 只股票（假设）。若采用**竞争路线 A（单屏全铺页）**，将大盘、财务批次、自选池、个股详情、研究草稿与复盘录入表单同时展开，首屏独立视觉块将超过 $25\sim 30$ 个（推断），导致高频看盘视线被低频表单淹没；若采用**路线 B（三视图渐进布局）**，首屏固定为 **5 个定高区域**（左顶市场环境卡 + 右顶财务大纲卡 + 左主自选列表 + 右主联动个股快照 + 底部单行复盘待办条），信息块控制在单屏无压力扫读范围内，重表单全部退入按需点击的二级视图。
- **敏感点与用户拍板（2026-11-27）**：用户明确要求工作台**完全不放证据、审计与材料来源**，且**推倒重做旧版暖纸墨色研报风**，采用让布局说话的现代极简空间结构（靠分组、层级、留白与视觉动线替代指导文案）。后端发布门禁和证据可追溯性保留在 SQLite 与 CLI，前端发布被阻断时仅做简洁状态反馈。

# 单屏行情工作台

更新：2026-10-28。分组：产品。边界：工作台信息架构与交互，不修改账户及研究权限。

## 目标与已明确要求

用户对当前工作台不满意，要求类似 TradingView 的看板和 K 线界面；信息集中在单屏，不采用整页上下滚动；只显示关键数据和图表，不显示审计、证据信息。这一要求替代旧工作台以研究说明和来源浏览为中心的呈现方向。

## 本轮检查与推导

读取当前 daily-use.tsx 和 workbench.css：大标题、说明段落、研究判断/事实与来源/观察复盘三个页签与账户侧栏构成页面；内容采用正常文档流。这支持“信息架构需要重做”的判断。未在本轮运行浏览器，不把源码检查称作视觉验收。

用户目标是同时观察图表与关键数据，因此建议固定视口、中央主图、周边联动面板。单屏不意味着把所有模块压小：优先保证主图尺寸，其余按当前证券和当前任务筛选。

竞争解释：不满意可能主要来自视觉风格。但只改颜色仍保留原有纵向信息流，无法满足已明确的无整页滚动要求；用可点击原型检查布局更直接。

## 布局提案（尚未实施）

- 默认深色中性底色、细分隔线、紧凑表格；配色是提案，用户未指定。
- 顶栏约 44px：证券搜索、当前股票、数据时点、刷新与设置。
- 左侧约 220px：持仓/自选切换，名称、价格、涨跌幅；选择证券联动其他面板。
- 中央弹性主区：价格及涨跌摘要、周期/复权控制、K 线与均线、成交量副图；缩放、平移、十字光标。
- 右侧约 280px：当前证券关键指标与精简辅助观点（结论、关键条件、风险）；禁止长篇报告挤占主图。
- 底部约 180px：持仓/相关新闻/回测结果页签，共用区域；默认持仓。只展示当前页签。
- 整页无滚动；列表内部滚动；可收起侧栏、放大主图。优先验证 1440×900 与 1920×1080；较矮屏幕先收底栏。
- 实际成交录入通过弹窗或抽屉完成。

## 减法

从工作台移除审计、证据、运行日志、资格术语、来源底稿入口、大标题口号、长篇解释和重复状态卡片。不在首页另放折叠证据块。底层记录及已有权限语义保持原状。

推迟任意拖拽布局、多图联屏、完整画线工具、全指标库、秒级实时行情；只有基础单图看板体验通过后再评估。首版周期由真实数据能力决定，日线不足时显示缺失，不生成假 K 线，也不以日线冒充分时。

## 复用调查

2026-10-28 阅读官方在线资料，未安装、未运行、未检查固定提交：

- TradingView Lightweight Charts：https://github.com/tradingview/lightweight-charts 。官方 5.1 文档：https://tradingview.github.io/lightweight-charts/docs/5.1/api/interfaces/LayoutOptions 。适合嵌入 Roll 自有数据的金融图表；工作台面板、业务联动及指标计算需另做。保留所要求的 attribution/NOTICE。
- 产品比较：https://tradingview.github.io/lightweight-charts/docs/product-comparison 。Advanced Charts 需申请访问；Widget 是托管图表路线，接入工作量较小，但与 Roll 自有数据及业务联动的适配不同。两种图表库本身均不提供行情数据。

建议复用 Lightweight Charts，不自研 K 线渲染引擎。不照搬 TradingView 全套工具。

# Triage Labels

| 标准角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予实施 |

技能提及分诊角色时，使用对应的本项目标签。
本地 Markdown 任务通过顶部附近的 `Status:` 行记录标签。

需要调整标签词汇时，编辑此表的“本项目标签”列。

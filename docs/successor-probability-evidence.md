# 后继政策的保存概率证据

后继参数已绑定后，在原“后继政策完整设计与验证”区展开“后继概率证据绑定”。先在前驱研究报告保存概率核验和对应区块核验，再读取来源、选择并保存关联。查看或原件重放不调用数值库、不拟合。

关联必须来自同一前驱完整冻结、原模型工件及原标签截止。区块报告必须引用所选概率报告的同一ID、manifest和截止；不能将两个“模型相同”的不同报告混用。入口阈值继承原0.60；不允许以关联动作改变已冻结策略。

保存CAL两阶段的成熟唯一/类别/选中支持、原库对齐数值、SOURCE区间和完整日历缺失。METHOD解析算例不能算进来源支持。同日排除的未知事件保留该日期未知。复用CAL拟合窗口不能验证独立校准；类别、占用分箱、选中样本、有效时间块及日历不足沿冻结要求明确列出。G3始终INCONCLUSIVE，假设、完整实验及资格未授予。

关联记录包含两个父manifest、原模型指纹、原截止、方法和结果原件。读者复用概率和区块原校验器，递归核对父报告引用的来源/方法归档；嵌套原件损坏时读取和重放均拒绝。原协议/模型/参数冻结/尝试次数不改变。

API：`POST/GET /api/research/policy-successor-freezes/{id}/probability-evidence`；`GET /api/research/successor-probability-evidence/{id}`；`POST /api/research/successor-probability-evidence/{id}/replay`。最多10,000事件/阶段，关联仅线性计数和已存数值读取，不新增bootstrap或评分进程。

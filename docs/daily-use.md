# 江西铜业日常使用

本阶段用于 SSE:600362 的事实分析、持续更新和实际买卖记录。模型训练、收益验证、正式建议仍在独立研究路径中，不阻止这里的使用。

## 启动和停止

在仓库根目录执行 `./scripts/start-roll.ps1`，打开 http://127.0.0.1:5173，默认进入「日常使用」。

`./scripts/start-roll.ps1 -Status` 检查 API、worker 和网页。沿用 `%LOCALAPPDATA%\Roll`；在沙箱或重定向环境中应显式传入 `-DataDirectory <实际账户目录>`，避免误用另一份空账户。

启动脚本会复用本项目已安装的 AKShare/Trafilatura 隔离环境，也支持 `-AksharePython`、`-TrafilaturaPython` 显式指定位置。已有进程不会热更新环境配置；改变代码或配置后先停止再启动。

`./scripts/start-roll.ps1 -Stop` 仅强制停止启动回执中 PID 和创建时刻匹配的 Roll 进程树，保留数据库、原件和日志。强制停止可能留下中断任务，页面如实显示中断；正在采集时优先等任务结束。关闭网页不会停止后台。电脑关机、睡眠或进程停止期间不采集；本阶段没有安装开机自启服务，开机后重新执行启动命令。

## 每日使用

### 真实辅助样例（2026-10-23 已验收）

「日常使用」顶部的「研究辅助与探索回测」可一键运行江西铜业、上证指数、沪深300和创业板指真实日线 → CODEX 辅助判断 → 固定5/20日均线探索回测 → 保存复盘。无需先创建账户或取得正式交易资格。18:00后请求当日已收盘数据，此前截至昨日；实际可用时点和过期状态始终显示。此入口目前按需运行，不代表已有30分钟自动综合分析。

CODEX 复用显式指定的已有 ChatGPT 授权文件；本机启动命令：

```powershell
./scripts/start-roll.ps1 -DataDirectory C:/Users/72449/AppData/Local/Roll -CodexAuthFile C:/Users/72449/.codex/auth.json
```

样例采用 BaoStock PUBLIC 有界读取，最多120自然日，原始回执、代码版本、辅助观点、成交、净值、基准和复盘分别保存。妙想此次实际返回积分耗尽，未成为启动依赖，也未购买额度。临时 CODEX 任务无交易和账户写权限；任务结束移除临时授权副本。重新启动使用相同数据目录即可找回历史；执行中断保留已取得内容并显示 INTERRUPTED。

回测只保留最后一次昨收调整之后的窗口，以未复权价模拟；费用、主板10%限制、日线成交等均为显式假设，未核验特殊临时规则或完整权益总回报。收益可为负，不代表已验证策略。完整证据见 [首个真实样例验收](../.scratch/roll-decision-assistant/acceptance.md)。

### 原有观察与账户流程

1. 首次使用先确认当前现金与持仓，无需补齐全部历史交易。
2. 「最近更新」查看行情、财报、新闻的实际保存时点与任务状态。来源内容不完整时仍显示已取得内容。
3. 可手动请求行情、财务和新闻更新；勾选刷新来源才会联网，否则只整理已存事实。
4. 「今天的事实观察」可按需分析或盘后复盘；「财务观察」显示确定性指标、变化与原件；新闻可查看正文及来源。
5. 通过「记录实际买卖」输入券商实际成交，预览差异后确认。自动填入江西铜业代码，费用未知时使用原暂估流程。这里不会替用户下单。
6. 在「历史记录」查成交与复盘；在「设置」创建、导出完整备份。

## 持续更新范围

已有 worker 与单租约负责调度，设置保存在应用数据库。启用对应盘后选项后，在有效交易日上海时间 15:05 后分别安排当天行情、财务和新闻任务；同一类别每天只安排一次。重启保留任务身份，不补写离线期间的预测。

行情只请求江西铜业近 90 个自然日的搜狐原价日线与新浪报价，每任务最多两次调用。财务复用同一上海自然日缓存，次日允许重新更新；新闻复用 15 分钟来源缓存，保留既有单次列表和正文数量限制。来源暂停、退避及错误继续可见。刷新不要求历史完整覆盖或模型资格。

行情和事实观察并不代表实时交易状态、完整公司行动或经过验证的买卖建议。缺失信息只限制依赖它的分析。当前版本不启动训练、不生成真实成交、不授予模型资格。

验收范围与实际结果见 [日常闭环验收](../.scratch/roll-daily-use/acceptance.md)。

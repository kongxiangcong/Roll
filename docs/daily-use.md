# 持仓与自选日常使用

本阶段用于有限持仓与自选中受支持的沪深A股的事实分析、持续更新和实际买卖记录。模型训练、收益验证、正式建议仍在独立研究路径中，不阻止这里的使用。

## 启动和停止

在仓库根目录执行 `./scripts/start-roll.ps1`，打开 http://127.0.0.1:8010，默认进入「日常使用」。首次安装先运行 `./scripts/install-roll.ps1`。

`./scripts/start-roll.ps1 -Status` 检查 API、worker 和网页。沿用 `%LOCALAPPDATA%\Roll`；在沙箱或重定向环境中应显式传入 `-DataDirectory <实际账户目录>`，避免误用另一份空账户。

启动脚本会复用本项目已安装的 AKShare/Trafilatura 隔离环境，也支持 `-AksharePython`、`-TrafilaturaPython` 显式指定位置。已有进程不会热更新环境配置；改变代码或配置后先停止再启动。

`./scripts/start-roll.ps1 -Stop` 仅强制停止启动回执中 PID 和创建时刻匹配的 Roll 进程树，保留数据库、原件和日志。强制停止可能留下中断任务，页面如实显示中断；正在采集时优先等任务结束。关闭网页不会停止后台。后台完成观察任务后自动更新合并报告；输入未变则复用已有报告版本。电脑关机、睡眠或进程停止期间不采集；本阶段没有安装开机自启服务，开机后重新执行启动命令。

## 每日使用

1. 首次使用先确认当前现金与持仓，无需补齐全部历史交易。
2. 「最近更新」查看行情、财报、新闻的实际保存时点与任务状态。来源内容不完整时仍显示已取得内容。
3. 可手动请求行情、财务和新闻更新；勾选刷新来源才会联网，否则只整理已存事实。
4. 「今天的事实观察」可按需分析或盘后复盘；「财务观察」显示确定性指标、变化与原件；新闻可查看正文及来源。
5. 通过「记录实际买卖」输入券商实际成交，预览差异后确认。自动填入所选证券代码，费用未知时使用原暂估流程。这里不会替用户下单。
6. 在「历史记录」查成交与复盘；在「设置」创建、导出完整备份。

## 持续更新范围

已有 worker 与单租约负责调度，设置保存在应用数据库。启用对应盘后选项后，在有效交易日上海时间 15:05 后分别安排当天行情、财务和新闻任务；每证券每类别每日最多3次；来源未就绪或暂时失败时，距上次结束至少15分钟后可追加尝试，上海时间21:00后不再安排。用户取消不自动重试；来源暂停和退避仍生效。重启保留任务身份，不补写离线期间的预测。

行情按所选证券请求近 90 个自然日的搜狐原价日线与新浪报价，每任务最多两次调用。财务复用同一上海自然日缓存，次日允许重新更新；新闻复用 15 分钟来源缓存，保留既有单次列表和正文数量限制。来源暂停、退避及错误继续可见。刷新不要求历史完整覆盖或模型资格。

行情和事实观察并不代表实时交易状态、完整公司行动或经过验证的买卖建议。缺失信息只限制依赖它的分析。当前版本不启动训练、不生成真实成交、不授予模型资格。

验收范围与实际结果见 [日常闭环验收](../.scratch/roll-daily-use/acceptance.md)。

日常版锁定安装与构建、版本诊断、恢复步骤见 [发布与运行](daily-production.md)。

## 合并报告与持续判断

页面选择持仓/自选后，可分别查看该证券来源和记录实际成交。合并报告汇总整个有限名单，不随所选证券缩小账户范围。

「生成 / 更新合并报告」整理已存事实；「今天的事实观察 → 补查缺失事实 → 按需观察」通过现有取证链补充背景指数等资料。指数指标需要20/21个连续完整日线，缺失保留未知。广度可以在报告底部导入有来源的全市场摘要，明确标为用户导入、未独立核验；没有自动全市场广度采集器，不能用自选池替代。

保存判断可登记推翻条件、价格阈值和复查日期；「已实际成交」须关联原账户确认成交。复查追加新记录，不覆盖原判断。价格条件仅用该日报告日期的完整收盘价，旧价不判触发。报告版本下拉框可回看旧版，原数据截止、取得时间、输入指纹保留。报告为事实与用户判断汇总，不包含自动交易判断。

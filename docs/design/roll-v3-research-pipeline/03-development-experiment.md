# 03 · 江西铜业 E0/E1 开发实验

阶段标识为 `roll-research-e0-e1`。01 完成后即可用离线执行桩开发实验，阶段验收再接入 02 的真实助手。用户要能回答“在同一组交易机会中，加入沪深 300 状态后，江西铜业趋势策略的结果发生了什么变化？”

## 本轮规格要回答的问题

- 在看结果前定下 E0 的个股量价规则、E1 唯一增加的沪深 300 条件、信号与执行时点。由研究者在建任务时选定这一组固定预设。Roll 复用现有成本、撮合、权益与双基准，用独立的开发入口保存成功或失败回执。现有 `experiment run` 和 `--replay` 都会登记正式区间的揭示。
- M0 冻结协议的开发窗口为 2020-01-02 至 2023-12-29。按该窗口及逐日可得性生成行情、指标和回执，再将这些材料交给助手。保留重建快照的实际取得时间及可得性假设。2026 年的公告、复盘备注、留出期行情及全窗汇总都不能进入开发输入。
- E0 与 E1 从两组必要特征均完成预热的首个共同可评价日开始，使用相同的期初现金、持仓和计量时点。回执分别报告预热或缺数减少的可评价机会，以及市场条件实际过滤的信号数。预设、有效区间和来源随回执保存。
- Roll 先计算并冻结回执，再调用助手一次。助手引用回执中已存在的指标解释差异、不确定性及证据缺口。开发报告在任务内审阅归档，临时提出的新条件可留作后续研究线索。

## 完成标志

1. 从正式 CLI 发起任务，按回执核对共同样本、覆盖损失、净收益、最大回撤、成交与成本。助手能说明市场条件具体改变了什么。数据只支持描述或证据不足时，在结论中写明。
2. 离线复算得到相同指标。作为计算自检，在相同输入和共同起点把 E1 条件置为恒真，两条策略路径的成交、费用、权益及净值一致。
3. 审阅归档后，以固定的当前盘后输入核对 `roll plan --preview` 仍引用原个股档案。正式验收、样本揭示、生产准入记录均与实验前一致，原 M0a 报告可由 `roll experiment verify m0a-jxcc-default` 核验。

4. 逐项列出 E0 与 E1 的入场机会、过滤或缺数原因、次日实际成交或未成交及费用。按连续持仓段解释差异，标记两条路径各自最大回撤的起止及期间持仓。在同一开发回执标明差异是否集中在一个行情段，分组日均收益只作提出假设的依据。
5. 两组动作一致、差异只来自缺数或费用、或改善集中在单一行情段时，归档描述性结论并停止扩展。多个不重叠持仓段都出现待解释的差异时，再预先固定下一项仓位对照及计量口径。全开发窗匹配平均持仓只作事后归因；评估推广性使用新的独立数据。

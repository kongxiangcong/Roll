# 确定性财务指标

在单股“确定性财务指标”查询已有财报，可指定系统已知截至时间。每期展开后可查看累计、单季、TTM、同比及比率，继续展开公式和输入原件。营收趋势使用保存的营业总收入；利润率专用营业收入，不混用字段。当前事实缺口会传递到结果。

单季取同口径累计差分，TTM须四个连续可比单季。同比基期为零或负只显示绝对变化；正基期才给百分比。现金利润比使用集团经营现金与集团净利，禁止混用归母净利；分母非正拒算。金融行业及未知行业不使用通用毛利率。未知币种、单位、主体、前期、字段冲突分别显示原因。

来源更正追加事实版本。当前查询使用当前已知版本，指定旧截止重放当时观察，不把后来重述回填历史。结果附计算版本及源事实ID；GET /api/market/financial/{instrument}/metrics支持known_by，不取数、不修改账户、不授资格。当前供应商观察不构成历史PIT，指标不提供目标价、行业排名或统一买卖评分。

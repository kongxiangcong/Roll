# 保存结果的绩效图

现有研究报告内展开「QuantStats绩效图与离线报告」，可生成或查看保存版本，下载含图表的离线 HTML。每份图表绑定当时的影子修订、源报告、原模型指纹、输入日历及渲染方法指纹。后续查看与重放只校验工件，不使用当前代码重算，也不要求已安装运行环境。

QuantStats0.0.86（Apache-2.0）使用独立 Python 环境，依赖固定于 `backend/requirements-quantstats-report.lock`。已验证Windows/Python3.13.12。配置 `ROLL_QUANTSTATS_PYTHON` 为该隔离环境Python的绝对路径；缺失配置时生成明确拒绝。子进程以 `-I -B` 启动，避免项目同名模块遮蔽标准库。30秒超时、3650个已存交易时点、结果和图表各8MiB；自动数据下载及Python/requests/curl_cffi网络入口关闭。

SHADOW只使用已保存NAV，累计收益从首个保存收盘到末个收盘，首收益保留null，首次入资至首收盘收益未知。固定日历缺日、未知净值或非正净值时不计算完整区间绩效。ACTUAL、HISTORICAL预测及ACCOUNT_CONDITIONAL没有可比连续收益时分别标记，不从快照或外部转入构造收益。所有结果均为描述性报告，NOT_GRANTED。

年化假设252期、无风险率0是本报告明确列出的诊断口径，不改变原实验。252个观察收益以下不年化。QuantStats月度接口会填充未观察月份为0，本适配只输出实际包含观察收益的月份，边界月份标注为部分区间。没有保存的同窗口连续基准时保留缺口，不自动下载或重算交易来制造基准，相关相对收益不显示。

当前交付仍partial：连续基准输入及基准错位的正向联读验收尚缺。已有API、独立数值、浏览器与离线导出验收属于193文件固定METHOD副本，不证明真实研究资格或财务回报。

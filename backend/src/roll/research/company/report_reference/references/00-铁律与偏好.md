# 铁律与偏好

## 一、输出禁则（硬约束）

**禁止出现**：买入/卖出/增持/减持/推荐/目标价/合理价位/仓位建议/星级评级，
以及**交易指令式的短线择时**（"几月内会涨""现在该满仓""抓紧建仓"）。

**禁止出现方法论底本的对照。** 报告里不写"本书""与《如何快速了解一个行业》一致"
"按书中方法/口径"这类字段，也不写与任何方法论文献的对照与衔接。该书是本 skill 的**内部底本**，
只用于指导研究，**不进交付物**；行业惯例、模型选择、公司在市场中的位置，直接用行业口径写。
（用户 2026-10-13 指定：这本书构成 skill 的基础，但后加内容已远超书中内容，报告不再与它对照。）

**允许出现：产业周期阶段与择时判断。** 行业处在产能周期第几阶段、股价的两波上涨分别落在哪个位置、
产能出清到哪一步、事件日历、风险最高的窗口——这些是**对行业状态与历史节奏的陈述**，要写。
界线一条：**写的是"行业现在是什么状态、历史上这种状态之后发生过什么"（可以），
还是"你该买该卖"（不可以）**。完整对照表见 `references/08-产业周期与择时.md` 第八节。

**必须出现**：事实判断。区分两者：

- ✅ "公司利润几乎完全跟着锂价走，锂价是它的第一驱动变量"
- ✅ "它的增长完全押在单一客户身上，该客户占收入 68%"
- ❌ "因此当前值得买入"

一份没有判断的报告是资料汇编，不算交付。

**参照带与目标价的界线（2026-10-12 新增）。** 报告要给出"在某价格 / 某情景下大致对应什么位置"的
**估值参照区间**，但不得给出目标价。两者的界线是：

| | 可以给 | 不可以给 |
|---|---|---|
| 形态 | 明确假设下的推算区间 ＋ 完整推导链 | 单点价格结论（目标价、合理价位、"应该值多少"） |
| 措辞 | "若胶价维持 1.8 万元/吨，历史同类价格档对应的 PB 区间为 2.2~2.6 倍，折合每股 5.0~5.9 元" | "合理价 8 元""建议关注""当前低估" |
| 声称的东西 | 对历史事实的复述，以及在给定假设下的机械推算 | 对未来的预测，或对"该值多少"的判断 |

**三条硬要求，缺一条，写出来的就是目标价**：① 推导链完整，读者能照着复算；
② 假设清单与样本区间写明（哪一段样本、为什么不取更早的年份）；③ 局限说明写明
（这套算法在什么条件下失效）。**单独给一个数字、不带推导与样本，就是目标价。**
算法见 `05-估值模型库.md` 的《估值参照带》，脚本见 `scripts/cycle_valuation.py`。

## 二、数据规范

1. 每个关键数字在溯源表里有一行：数字 → 来源文件 → 页码/表号 → 报告期 → 访问日期。
   **坐标一律落在原件上**（`01-原始资料/` 里的文件名 ＋ 页码或表号），**不写文本抽取副本的行号**——
   抽取副本是派生物，项目结束就清掉（第七节第 5 条），写行号等于交一份没人能核的稿子。
   抽文本时把页码锚带进去，做法见 `03-数据源地图.md` 第一节
2. 原始披露优先；研报只用于找口径、找可比公司、找反方观点，数字一律回原始来源核验
3. 多口径并存时写明取了哪个、为什么
4. 查不到 → 进"待核实清单"。**落点是正文第 10 节的数据缺口，不是附录**
   （附录 I 是免责声明，见第五节与 `02` 第四节）。**每条必须写三行**：① 已试过哪些路径、为什么没拿到；
   ② 还能去哪些具体渠道找（机构名 / 数据库名 / 页面，要具体到能照着去查）；
   ③ 拿到它需要什么条件。**只写"找不到"不算完成，等于没做。**
   **缺口不阻塞首版报告**：妙想 MCP 不可用时先自动走公开接口与脚本，仍缺的项按三行格式落盘后继续研究；交付后再给补数清单，用户提供 Wind／Choice 等数据时重跑计算、图表与受影响章节，而不是只替换正文数字。
5. 禁止：用"约""大概""据了解"掩盖没有来源的数字
6. **不许留空位。** 正文与表格里不得出现"给不出就画一道横杠"式的空位。
   确实拿不到精确数字时，必须写清三件事：① 为什么给不出（口径未披露 / 披露受限 / 无公开源）；
   ② 怎么估（用哪个价格源、取哪一段时间、怎么换算）；③ 量级判断及其依据。
   例：天然橡胶一天一个价，就给出口径——"以上期所主力连续合约的年度结算均价为年度口径，
   现货与期货的基差按 XX 处理"，并附量级区间
7. **榜单、评分与名次类信息另按一档处理。** NPS、满意度、品牌力指数、行业排名、
   "第一／冠军／蝉联／榜首"这一类，来源是第三方榜单，年报通常只转述结论，
   不给样本、口径与完整名次。规范三条：① **只能引用原文原话并标出处与页码，
   不得转述成判断**（写"年报称……并引述某报告列为第一"，不写"该品牌口碑行业第一"）；
   ② 口径与样本缺失、或报告原文未获取的，降格为"公司披露的一项事实"，
   **不得作为优势、壁垒或定价权的论据**；③ 与经营数据（销量／份额／复购等）背离的，
   必须在正文写出背离。**年报的真实性不是研究者要评判的对象，但投资者有权质疑任何官方数据**——
   采信门槛与该数字要承担的结论分量成正比。四步核查与三档采信写法见 `references/11` 第九节。
8. **自算的派生数字，先过口径与对照，再进正文。** 吨成本、吨毛利、单店收入、单客价值、
   单车利润、隐含市值、盈亏平衡价这一类，是研究者自己拿两个数算出来的，年报里没有现成的。
   三条硬要求：① **分子与分母必须同口径**，并在底稿里逐项写明各自涵盖哪些主体与科目
   （集团还是分部、含不含贸易量、含不含财务费用），有一项答不上就不得写成"成本""毛利"；
   ② **每个单位数必须拿一个独立来源的同量级数字比一次**，差异超过一倍的一律降为
   "推算值，仅供量级参考"，不得承担关键结论；③ **降级的数不得进速览必记数字**。
   由反推得到的临界值（盈亏平衡价、隐含价格）同样不得进速览必记数字——
   速览页的数字会被读者当成公司的属性记住，反推值只是某个假设下的解，它属于第 9 节，
   且必须写明假设与移动幅度。五法与逐模型自检表见 `references/12-模型自检与交叉验证.md`。

## 三、篇幅与结构

- **不设页数目标。** 篇幅由内容决定：查得透就长，查不透就短
- **但有复核触发线。** 两份实盘落在这个量级（海南橡胶约 3.4 万中文字、双环科技约 3.9 万）。
  **成稿中文字数低于 15,000 时不许直接交付**——先回答一个问题并写进自检记录：
  **"内容本来就少，还是取数没做完？"** 是前者，说明理由；是后者，回 Step 1。
  **这是触发器，不是配额**：低于它会触发复核，不会触发凑字数。
- **机械下限（可以数出来的，不靠感觉）：** 附录 D 排雷表 A 股 28 行、港股 38 行，一行一项；
  附录 G 溯源表正文每个关键数字一行；附录 E 可比公司不少于 5 家，其中上市的国际同业不少于 2 家；
  **正文图不少于 8 张，且第三、四、六、八节各至少一张**（见 `06` 第五节）。
- **正文锋利**：每节第一句是判断，其余是证据
- **附录厚**：背景资料一律进附录，不占正文
- **不确定就标不确定**，不要用确定语气写推测

## 四、读者假设

读者是**投资圈外的使用者**，可能不懂行话。因此：

- **行话一律换成人话。** 单用的"倍数"、段表里的"主导侧"、正文里的"共振 / 双杀 / 双击"
  这类圈内简称，读者看不懂，**一律不写**。改写与替换对照见第六节·行话与术语。
- **术语首次出现给一句话解释。** 所有字母缩写（PE / PB / ROE / EBITDA / TTM / EV 等）、
  财务词（归母净利、扣非）与行业词（产能出清、基差）都在此列，格式：
  **中文名（缩写，一句话算法或含义）**。例：每股收益（EPS，归母净利 ÷ 总股本）。
  必须展开的完整清单见第六节·行话与术语。
- **附录 H 放术语表**，正文出现过的术语逐条成行（格式：术语 ／ 一句话解释 ／ 首次出现的位置）。
- **章节不写导语。** 不用"这一节回答一个问题""下面来看"这类预告句开头，直接给判断与证据。
  （2026-10-12 修订：原条目要求每章开头点明"这一节回答什么问题"，实盘证明它会带出讲解腔，已废止）

## 五、免责声明（固定文本，置于正文开头与附录 I）

成稿里**只写一遍**：开头那个 `>` 引用块。脚本会把它同时印到**封面页脚**与**每一页页脚**
（页足迹的是简版「本报告仅供研究参考，不构成投资建议」）。**不要为封面另抄一份。**

> 本报告基于公开信息整理，用于帮助理解该公司及其所处行业，**不构成任何投资建议**，也不提供买入、卖出或目标价判断。报告中的分析框架与事实判断仅供研究参考，投资者应自行核实并独立决策，据此操作风险自担。报告不保证所引信息的完整性与时效性；标注"待核实"的内容尤需进一步验证。

## 六、语言规范（正式书面，不机械）

**文体：正式书面语。** 这是一份给人读的研究档案，既不是清单，也不是资讯快讯。

- **用书面词，不用口语词。** "盈利下行"而非"跌得惨"；"供给刚性"而非"补不上"；
  "同比回落"而非"少了一大截"；"标的"而非"票"。
- **一句话一件事。** 不要用"不仅……而且……同时……"把三个判断串成一句。
- **少用过渡词。** "值得注意的是""需要指出的是""综上所述""换言之"，
  **每篇各自最多出现一次**——这类词的出现频率是机械感的最大来源。判断直接说，不垫词。
- **不要套模板。** 各节句式不要雷同：不要每节都以"本节回答……"开头，
  不要每条关键发现都用"首先/其次/再次"，不要每条都用同一种"**短句。** 数字……"的结构。
  段落长短要有变化。
- **不修辞，不煽动。** 不用感叹号，不用"爆炸式增长""天花板""吊打"这类夸张词。
  数字本身就是力量，不需要形容词加持。
- **判断要能被复述。** 一个结论如果需要连读三段才看明白，就是没写清楚。
- **术语首次出现给一句话解释**（与第四节读者假设配套）。

**这几条能数出来（机械核对，见 `scripts/check_gates.py`；超线按 `warn` 提示、不阻断交付）：**

| 项 | 上限 |
|---|---|
| 破折号插入语（`——` / `—`） | 个位数，全篇 ≤ 9 |
| 过渡词（值得注意的是 / 综上所述 / 换言之 / 需要指出的是） | 每个词全篇 ≤ 1 次 |
| 正文整句加粗（整句被 `**…**` 包住） | 0——加粗只用于词与短语，结论级强调走 `==` / `@@` |
| 自我指涉（本报告 / 本节 / 笔者） | 只留在口径声明、待核实条目与免责段落，正文其余部分为 0 |
| 讲解文标记（这一节回答一个问题 / 读法 / 必须说清楚 / 先说明） | 0 |
| 中文引号 | 全角“ ”，正文不出现直引号 |
| 圈内行话（倍数单用 / 主导侧 / 共振 / 双杀 / 双击） | 0，见本节·行话与术语 |

另外，关键结论（`==`）与风险（`@@`）两色的标注处数要相当，与"优势与雷点同权"一致，
细规则见 `06-成稿与PDF交付.md` 第四节。

**文体：报告体，不是讲解文（2026-10-12 新增，源自海南橡胶第四轮返工）。**

用户对第一版的判定是"不像一个报告，更像是一个强行把话说明白的文章"。二者的分别在于：
报告体只陈述事实与判断，**不向读者交代"我接下来要讲什么""这句话的意思是"**。以下为禁则，
成稿体检时逐项数：

| 禁止 | 说明 |
|---|---|
| 每节开头写"这一节回答一个问题""本节回答的是" | 章节直接进入内容；标题用名词短语，不用问句 |
| `**读法**：`"**小结**："这类标签 | 解读直接写成陈述句，不加标签 |
| "必须说清楚""必须点出""先说""最需要记住的一句话""值得记住的数字" | 作者出面强调，全部删除 |
| "换句话说""也就是说""这句话本身不是……" | 同义反复与自我辩解 |
| 用破折号做插入语 | 破折号只用于列表条目分隔，全篇控制在个位数 |
| "本报告 / 本节 / 笔者"高频自我指涉 | 只保留在口径声明、待核实条目与免责段落 |
| "行业专家角色取××研究员，他的第一问是……""章节顺序按这一问排列（四层判定表××栏）" | 作者怎么取角、怎么排章节，读者不需要知道；直接写这家公司看什么 |
| "盈利特征判定直接决定各节权重：……是重点，……不适用" | 权重体现在篇幅与先后上，不讲给读者 |
| "按分流三问（底稿《四层判定表》4.0，两问为否）""完整 13 段见底稿《历史股价复盘》""（详见底稿）" | 报告要自足：判据与结论写在正文里，完整版放附录 |
| 关键发现每条都是"**加粗结论。** 数字 + 解释" | 换陈述句并列，段落长短要有差异 |
| 加粗密度过高 | 加粗只用于表格内的关键格与全文少数关键判断；正文段落不整句加粗 |

**检验办法**：把每节第一段与"读法"类句子抽出来单读，若出现"我来告诉你"的语气，即为不合格。
样板见海南橡胶成稿的"定性"段、1.1、2.2、4.1。

**排版随文一条**：中文引号用全角弯引号“ ”，不使用直引号 `"`。
Markdown 源里写的是直引号时，成稿前逐行替换（逐行核对引号成对，避免单行引号数为奇数导致方向错乱）。

**本次实盘出现过的腔调问题（引以为戒）：**

- ❌ "这台机器赚不赚钱，不取决于经营效率，取决于三个外部变量"——既用了"机器"这个比喻，
  又是口语化的对比套式。改为："公司盈利由三个外部变量决定，经营效率的影响很小。"
- ❌ 关键发现八条，每条都是"**加粗结论。** 数字＋解释"的同一结构——机械。

**重点标注是与"少加粗"并行的另一条通道（2026-10-13 新增）。**
加粗的克制不变，它只用于词与短语，正文段落不整句加粗。
**结论级的强调改用标注**：`==……==`（主色）标关键结论与关键变量，`@@……@@`（红）标风险与雷。
分工一句话——**加粗管"这个词重要"，标注管"这句话就是结论"。**
必标清单、密度上限与禁则见 `06-成稿与PDF交付.md` 第四节。

**不接入表达习惯档案。** 本 skill **不读、不写** `~/.codex/风格档案/表达习惯档案.md`，
也不调用任何图文 / 视频文案类 skill（`wechat-article`、`xhs-copy`、`storyboard-gen`）。
理由：那份档案沉淀的是用户改**人读文案**的习惯（网感、口播节奏），与研究档案的书面文体
是两套语言，混用会把报告拉回口语。**用户 2026-10-12 明确指定：表达习惯不要调用他的任何 skill。**

### 去 AI 味：词、句、节奏（2026-10-14 新增，源自四份成稿的语言体检）

**一句话标准：这句话，券商研究员在正式研报里会不会这么写？不会，就是 AI 味。**

这不是风格偏好，是可信度问题——读者一读出机器腔，会连带怀疑数字，
一份让人边看边皱眉的报告，后面写得再对也没人读完。**词、句、段落节奏三层都要清；
只换词、不改节奏，改完还是那股味。**

**甲、自造隐喻当术语（直接禁）。** 把生意比成"引擎""外壳""开关""机器"再据它搭一套"模型"，
是最重的一类 AI 腔。真研报里的比喻是**行业早已通行的词**（周期底部、成本曲线、利润弹性、现金牛），
不是作者现造的。这类词**第一次出现就要拿掉**——留着它会像种子一样长出整节的排比。

| 禁 | 改成 |
|---|---|
| 引擎 / 外壳 / 三层壳 / 底座 / 舞台 | 直接说业务名（碳四深加工产品链、贸易板块） |

**句式上另有五种机器口，靠读、不靠数：**

| 禁 / 限 | 改法 |
|---|---|
| "不是……而是……" | 全文 ≤ 2 次。改成一正一反两个陈述句 |

**节奏与章节装配这一层比词更要紧，也最难自查。** AI 的腔调主要长在这里：

- **段落长短要参差。** 每段都是三到五句、长度相当，读起来像机器印的。关键处可以只有一句话。
- **不要每段都以判断句开头。** "每节第一句是判断"只管**节**，不管每一段；段段首句立论，
  整篇会变成格言集。
- **模块不许同构。** 同一份报告里，不要每个小节都套"现象—原因—判断"或"驱动—弹性—历史类比"
  的同一副脚手架。换一副，或用叙述推进。
- **不要先立框架再填内容。** 先甩一个"四层模型 / 三条主线 / 两把尺"再往里塞，是 AI 的装配习惯。
  按问题顺序写，读者不必先接受你的框架。
- **不用列表代替段落。** 三句话能讲清的因果，不要切成三个 bullet。正文里 bullet 是例外，
  不是默认（速览页、附录表、排雷表这些结构化处不在此列）。
- **表格后不复述。** 不写"上表显示……""由表可见……"；表后接的必须是**表里没有的判断**。
- **详略分明。** 各节篇幅不要均等。决定结论的那一节写厚，次要的写薄——等长本身就是
  "按模板填充"留下的痕迹。

### 行话与术语：正文只写读者能读懂的词（2026-10-15 新增）

**来由。** 用户读齐翔腾达那轮的历史股价复盘底稿，段表里有一列叫"主导侧"，正文通篇是
"倍数""共振""双杀"。他的原话是"什么叫倍数"。这份档案的读者是**投资圈外的人**，
不是卖方研究员。圈内简称在同一件事上有短名，圈外没有——报告的义务是把短名摊开成一句话。
**这一节与去 AI 味的区别：去 AI 味管"像不像机器写的"，这一节管"读者看不看得懂"。两条都过。**

**一、这些词一律不写（替换对照）**

| 行话 | 为什么不写 | 正文里的写法 |
|---|---|---|
| 倍数（单用） | "倍数"不是指标名，读者不知道乘的是什么 | 先给指标名与算法，再给数值：**市盈率（PE，股价 ÷ 每股收益）15 倍**、**市净率（PB，股价 ÷ 每股净资产）1.8 倍** |
| 关键倍数 / 倍数分位 / 倍数区间 / 倍数分布 | 尺子没有名字，分位与区间就跟着悬空 | 关键估值指标（写清是市盈率、市净率还是 EV/EBITDA）；市盈率的历史百分位；市净率的参照区间 |
| 主导侧 | 圈内对"这一段涨跌是由利润推动还是由估值推动"的简称 | 表列名写**涨跌来源**，取值写：**利润推动 / 估值推动 / 两者同升 / 两者同降** |
| 共振 · 双向共振 | 圈内语，字面与含义对不上 | **利润与估值同时上升** |
| 双杀 · 双向双杀 | 圈内语 | **利润与估值同时下降** |
| 双击 · 戴维斯双击 | 圈内人名梗，与这家公司本身无关 | 同"共振"一格：利润与估值同时上升。**不必给这件事起名字** |
| 戴维斯双击、戴维斯双杀 | 读者在别处会遇到这两个词，需要一个落点 | 只在附录 H 写一行对照（"戴维斯双击＝利润与估值同时上升"），**正文不用** |

**二、这些词可以用，但首次出现必须展开，并在附录 H 留行**

- **字母缩写**：PE、PB、PS、EV、EBITDA、ROE、ROA、TTM、FCF、CAGR、NPS、AH 溢价
- **财务报表项**：归母净利、扣非净利、少数股东损益、经营性现金流、资本开支、商誉、在建工程
- **行业与产业链词**：产能出清、供给刚性、开工率、社会库存、基差、升水与贴水、
  吨毛利、单位经济、渗透率、TAM（可服务市场总规模）
- **本报告自造的比率**（确有需要才造）：写成算式，如"分红覆盖倍数＝自由现金流 ÷ 分红"

展开格式统一为 **中文名（缩写，一句话算法或含义）**；括号只展开一次，第二次起直接用缩写。

**三、附录 H 的写法**

**写成三列表：术语 ／ 一句话解释 ／ 本报告首次出现的位置（节号）。** 前几份成稿用的是
"**术语**：解释"的段落式写法，也能读，但表格便于按行核对，改过来。三条要求：

- **行数 ≥ 15**，正文用到的缩写、财务词、行业词一条不落；
- 解释写"它是什么"，不写"它有多重要"；
- **与正文同口径**：正文说"归母净利"，术语表就写"归母净利"，不要一边简称一边全称。

|---|---|

### 机器腔：句子被塞成了状态行（2026-10-15 新增）

**来由。** 东方钽业那份成稿的速览页，用户的原话是"这一段读起来非常的奇怪，他不像是给人读的，
像是给机器接收指令的"。原文照抄如下：

> （不复权月收盘 90.60 元），至 2026-10-15 已调整 4 个月、收盘最大回撤 51%。中继与见顶两侧对照：
> 顶后读数 4 条（供给投放已明确、放量下跌、估值盈利背离、定增落地解禁）对中继读数 3 条
> （未破起涨平台、时间仅 4 个月短于本公司历史最短的 8 个月、需求增速未拐），
> 排除上升中继的理由即顶后四条；对顶后调整中位（-75.1%／36.5 个月）本轮尚在早期。

| 不写 | 写什么 |
|---|---|
| 行业专家角色取××研究员，他的第一问是…… | 直接写这家公司看什么（矿端供给与出口管制、三条需求线哪条在拉量、加工溢价扩了还是缩了） |
| 盈利特征判定直接决定各节权重：……是重点，……不适用 | 删。权重体现在篇幅与先后上 |
| 章节顺序按这一问排列（四层判定表××栏） | 删。底稿栏位不进正文 |
| 本报告按……的顺序展开 | 删导语，直接进第一节 |

**判据一条：句子的主语应该是公司或行业，不是"我这份报告"。**

**这批口令的源头在 `01` 与 `09`**（"决定了启用哪些模块、重点写哪几节""按该角色的第一问排序章节重点"）——
两处都写了用途是排序，都没写明"不进正文"。见到这类句子，**先回溯提示语**（与 4.10 同一路数）。

**机械化的一条（warn，不阻断）**：正文出现底稿栏位引用（如"（四层判定表××栏）"）、
"专家角色取……""章节顺序按……排列""各节权重"，`check_gates.py` 按「无过程自述」提示。
表格行、标题与代码块跳过——与机器腔同一条扫法。

### 报告要自足：正文不指向底稿与其他文件（2026-10-15 新增）

**来由。** 东方钽业那份成稿的第 4 节开头是这样写的：

> 按分流三问（底稿《四层判定表》4.0，两问为否），这条路走 B 类（需求拉动／资源约束型），
> 不走 A 类（过剩出清型）的出清框架；按五阶段读，行业处在阶段二（缺口打开）向阶段三
> （供给追赶）的过渡……

用户的原话是"我这是一份呈现给投资者的报告。怎么会让我去查底稿然后搞清楚你是怎么分类的呢。
报告呈现的目的就是为了把问题直接在当前报告中说清楚，而不是指向其他文件，
这是机器会做的事，不是人会做的事"。

那份稿子里「底稿」出现 15 次，10 次在正文：还有"完整 13 段见底稿《历史股价复盘》"、
"（详见底稿）""前提写在参照带底稿第 0 节"。**读者手里只有这一份 PDF**——
指路等于把没写完的部分藏起来。

| 不写 | 写什么 |
|---|---|
| 按分流三问（底稿《四层判定表》4.0，两问为否） | 把三问的证据写出来：需求增速与供给增速谁高、新增供给最早哪一年放量、价格有没有跌到边际产能现金成本 |
| 按五阶段读，处在阶段二向阶段三的过渡 | 处在缺口打开向供给追赶的过渡，并给出读数（缺口七项里哪几项已转向补上） |
| 完整 13 段见底稿《历史股价复盘》 | 放进附录，或把段落写完 |
| （详见底稿） | 删。要么写出来，要么不写 |

**判据一条：假设读者手里只有这一份 PDF，这句话他读不读得懂。**

**边界。** 附录 G 溯源表里列文件路径**不算违规**——那是来源登记，不是让读者去看；
**正文里的指向才违规**。底稿照旧要写，只是不进正文。

**还有一种指向：指着规则文档。** "股价见顶信号（`08` 4.6 六项）""（`08` 4.2，两列都要写）"
"（`08` 判读规则第 1 条）""分流后按 `08` 第三节读"——`08` 是本 skill 的文件编号，读者手里没有它。
**表题只写名称**（"表 4-2　股价见顶信号"）：不带编号、不带"要做几项"、句末不加句号。
**表头不用圈内词**：`读数` → "本轮的实际情况"；`取数` → 直接写数值或"来源"。

**根子在规范文档自己的表。** `08` 里那几张对照表的表头原本带 `B ·`／`C ·` 指代代号，第三列叫"取数"
（内容是底稿指针），表题写法又是"（4.6 六项）"这类——**整表照抄，脚手架就跟着进成稿了**。
所以这回连 `08` 的表头一起改。**规范文档里的表要写成"复制进成稿就能用"的样子。**
表题与表头的三条要求见 `06-成稿与PDF交付.md` 第五节。

**机械化的一条（warn，不阻断）**：正文（附录之前）出现"底稿"二字、或 `` `08` `` 加节号／
"判读规则"／"第 N 节"这类规则编号指针，`check_gates.py` 按「正文不指向底稿与规则」提示；
**表头出现"读数／取数"**另有提示；"分流三问""四态 C"并进「无过程自述」与「无机器腔」那两条。

### 标注不写第二遍（2026-10-15 新增）

`==关键结论==` 与 `@@风险@@` 是**圈原词**的语法，不是"在同义重复里补一句"。
东方钽业那份成稿写成"……向阶段三（供给追赶）的过渡，`==处阶段二向供给追赶过渡，缺口七项两项转向补上==`"——
前半句和标注那一半是同一件事（用户指出）。这类重复最爱长在高亮处，因为那正是作者觉得
"这里重要、得再说一次"的地方。

**两个动作：** ① **把标记去掉再读这句**——通顺＝圈出来的，读不通＝插进去的新句；
② 跑下面这条，把每个标注连同它前面 55 字列出来逐条读，看标注与紧邻的前一句是不是在说同一件事：

```bash
rg -n -o '.{0,55}==[^=]{4,}?==' 03-交付物/    # 风险侧把 == 换成 @@ 再跑一遍
```

**这条不设机械项。** 实测过：按"标注与前文的最长公共子串 ≥ 4 字"扫，东方钽业那份 11 个标注
命中 3 个，只有 1 个是真重复，另两个是正常的词面共享；**同义改写扫不出来**，硬扫只会制造噪声
（与"死"字那条同理）。

### 行业状态写方向，不写进度（2026-10-15 新增）

**来由。** 中粮糖业那份成稿第 4 节的结论：

> 行业处在"出清前夜与出清兑现之间的模糊带"。==第一波上涨的触发条件尚未凑齐==。
> 供给收缩未确认、库存未至低位、资本开支未持续负增长；这是行业状态的陈述，不构成对股价的买卖指令。

同一页往上翻，八项判据逐条读下来是"判为中性""未见激进行为""未见大面积击穿""数据缺口"——
**全是没转好的，结论却写成"尚未凑齐"。**"尚未凑齐"读起来是"只差临门一脚"，
把"还在往下走"说成了"快要往上走"，方向是反的。

速览页那处还有第二个毛病：同一页写着"上一轮高点在 2025 年 11 月、回撤约 39%"，
底稿段表里躺着 +159% 的完整上涨段——"第一波上涨的触发条件尚未凑齐"连起来读，
就是"股价都涨完了还说没开始"。

**判据只有一条：结论的方向要与判据的读数一致；这句位置判断与同页的股价节奏坐标
连起来读，会不会读成两个故事。**

| 不写 | 写什么 |
|---|---|
| 第一波上涨的触发条件尚未凑齐 | 出清没有进展：供给没有收缩，基本面还在走坏，价格缺乏上行动力 |
| 第二波上涨（业绩兑现） | 业绩兑现驱动的那一段 |
| 处在第一波上涨的触发区 | 处在下一轮上涨的触发区（**判据真的读到资本开支转负、亏损面扩大时才成立**） |

**"尚未凑齐"这类进度词要当心。** 句式是"条件还不具备"，读者会自己补上"那就快具备了"。
判据没转好就写"没有进展"，不写"还没凑齐"。

**手上有上一轮的起止与幅度就用上，没有就不写**——这条管的是通读，不是"必须出现某个数字"。

**边界。** 这条只管**成稿的措辞**。阶段表里对周期本身的描述（阶段名、"股价先于盈利见底"）
照旧写；`08` 第二、三节那两张阶段表里的股价特征列已改成不带序数的说法。

**机械化的一条（warn，不阻断）**：成稿正文出现"第 X 波上涨／行情／反弹／下跌"这类编号式波次、
或"尚未凑齐／凑齐了没有"这类**把方向说反**的进度说法，`check_gates.py` 按「不写编号式波次」
「位置结论带方向」两条提示；底稿段表里有 ≥ 50% 的上涨段时，波次那条会一并带出那个幅度。
**判据真的齐了、写"已经凑齐"是正当用法，不算命中**——脚本只抓"没到"那一侧，
免得多一条误报把这些提示变成噪声。

## 七、执行纪律（2026-10-13 新增，源自 mimo 工作台实盘复盘）

**背景。** 同一份 skill 换到另一个 agent 工作台上跑，13 份报告被压成 16 页的骨架。
复盘定位到三条机制，都不是"模型不会"，而是执行侧被悄悄放宽了。第 1—3 条是对这三条机制的封堵，
第 4、5 条是后续补的；五条都**与前面六节的写法规范同级，不是建议**。

### 1. 本任务不适用"最小化"偏好

通用 agent 的默认纪律是"做最小改动、别超出任务要求、能用就行"。写代码时这是对的，
写研究档案时是灾难：它会把"扒干净"执行成"搭个骨架、把数填进去"。
**在本 skill 里这条纪律作废。** 替代标准只有一条——
**必答问题是否都有实质回答、关键结论是否都带数字与来源。**
篇幅不够不是因为"精简"，是因为取数没做完。

### 2. 一家一会话

**不许把多家公司排成队列在同一个会话里连跑。** 原因是上下文会随会话变长被自动压缩，
而技能正文与 8 个参考文件都在会话最开头，**压缩时最先被挤掉**。

实盘证据（2026-10-12 会话）：开场读入技能与参考文件后，上下文在 30 分钟内涨到 37.9 万 token，
被压回 10 万；随后又涨到 48 万，再压回 22.6 万。被压掉之后再写报告，
手上只剩一副骨架记忆——记得住标题层级，记不住正文要求。
**表现就是质量随队列位置单调下降**：同一天里第一份 26 页、最后一份 16 页，
原始资料从 26 份掉到 1 份，每份报告只用了 5~6 次工具调用。

用户一次给多家时，逐家单独开会话；做不到就明确告知会降质，不闷头快跑。

### 3. 开写前重读、成稿前复核（抗压缩兜底）

**按流程表的「本步必读」走：进哪一步，就读那一两份。**

做法是**分散读**，不是开工前一次性硬读七八份——一次硬读的内容会在会话中途被压缩掉，
而且弱工作台读不完就会直接跳过。所以：动笔写正文前读 `00`（第六节）与 `02`，
排雷前读 `04`，估值前读 `05`，成稿前读 `06`，成稿后读 `10`。
**成稿前那一刻的重读最要紧**：会话中途被压缩过之后，这几份文件的内容已经不在上下文里了，
"我记得要求"不等于"要求还在"。重读时间与读到的文件写进 `02-工作底稿/成稿自检记录.md`。

**成稿前复核三件事，三件都要落在文件上，不靠回忆：**

1. 取数台账是否逐项填满（Gate 1）；
2. 排雷表是否**逐项成行**（不是一句"全部未命中"）；
3. 溯源表是否覆盖正文每个关键数字。

### 4. 取数优先走接口，浏览器只作补充

实测可用性排序：**官方接口（curl）> 年报正文 > 研报 PDF > 搜索引擎 > 浏览器逐页读**。
浏览器自动化（点击、翻页、读渲染内容）成本最高、失败率最高，
**只用它来找入口**；拿到 URL 之后改走 curl 或直接下载原文。接口清单见 `03-数据源地图.md`。

### 5. 派生文件不进交付物，项目结束清掉（2026-10-15 新增）

**为什么单列一条。** 每跑一家公司都会顺手产出一批"为了干活、不是为了留档"的文件——年报抽出来的全文副本、
接口拉回来的原始响应、一次性跑数的中间输出、转 PDF 时留下的中间 HTML。它们堆在项目目录里，
下一家进来就分不清哪个是原件、哪个是脚手架。**清掉它们，报告的可核性一点都不会少——
前提是引用落在原件坐标上（第二节第 1 条）。**

**认定标准一句话：删掉之后，报告里的数字还能不能核？能核，就是派生物。**

| 判 | 内容 |
|---|---|
| **算派生物（交付时清）** | 年报／公告／研报 PDF 的**文本抽取副本**（`02-工作底稿/文本/` 下的 `.txt`／`.md`）；**接口响应的原始缓存**（公告检索结果、全量日 K 这类，同一条命令能重新拉回来的）；**一次性跑数脚本与它们的中间输出**（`xx_out.txt` 这类；**报告复算要依赖它的不在此列**，见下一行）；`md_to_pdf.py --keep-html` 留下的**中间 HTML**；临时截图、空文件、废弃草稿 |
| **不算派生物（留）** | `01-原始资料/` 的**原件**（PDF 原件、研报原件）；`02-工作底稿/` 的全部 `.md` 底稿（闸门与结论的依据）；`02-工作底稿/数据/` 的**序列数据**（图与参照带的复算输入）；**估值脚本与参照带的输出**（要求留档的那几份，连同可复算依赖到的调用命令一起留）；`03-交付物/` 的成稿、PDF 与图 |

**动作：列清单 → 用户确认 → 删 → 记账。** 交付时把派生物按类列成清单交给用户，**确认之后再删**；
用户自己放进项目目录的文件一律不列、不删。删完在 `02-工作底稿/成稿自检记录.md` 留一行：
清了哪几类、各几个文件。**清单没列、没经确认，不许自行删除**——这一条要的是目录干净，不是"顺手清理"。

**留档与派生物的界线在哪。** 底稿是"结论的依据"（闸门要查、读者要核），派生物是"干活的脚手架"。
拿不准时问一句：下一家公司的研究者打开这个目录，要靠它才能核数字吗？答案是"是"就留。

**文件放哪。** 抽取副本一律写 `02-工作底稿/文本/<原件名>.txt`，**不摆在 `01-原始资料/` 的原件旁边**——
`01-原始资料/` 只放不可再生的原件。目录名固定，不要另起（`txt/`、`fulltext/` 都不算数）。

# 数据源地图

标注「实测」的接口在本机验证通过（A 股部分 2026-10-12，港股部分 2026-10-13）。数据获取优先级：**原始披露 > 官方统计 > 专业数据库 > 券商研报 > 媒体 > 搜索引擎**。

**这句话说的是证据等级，不是取数通道。** 取数时先走当前会话可用的妙想 MCP；关键数字仍要回到原始披露或官方统计核验。两套顺序不要混：

- **通道顺序**：妙想 MCP → 本文件公开接口／`scripts/` 脚本 → 用户补充的数据文件或只读接口；
- **证据等级**：原始披露 > 官方统计 > 专业数据库 > 券商研报 > 媒体 > 搜索引擎。

## 零、取数通道与自动降级

### 0.1 首轮取数

1. **先探测当前会话是否加载了妙想 MCP。** 常见 server 标识是 `mx-ds-mcp`，但工具名、参数和返回字段以实际加载结果为准；不要把某一版接口写成永久契约。
2. **能用就先用妙想。** 公司资料、财务指标、行情与估值序列、股东与事件、行业数据、公告与新闻等，按当前工具覆盖范围取数。妙想适合做结构化检索和批量取数，不改变证据等级；关键数字仍按“原始披露 > 官方统计”的次序核验。
3. **未安装或调用失败就立即降级，不停下等用户。** 触发条件包括：会话里找不到妙想工具、连接失败、开始收费、额度不足、鉴权失效、限流、持续超时、返回空值、字段缺失、口径无法确认，或数据与申万三级／公司披露口径不匹配。此时直接改用本文件列出的公开接口、官网与 `scripts/` 脚本，不用先征求用户同意。
4. **逐项记录通道。** 取数台账每一类至少记：`来源通道`（妙想／公开接口／官网／脚本／用户补充）、`查询对象与日期`、`报告期／截止日`、`MCP 状态与失败原因`（若使用妙想）、`实际降级路径`、`仍未取得的项`。不要让后来的人看到一串数字却不知道它是怎么来的。
5. **降级后仍缺，照常完成报告。** 缺口按“已试路径／可继续查的具体渠道／需要什么条件”三行登记，进入正文第 10 节与溯源表。**缺口不阻塞首版报告**，但阻塞“所有数据已齐”的表述。

### 0.2 交付后补数

报告交付后，必须生成 `02-工作底稿/数据缺口与补数清单.md`，并把同样内容在对话里单独说一遍。表头固定为：

| 缺什么 | 影响哪一节／哪个结论 | 已试路径与失败原因 | 建议查询渠道 | 需要权限或费用 | 可接受的补充格式 | 补上后要重跑什么 |
|---|---|---|---|---|---|---|

建议查询渠道要具体到机构名、数据库名或页面，例如交易所公告、国家统计局、行业协会、巨潮／披露易、公司 IR、Wind／Choice／iFinD／Bloomberg。费用未知写“需询价”，不要猜。

**用户补充数据后的处理顺序：**

1. 用户可提供 CSV／XLSX／JSON、Wind／Choice／iFinD 等终端导出的文件，或已配置好的只读接口。**不要让用户把账号密码或 API key 写进报告、skill 或项目文件。** 需要凭据的接口由用户在本机环境配置，或直接导出数据。
2. 原始文件放 `01-原始资料/补充数据/`，整理后的数据放 `02-工作底稿/数据/`；保留原始文件，不覆盖首轮数据。
3. 在 `02-工作底稿/补数记录.md` 记录：补充项、来源、口径、报告期、截止日、与原数据的差异、替换或并存的决定。
4. 更新 `取数台账.md` 与成稿溯源表，重跑受影响的计算、图表、`scripts/cycle_valuation.py` 与估值参照带；不要只改正文数字。
5. 重读受影响章节，判断结论是否变化：变化就改结论并写明原因；不变化也写“补数后结论未变”。随后重跑 `check_gates.py`、重新生成 PDF，交付带版本号的新稿。

### 0.3 开源边界

- 妙想 MCP 是**可选增强**，不是安装前提；没有它，公开接口与本地脚本仍要能完成报告。
- skill 不读取用户客户端的配置文件，不保存 MCP 地址、密钥或账号；工具发现只在当前会话内完成。
- 不把某个用户的私有接口、绝对路径、终端配置写进 skill。用户补充的 Wind／Choice 等数据只进当前项目目录，不反向写入 skill 包。

## 一、公司原始披露

两条渠道并行：**A 股走巨潮资讯网与沪深交易所官网，港股走港交所披露易（HKEXnews）**。
A+H 两地上市的公司，两边的文件都要下，且要留意准则与口径差异（见本节末）。

### 巨潮资讯网（A 股，证监会指定披露平台）— 实测可用

年报/半年报/公告按公司代码程序化检索：

```bash
# category_ndbg_szsh = 年度报告；stock 需带 orgId 前缀
curl -s -X POST "http://www.cninfo.com.cn/new/hisAnnouncement/query" \
  -H "Referer: http://www.cninfo.com.cn/new/commonUrl?url=disclosure/list/notice" \
  --data "pageNum=1&pageSize=30&column=szse&tabName=fulltext&plate=&stock=600176%2Cgssh0600176&category=category_ndbg_szsh&seDate=2023-01-01~2026-10-12"
```

- 返回 `adjunctUrl`，拼 `http://static.cninfo.com.cn/` 即可下载 PDF
- 常用 `category`：`category_ndbg_szsh` 年报、`category_bndbg_szsh` 半年报、`category_yjdbg_szsh` 一季报、`category_sjdbg_szsh` 三季报、`category_zf_szsh` 增发、`category_gqjl_szsh` 股权激励
- 沪深两市的公告都在这里；深市 `column=szse`、沪市 `column=sse`

### 交易所官网

- 上交所 `www.sse.com.cn`、深交所 `www.szse.cn`：问询函、监管函、纪律处分、处罚
- 北交所 `www.bse.cn`

### 监管与司法

- 证监会 `www.csrc.gov.cn`：行政处罚、立案调查、市场禁入
- 中国裁判文书网、全国法院被执行人信息（诉讼与执行）

### 港交所披露易 HKEXnews（港股，唯一法定披露平台）— 实测可用

港股的法定披露只有这一个入口，年报与中报、公告、通函、权益披露都在这里。**两步走：先查内码，再检索公告。**

```bash
# ① 查股票内码（stockId）：检索接口只认内码，不认股票代码
#    name 可传代码或英文名；一只股票会有多个条目，取 code 与标的完全一致的那条
curl -s "https://www1.hkexnews.hk/search/prefix.do?callback=cb&lang=ZH&type=A&name=02386&market=SEHK" \
  -H "User-Agent: Mozilla/5.0"
# → stockId=87785, code=02386, name=中石化煉化工程

# ② 按类型检索公告：GET，POST 会返回「method POST is not supported」
#    lang=ZH 中文 / lang=EN 英文；t1code=40000 财报类，t2code=40100 年报、40200 中报
curl -s "https://www1.hkexnews.hk/search/titleSearchServlet.do?sortDir=0&sortByOptions=DateTime\
&category=0&market=SEHK&stockId=87785&documentType=-1&fromDate=20250101&toDate=20261013\
&title=&searchType=1&t1code=40000&t2Gcode=-2&t2code=40100&rowRange=100&lang=ZH" \
  -H "User-Agent: Mozilla/5.0" \
  -H "Referer: https://www1.hkexnews.hk/search/titlesearch.xhtml?lang=zh" \
  -H "X-Requested-With: XMLHttpRequest"
# → {"result":"[{...}]","recordCnt":2,...}，每条含 TITLE、DATE_TIME、FILE_INFO(体积)、FILE_LINK
```

- **PDF 直链**：`https://www1.hkexnews.hk` ＋ `FILE_LINK`，例
  `/listedco/listconews/sehk/2026/0315/2026031500028_c.pdf`
- **中英文版的差别只在文件名**：中文版结尾是 `_c.pdf`，把 `_c` 去掉即英文版。**两边内容可能不完全对称，
  正式引用以与投资者沟通所用的版本为准，报告里注明取的是哪一版**
- **`t1code` 常用值**：`40000` 财报 / ESG；`40100` 年报、`40200` 中报、`40300` 季报（自愿）；
  `-1` 不限类型（拉全部公告）。`rowRange` 上限放宽即可一次拿一年
- **文本提取**：年报 PDF 的文字层完好，用 PyMuPDF 直接抽（本次实测 187 页中文年报，
  正文与附注均可正常抽取，无需 OCR）。**抽取副本落 `02-工作底稿/文本/<原件名>.txt`，
  不放进 `01-原始资料/`**——它是派生物，项目结束随派生文件清掉（`00` 第七节第 5 条）。
  所以抽的时候就把**页码锚**写进去，成稿引用才落得到原件坐标上（`00` 第二节第 1 条）：

```bash
mkdir -p 02-工作底稿/文本
python3 - <<'EXTRACT'
import pathlib, pymupdf
src = pathlib.Path("01-原始资料/2024年年度报告.pdf")
dst = pathlib.Path("02-工作底稿/文本/2024年年度报告.txt")
with pymupdf.open(src) as doc:
    dst.write_text("".join(f"[[第 {i} 页]]\n{p.get_text()}\n"
                           for i, p in enumerate(doc, 1)), encoding="utf-8")
EXTRACT

# PDF 本身搜不了，在副本里搜；引用时回原件页码
rg -n "表观消费|开工负荷|产能" 02-工作底稿/文本/
```

  缺 `pymupdf` 时脚本会报错并给出 `python3 -m pip install pymupdf`。

**港股披露与 A 股的四处不同，取数前先记住：**

1. **没有季报。** 只有年报与中报，部分公司自愿披露季度营运数据或经营公告。
   信息滞后比 A 股长，报告的数据基准要写清"最新报告期为某年中报"
2. **财年不一定是 12 月 31 日。** 有公司用 3 月、6 月、9 月年结，跨公司比较时要对齐期间，
   不能拿"2025 年报"直接当同一年度
3. **会计准则走 HKFRS**（与 IFRS 趋同），与中国会计准则存在差异，净利润与净资产都可能不同。
   A+H 公司会分别披露两套，**报告要写明引的是哪一套**，做两地对比时不能混用
4. **关连交易、权益披露、股份抵押是法定的持续披露项**，比 A 股细，是排雷的富矿

**港股的监管与治理文件：**

- 港交所「上市规则执行」页：纪律行动、公开谴责、董事不适合性声明
- 证监会 SFC `www.sfc.hk`：执法消息、市场失当行为审裁处（MMT）裁决、股权高度集中提示
- 港交所「披露易」下的**权益披露（DI）**与 **CCASS 持股查询**：主要股东与股份抵押、券商席位持股
- 港交所「长期停牌与除牌」公告：停牌超过《上市规则》规定期限可被除牌

**A+H 两地的对照要点：**同一家公司两套报告同时存在时，**把两边的关键数字并排放**——
KPI 口径、分部划分、关联方范围、政府补助认定都可能不同，差异本身就是信息。

## 二、行情、行业与宏观数据

### 行情、估值与财务序列（做估值参照带的原料）

参照带要的是**逐日序列**，不是某一天的快照。三个接口实测可用（2026-10-12）：

```bash
# ① 个股逐日估值序列：收盘价、总股本、总市值、PB(MRQ)、PS(TTM)、PE(TTM) —— 参照带的主数据
#    reportName=RPT_VALUEANALYSIS_DET（写成 RPT_VALUEANALYSIS 会报"报表配置不存在"）
#    pageSize 上限 500，要翻页；海南橡胶 2,126 个交易日 = 5 页
curl -s "https://datacenter.eastmoney.com/securities/api/data/v1/get?reportName=RPT_VALUEANALYSIS_DET\
&columns=SECUCODE,SECURITY_CODE,TRADE_DATE,CLOSE_PRICE,TOTAL_SHARES,TOTAL_MARKET_CAP,PB_MRQ,PS_TTM,PE_TTM\
&filter=(SECUCODE%3D%22601118.SH%22)&pageSize=500&pageNumber=1&sortColumns=TRADE_DATE&sortTypes=-1" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: https://data.eastmoney.com/"

# ② 主要财务指标（分报告期）：BPS、EPS、ROE、扣非归母净利 —— 算正常化基准与历史净资产
#    同域，reportName=RPT_F10_FINANCE_MAINFINADATA；资产负债表用 RPT_F10_FINANCE_GBALANCE

# ③ 个股日 K（不复权 fqt=0 / 前复权 fqt=1）：算历史某一时点的市值与估值指标
curl -s "https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.601118\
&fields1=f1,f2,f3,f4,f5&fields2=f51,f52,f53,f54,f55,f56&klt=101&fqt=0&beg=20110101&end=20110331" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: https://quote.eastmoney.com/"
```

- `secid` 前缀：沪市 `1.`、深市 `0.`；`klt=101` 日线、`102` 周线、`103` 月线
- **东财的估值序列只回溯到 2018 年**，更早的时点要用"不复权收盘价 ÷ 当期 BPS"自行计算，
  并且必须注意当时的股本与净资产口径（本次海南橡胶实盘踩过：用 2010 年三季报净资产
  算 2011 年 2 月的 PB 会虚高到 17 倍，因为四季度的股本扩张还没进报表）
- 拿去做 `scripts/cycle_valuation.py` 的输入时，估值序列和品种价格序列都存成 JSON，
  放在项目目录的 `02-工作底稿/` 下，便于复算与留档
- **历史股价复盘用月线（`klt=103`），不用日线**：段边界是中长线趋势的反转，
  日线的噪声会把反弹误判成反转（见 `references/13` 第一节）。
  复权口径全篇统一一种（前复权或后复权），并在底稿里注明是哪一种；
  区间跨过送转、定增或可转债转股时，回查一下是否需要按当前股本折算

### 港股行情、估值与财务序列 — 实测可用（2026-10-13）

**港股没有 A 股那样的逐日估值序列接口**（`RPT_VALUEANALYSIS_DET` 对港股返回"数据为空"），
要按下面这套组合自己拼，其中 PB 序列用"不复权收盘价 ÷ 当期 BPS"自建。

```bash
# ① 日 K（不复权 fqt=0 / 前复权 fqt=1）——港股 secid 前缀是 116.
curl -s "https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=116.00700\
&fields1=f1,f2,f3,f4,f5&fields2=f51,f52,f53,f54,f55,f56&klt=101&fqt=0&beg=20200101&end=20261013" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: https://quote.eastmoney.com/"

# ② 快照：每股净资产 f92、总市值 f116、PB(MRQ) f167 —— f167 是 ×100 的整数，要除以 100
#    f43 是价格 ×1000（港股用 3 位小数）：424600 ÷ 1000 = 424.6 港元
curl -s "https://push2.eastmoney.com/api/qt/stock/get?secid=116.00700\
&fields=f57,f58,f43,f92,f116,f117,f167,f162,f164,f127" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: https://quote.eastmoney.com/"

# ③ 分报告期财务指标：BPS、EPS、营收、毛利、归母净利、ROE、资产负债率 —— 建 PB 序列与做财务体检的主数据
curl -s "https://datacenter.eastmoney.com/securities/api/data/v1/get?reportName=RPT_HKF10_FN_MAININDICATOR\
&columns=SECUCODE,REPORT_DATE,REPORT_TYPE,BPS,BASIC_EPS,OPERATE_INCOME,OPERATE_INCOME_YOY,HOLDER_PROFIT,GROSS_PROFIT,ROE_AVG,DEBT_ASSET_RATIO\
&filter=(SECUCODE%3D%2202386.HK%22)&pageSize=50&pageNumber=1&sortColumns=REPORT_DATE&sortTypes=-1" \
  -H "User-Agent: Mozilla/5.0" -H "Referer: https://emweb.securities.eastmoney.com/"

# ④ 资产负债表全表（`columns=ALL`），含 CURRENCY、ACCOUNT_STANDARD、FISCAL_YEAR 三个口径字段
#    reportName=RPT_HKF10_FN_BALANCE；利润表同理换名字即可

# ⑤ 公司资料：reportName=RPT_HKF10_INFO_ORGPROFILE（注册地、成立日、行业、员工等）
```

- **`SECUCODE` 写法**：`00700.HK`，代码补足五位
- **口径字段很有用**：`ACCOUNT_STANDARD` 会直接告诉你是"国际会计准则"还是中国会计准则，
  `CURRENCY` 是报表币种（H 股公司常见人民币），`FISCAL_YEAR` 是年结日。
  **建 PB 序列前先核对币种：股价是港元，BPS 若是人民币口径，必须按同一日汇率折算后再相除**
- **`f162`（PE）在港股返回 0，不可用**；PE 要用"总市值 ÷ 归母净利"自算，且注意
  港股中报与年报的口径（TTM 需自己滚动四个半年度，A 股那套"自动 TTM"的便利这里没有）
- **南向资金**：`reportName=RPT_MUTUAL_STOCK_HOLDRANKS`，`filter=(SECUCODE="00700.HK")`，
  返回持股数量、持股市值、占总股本比例（`TOTAL_SHARES_RATIO`）、参与券商数
- **汇率**：`https://api.exchangerate-api.com/v4/latest/HKD` 实测可用（免费端点，返回 HKD 对各币种中间价）。
  写进报告时要标明汇率来源与取值日，并与中国银行外汇牌价页交叉核对

**已知未程序化验证的港股数据（要用时按路径去试）：**
港交所 CCASS 持股查询与权益披露（`www3.hkexnews.hk/sdw/search/searchsdw.aspx`，需交互式查询）、
沽空比率（港交所每日沽空数据页）、同股不同权（WVR）公司名单、
恒生 AH 股溢价指数的官方历史序列、港股通标的调整名单。

### 官方统计机构（书第 12 章清单的落地版）

| 机构 | 能拿到什么 |
|---|---|
| 国家统计局 | GDP、工业增加值、社零、CPI/PPI、分行业数据 |
| 央行 | 社融、货币供应、金融机构信贷 |
| 海关总署 | 进出口分商品/分国别（**国际依赖型公司必查**） |
| 工信部 | 原材料、装备、消费品、通信、电子制造、软件业 |
| 发改委 | 分省经济、煤电油气、重要商品价格 |
| 财政部 | 财政收支、税收、土地出让金 |


  要连测算方法一起引用，**并把 PDF 原件存进 `01-原始资料/研报/`**；② 图表读数，
  要连图题与资料来源一起标注，原件同样存档）
- **转引研报数字前，先看原件在不在。** 存的规矩是：只要正文里的数字、口径或结论来自某份研报，
  该研报 PDF 就进 `01-原始资料/研报/`，文件名带机构与日期（如

  的「研报」一类里逐份登记。
  **没存原件的，溯源表必须注明"转引，不可回原件核验"，并且这个数字不得承担关键结论。**
  实盘教训：海南橡胶报告 2.4 节的单吨成本表声明来自某份券商测算，`01-原始资料/` 里
  一份研报都没有，联网也查不到该报告——数字用了九年，原件却无从核对，
  最后是用户凭常识（真实吨成本约 1.5 万至 1.6 万元）发现它离谱。

## 四、检索工具与使用边界

**默认走 Bing。** 用户 2026-10-12 指定：检索一律优先用 Bing（`https://www.bing.com/search?q=`）——
中英文结果质量都够、反爬压力小、连续查询不容易被拦。Bing 明确查不到时才换备用工具。

| 工具 | 定位 | 备注 |
|---|---|---|
| **Bing**（`https://www.bing.com/search?q=`） | **默认首选** | 中英文都稳；`&cc=cn` 偏中文结果，`&setlang=en` 偏英文结果 |
| （Bing 的已知失效模式） | — | **长问句或首词为常见词（如"天然橡胶…"）时，会退化成词典释义结果**。对策：把查询改成短词组、把专有名词放前面、加 `site:`；仍不行就换下面的专用接口 —— **本次实盘的下游占比数据最终是从券商研报 PDF 里取的，不是搜出来的** |
| 360 搜索（`https://www.so.com/s`） | 备用 | 可用，但连续查询会限流，需间隔数秒 |
| 百度 | 备用 | 中文覆盖最好，反爬较强 |

- 搜索引擎只用于**找线索、找原文入口**，不作为数据来源
- 引用网页内容时记录：标题、站点、发布日期、URL、访问日期
- **找到入口之后，改走 `curl` 或直接下载原文，不要用浏览器逐页读渲染内容。**
  实盘比较：浏览器自动化（点击、翻页、读渲染页面）在这套流程里成本最高、失败率最高；
  本文件里标着「实测」的接口都能用 `curl` 直接拿到结构化结果，优先用它们。

## 五、取数与核验规则

1. **一张表两个源**：关键数字至少交叉验证一次；两源不一致时以原始披露为准，并在溯源表里记差异
2. **口径优先**：同一指标有多种口径（如"市场规模"的 TAM/SAM/SOM）时，写明取哪个、为什么
3. **时点标注**：所有数据标日期或报告期，避免用旧数据
4. **拿不到就写"公开渠道未获取"**，并写明需什么条件才能拿到
5. **转引必有存件**：正文任何数字、口径或结论来自研报的，原件进 `01-原始资料/研报/`
   并在台账「研报」一类登记；没存件的在溯源表注明"转引，不可回原件核验"，
   **且不得承担关键结论**（见第二节第一节的用途限定）
6. **自算的派生数字另有一关**：口径三问 ＋ 独立源对照，做法见
   `12-模型自检与交叉验证.md`。这一条管的是原始数据，那一份管的是算出来的数
7. **引用坐标落在原件上**：正文与溯源表的坐标写「原件文件名 ＋ 页码／表号」，
   **不写文本抽取副本的行号**——副本是派生物，项目结束清掉（`00` 第七节第 5 条），
   行号引用届时无人能核。抽文本时的页码锚做法见第一节
8. **补数不是改一个数字**：用户补充数据后，按 §0.2 更新台账、重跑计算与图表、重读受影响章节并重跑闸门。原始文件、补数记录与修订版报告都要留档。

### 取数台账（Step 1 的完成闸门）

Step 1 的产物除了 `01-原始资料/`，还有 `02-工作底稿/取数台账.md`。
**它不通过，不进 Step 2**（Gate 1，见 `SKILL.md`）。
台账按下面七类逐项登记，每项只有两种状态：**已取**（写文件名／接口 ＋ 日期）或
**缺口**（写"已试路径 ／ 可继续查的具体渠道 ／ 需要什么条件"三行）。

| 类 | 最少要有什么 | 缺口的标准写法 |
|---|---|---|
| 本体披露 | 近 3~5 年年报 ＋ 最近中报/季报 ＋ 重大公告（处罚、质押、减持、重组） | 已试路径 ／ 具体渠道（机构名、数据库名、页面） ／ 需要什么条件 |
| 行业时序 | 近 5 年产量、需求、进出口、库存、价格序列 | 同上 |
| 产业链 | 上游原料、下游应用逐项 ＋ 占比（带数据年份） | 同上 |
| 同业对照 | 国内同业 ≥ 3 家 ＋ **国际同业 ≥ 2 家** | 同上 |
| 估值序列 | 个股 PE／PB 逐日序列（东财接口，见本节第一、二部分），区间 ≥ 5 年 | 同上 |
| 研报 | 至少 2 家券商的行业或公司深度 | 同上 |
| 官方监管 | 交易所问询／监管函、证监局处罚、裁判文书检索结果（含"未检索到"这一结论） | 同上 |

**三行缺一行，这一项算没填。** 空白格与"未获取"三个字都不算填过。

**台账是给用户看的，不是给自己看的。** 成稿渲染出来看不出少了哪一类数据，
台账一眼能看出来——它把"少做"从隐性变成显性。

## 六、已知取不到的数据与替代路径（2026-10-12 海南橡胶实盘）

国际对标做到一半会卡在"数据在，但拿不到"。先记下来，下次照这条路走，不要临时抓瞎：

**规则：缺口必须写成可执行的下一步。** 每一行都要能让下一个人照着去查——
具体机构名、数据库名、页面路径，以及"拿到它需要什么条件"。
**只写"未获取"不是结论，是没做完。**

| 想拿什么 | 卡在哪 | 替代路径 |
|---|---|---|
| 泰国上市公司行情与估值指标（如诗董 Sri Trang 的市值、PB） | 泰国交易所行情页需要交互或反爬 | 依次试：① SET 官网个股页（`set.or.th`，有英文版）；② Investing.com / TradingView 的 SET 板块；③ 公司 IR 页年报与投资者简报（含股本，可自算市值）；④ 有 Wind / Bloomberg / Choice 账号时直接取；⑤ 当地券商研报。**以上都失败，才退到只做盈利质量对标，并把上述路径写进报告** |
| 下游分行业用量占比（如橡胶下游轮胎、胶带、胶管、鞋材各占多少） | 协会数据多为付费或只给总量 | ① 中国橡胶工业协会的年度报告摘要与新闻稿；② 卓创 / 隆众的行业月度报告（免费摘要）；③ 用下游上市公司的收入结构反推；④ ANRPC / IRSG 的消费分项。**找不到就把"占比未知"与路径一起写清楚** |
| 近 5 年现货均价与库存序列 | 单个来源口径不一致 | ① 上期所主力连续合约结算价的年度均值（可程序化取）；② 生意社 / 卓创的年度现货均价；③ 上期所库存周报。**两源不一致时以交易所口径为准并标注差异** |
| 单位经济模型的精确吨毛利 | 公司不披露分产品单位成本 | 用"收入结构 ＋ 分产品成本"倒算，按 `00` 数据规范第 6 条写清口径与换算；给出量级区间，不留空位 |
| 客户名称 | 年报只披露前五大占比、不披露名称 | ① 年报"前五大客户"附注与关联方披露；② 招投标 / 中标公告；③ 重大合同公告；④ 公司官网客户案例；⑤ 行业媒体与供应链报道。**确实查不到就写"仅披露占比 XX%，未披露名称"，并附上述路径** |
| 越南橡胶集团（VRG）财务数据 | 官网改版后英文财务页缺失 | 找其年报 PDF 直链或当地券商报告；仍拿不到就如实写缺口，不要用行业均值顶替 |
| 中国本土天然橡胶产量的权威分品种数字 | 国家统计局/农业农村部未见对应口径公开 | 用"消费量 − 进口量 ± 库存变动"倒推量级，并明确标注这是推算口径、非官方产量 |
| 商誉减值测试的关键参数（增长率、折现率） | 年报未逐项披露 | 只能记"未披露、无法验证账面值支撑强度"，不要自行假设 |
| 某次监管认定涉及的逐笔交易对手方 | 监管文件只披露金额与性质 | 记缺口；同时提示"无法判断是否存在关联方参与" |

**通用原则：卡住的时候，先问"这个数能不能换一个口径答同一个问题"，不能就进缺口清单。**
不要为了把表填满而拿一个口径不同的数顶上——那比留空更糟。

## 七、已知取不到的数据与替代路径（2026-10-12 双环科技实盘）

### 先记一条正面经验

**制造类行业的行业数据，同业年报正文往往比公开检索更可靠。**

本次必应对纯碱行业数据检索基本失效：短查询词（`纯碱 产能`）被同名的双环传动（002472）淹没，
长问句退化成词典释义，加 `site:` 也拉不回行业口径。
行业供需、下游消费占比、工艺结构、进出口、开工负荷最后**全部从 8 家同业、12 份年报正文取得**
（三友化工、山东海化、中盐化工、和邦生物、博源化工、苏盐井神、雪天盐业、华昌化工）。
同业年报里既有中国纯碱工业协会口径，也有卓创、隆众、百川的转引，**带口径来源与年份**，
比搜出来的二手转述更完整、更可溯源。

**做法：拿到标的先列同业名单，把同业年报全文下载、转文本，再按关键词（产能、产量、表观消费、
下游、开工、库存、出口）逐份过一遍。** 这比反复换检索词快得多。
转出来的文本按第一节的做法落 `02-工作底稿/文本/`（带页码锚），**引用其中的数据时写回原件页码**——
副本是派生物，项目结束就删。

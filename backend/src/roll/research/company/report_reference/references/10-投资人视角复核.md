# 投资人视角复核（Gate 3）

成稿写完、PDF 也渲染出来之后，换一副眼睛再读一遍：**把自己放到一个真正要管钱的位置上。**
这一步不判断该不该买——本 skill 不给买卖建议——它只回答三个问题：

1. **我能不能看懂？** 一个不在投资圈里的人，读完这份报告，能不能复述出这家公司是怎么回事。
2. **它对投资有没有帮助？** 读完它，我对这家公司的理解，是不是比读十篇新闻更多。
3. **哪些重要的事没写？** 那些我下次想投它会去查、但报告里找不到的东西。

**为什么要单设一步。** 写的人与读的人视角不同：写的人盯着"我该写的都写了没有"，
读的人只关心"我看完拿到了什么"。前两道闸门（Gate 1 取数、Gate 2 成稿）都是**写的人自查**——
数台账、数行数、数标注。这一步是**第一次用读的人的眼光看成品**，
它专抓"每一项都写了、但读者还是没得到答案"这类问题。

**位置。** Step 6 出了 Markdown 与 PDF 之后、Step 7 交付之前做。命中缺口就回补正文，
然后重跑一次 `scripts/md_to_pdf.py`。
**结论写进 `02-工作底稿/投资人视角复核.md`，逐条给结论与证据。**

## 一、三遍读法

### 第一遍：只读速览页（60 秒测试）

把正文遮住，只读速览页。读完后合上，问自己能不能用一段话复述这五件事：

- 它靠什么赚钱（哪几块业务、各自贡献多少）
- 哪个变量说了算（改它一个，全篇结论要重算）
- 现在处在周期的什么位置、什么时候该提高警惕
- 最该防的雷是什么
- 还有什么没查清

五件事里答不全任何一件，**速览页不合格**——不是正文的问题，是速览页没把结论提上来。

### 第二遍：只读骨架（结构测试）

只读四部分的导语页 ＋ 每节标题 ＋ 每节第一句，不读正文。
能不能拼出全文的推理链：生意是什么 → 外部条件如何 → 账本真不真、雷在哪 → 什么价位对应什么状况。
拼不出来，说明标题写成了分类标签、或者首句不是判断（对照 `02-问题链与报告结构.md` 四条做法）。

### 第三遍：带着下面这张清单逐条问（缺失测试）

这一遍是核心。每条只判"过／不过"，不过的写清缺什么、补在哪一节。

## 二、必问清单（重要但最常没写到的）

| # | 投资人会问 | 不合格的样子 |
|---|---|---|
| 1 | 靠什么赚钱，一句话说清 | 复述年报"主营业务为……" |
| 2 | 第一驱动变量，一阶敏感度给了吗（X 变 1 单位，净利变多少） | 罗列 20 个指标，不排序、不给敏感度 |
| 3 | 处在大周期的什么位置：哪条路径（A 过剩出清型／B 需求拉动型）、第几阶段、库存第几象限；以及**是不是已经见顶**（`08` 第一、四节）。速览的周期坐标、第 4 节的阶段、第 8 节的股价节奏坐标三处说法一致吗 | 只给当年供需量；只给价格分位不给阶段；只答"出清到哪一步"、不答"是否见顶"；三处位置各说各话 |
| 4 | 什么时候风险最高（不是"有风险"，是"风险在什么时点集中出现"） | 风险写成一段泛泛的定性 |
| 5 | 上下游列全了吗、占比给了吗、钱落在产业链哪一段 | 只写"下游主要是轮胎" |
| 6 | 国际同业是什么水平、这家排第几、差在哪 | 只跟国内比；国际对标一句"查不到"带过 |
| 7 | 单位经济模型填满了吗、每单位赚多少、怎么算出来的 | 表格里留横杠或"未获取" |
| 8 | 盈亏平衡点在哪（价格/利用率跌到什么水平会亏） | 只给利润，不给临界值 |
| 9 | 最重的雷是什么、灯号是什么、优势与雷写对等了吗 | 一边三条一边三十行 |
| 10 | 该给事件日历的（牌照/许可/事件驱动型），日历给了吗 | 用产能周期逻辑硬套牌照型公司 |
| 11 | 没查到的数字，三条路（已试／还能去哪／需要什么条件）齐了吗 | 一句"未获取"收尾 |
| 12 | 读起来像报告还是像资料汇编/讲解文 | 有"这一节回答一个问题"式导语、有 `读法` 标签；速览页或正文出现 `C · 顶部结束` 式代号、`读数 4 条对 3 条` 式计数、`理由即前四条` 式指针、一个括号塞四件事（`00` 第六节·机器腔） |
| 13 | 管理层的钱往哪投、再投资的回报如何（`11` 第五节） | 只写"管理团队优秀"，不给资本配置的历史数字 |
| 14 | 反过来查过没有：最大证伪点是什么、多空两侧各证伪一遍（`11` 第一、二节） | 只有正面结论没有反面；或反面只是"行业有风险"这类通用话 |
| 15 | 那些"第一"和评分是谁数的、样本多大、跟谁比、和同期的销量／份额对得上吗（`11` 第九节） | **把年报转述的 NPS／满意度／行业排名直接写成品牌壁垒或定价权**；只有绝对值、没有机构与口径；指标极好而经营数据在恶化却只写了好看的那半边 |
| 16 | 这只股票历史上**为什么涨、为什么跌**：每段是利润推的还是估值推的、上一轮调整**靠什么结束**、当时最早的先行信号是什么、这类调整本行业**通常多久**、**当前这轮走到哪一步**（`13`）；成稿里有没有出现逐日涨跌归因 | **只报结论不报价格历史**，读者拿不到"现在是什么时候"；或写成"某月某日下跌是因为……"式的日线归因；把一次性催化（事故、传闻、大盘暴跌）当成公司竞争力 |

## 三、按类型的加问（接 `01` 的侧重与 `08` 的择时表）

| 类型 | 投资人额外追问 |
|---|---|
| 周期型 | 判断给的是**增速**还是利润水平——利润增速见顶了没有（利润还在涨不等于没见顶）？供给投放进度到哪一步了（股价不会等到投放那天才跌）？三条读数（商品价格／利润／股价）谁领先、谁滞后？涨完一轮之后是中继还是见顶：驱动变量（现货价与价差、供给投放进度、下游增速）现在往哪边走？本轮回撤与这只股票历史上"中继调整""见顶后调整"两条分布比，更像哪一条（`08` 第四节、《13》）？这条路是 A 类过剩出清型还是 B 类需求拉动型（`08` 第一节三问）？A 类：出清判据八项读到哪一步、方向是在恶化还是在改善（**结论有没有照判据写**，
还是落在了"只差临门一脚"式的措辞上；**这只股票上一轮已经走过了没有**）？B 类：缺口判据七项读到哪一步、缺口是在打开还是正在被补上？这一轮涨价是供需缺口、成本推动还是突发事件？**行业与股价各自见顶了没有**（`08` 第四节两张清单里哪些已经出现、哪些还没有）？ |
| 成长型 | 渗透率多少、斜率如何？增长的钱从哪来（量/价/新市场/抢份额）？现金还能撑几个季度？ |
| 科技型 | 产品在第几代、进大客户供应体系了吗？管线/流片到什么节点？壁垒是"换供应商要多久"？ |
| 红利型 | 分红的钱从哪来（经营现金流/卖资产/举债）？自由现金流对分红的覆盖程度（自由现金流 ÷ 分红）多少？资本开支是维持性还是扩张性？ |
| 金融型 | 不良生成率趋势？息差还能不能稳住？PB 背后对应的 ROE 是多少？ |
| 事件驱动型（牌照/许可） | 事件日历给了吗？下一个可能的催化是什么、大概什么时点？ |

## 四、写下来的格式

`02-工作底稿/投资人视角复核.md` 用一张表逐条落地，不写空话：

| 检查项 | 结论 | 证据 / 位置 | 未过时怎么补 |
|---|---|---|---|
| 速览页 60 秒复述 | 过 / 不过 | 速览页第 X 段 | —— |
| 骨架测试 | 过 / 不过 | 四个导语页 | 标题改写成"主题：结论" |
| 必问 1~16 逐条 | …… | …… | 回补到第 X 节 |
| 本类型加问逐条 | …… | …… | …… |
| 最大证伪点 / 多空对垒 | 过 / 不过 | 速览页 ＋ 第 10 节 | 回补到第 10 节 |
| 本报告未能回答的关键问题 | 过 / 不过 | 第 10 节 | 逐条补去向，空表即不合格 |
| 榜单／评分／名次类指标（必问 15） | 过 / 不过 | 正文各处 ＋ `02-工作底稿/指标核查.md` | 补口径、补外部锚、按 `11` 第九节定档；未核实的从"优势"一节撤下 |
| 历史股价复盘（必问 16） | 过 / 不过 | 正文第八节 ＋ 速览页股价节奏坐标 ＋ `02-工作底稿/历史股价复盘.md` | 补段表与 利润侧与估值侧拆解（每股收益、市盈率）、补调整段的结束标志与先行信号、按 `13` 第五节的行业经验值做对照 |

**回补之后必须重跑 `scripts/md_to_pdf.py`**，因为正文变了、页码会挪。

## 五、防橡皮图章

**下面这些写法不算复核，看到就等于没做：**

- "已复核，内容详实、逻辑清晰、结构完整"——没有一个具体结论
- "建议补充国际对标"——但不说补到哪、缺哪几家、为什么现在这版不合格
- 把必问清单原样抄一遍、每条都打勾，却没有任何证据或位置

**判断标准一条：** 复核记录的每一条，要么指出一个**具体位置**（在第几节、哪张表），
要么给出一个**具体缺口**（缺什么、怎么补）。**说不出位置和缺口的结论，等于没读。**
